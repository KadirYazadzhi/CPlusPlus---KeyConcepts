# Ламбда Изрази (Lambda Expressions) в C++

## 1. Въведение

Ламбда изразите (въведени в C++11) са начин за дефиниране на **анонимни функции** директно на мястото, където се използват. Те са изключително полезни за кратки фрагменти от код, които се предават като аргументи на алгоритми.

---

## 2. Синтаксис

Пълният синтаксис е:
`[capture](parameters) -> return_type { body }`

*   `[]` **Capture clause:** Какви променливи от външния обхват да бъдат достъпни.
*   `()` **Parameters:** Аргументите на функцията (като при нормална функция).
*   `->` **Return type:** (Опционално) Тип на връщаната стойност.
*   `{}` **Body:** Кодът на функцията.

```cpp
auto hello = []() {
    std::cout << "Hello Lambda!\n";
};
hello(); // Извикване
```

---

## 3. Capture Clause (Прихващане)

Ламбдата може да вижда локалните променливи от функцията, в която е дефинирана.

*   `[]`: Нищо не се прихваща.
*   `[=]`: Всичко се прихваща **по стойност** (копие).
*   `[&]`: Всичко се прихваща **по референция** (оригинал).
*   `[x, &y]`: `x` по стойност, `y` по референция.
*   `[=, &y]`: Всичко по стойност, само `y` по референция.

```cpp
int factor = 10;
int total = 0;

// Прихващаме factor по стойност (четене), total по референция (писане)
auto add = [factor, &total](int a) {
    total += a * factor;
};

add(5); // total става 50
```

### Mutable Lambdas
По подразбиране, променливите, прихванати по стойност (`[=]`), са `const` вътре в ламбдата. За да ги променяме (само техните копия), трябва да добавим ключовата дума `mutable`.

```cpp
int x = 10;
auto f = [x]() mutable {
    x++; // Променя локалното копие на x
    std::cout << x; // 11
};
f();
std::cout << x; // 10 (оригиналът не е променен)
```

## 4. Използване със STL Алгоритми

Това е най-голямата сила на ламбдите.

### 4.1. for_each
```cpp
std::vector<int> v = {1, 2, 3, 4, 5};
std::for_each(v.begin(), v.end(), [](int n) {
    std::cout << n * n << " ";
});
```

### 4.2. sort
```cpp
struct Person { std::string name; int age; };
std::vector<Person> people = { {"Bob", 30}, {"Alice", 25} };

// Сортиране по възраст
std::sort(people.begin(), people.end(), [](const Person& a, const Person& b) {
    return a.age < b.age;
});
```

### 4.3. find_if
```cpp
// Намиране на първото четно число
auto it = std::find_if(v.begin(), v.end(), [](int n) {
    return n % 2 == 0;
});
```

## 5. std::function

Ламбда изразите имат уникален, неименуван тип, генериран от компилатора. Ако искаме да съхраним ламбда в променлива с ясен тип или да я подадем като параметър без шаблони, използваме `std::function` от `<functional>`.

```cpp
#include <functional>

// Функция, която приема callback
void execute(std::function<int(int, int)> operation) {
    std::cout << operation(5, 10) << "\n";
}

int main() {
    execute([](int a, int b) { return a + b; }); // 15
    execute([](int a, int b) { return a * b; }); // 50
}
```

*   Заместват нуждата от Functors (класове с `operator()`).
