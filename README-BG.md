# Ключови Концепции в C++

Това хранилище служи като изчерпателен справочник за фундаменталните и напреднали концепции в езика за програмиране C++.

Целта на проекта е да предостави задълбочени обяснения, примери от реалния свят и най-добри практики за всяка разгледана тема. Всяка концепция е обособена в собствена директория, съдържаща подробна документация на български език.
