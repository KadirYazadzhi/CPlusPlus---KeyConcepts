# Време и Файлова Система в C++ - Пълно техническо ръководство

## 1. std::chrono: Прецизност и Типова безопасност

Библиотеката "<chrono>" (C++11) е един от най-добрите примери за силно типизирана система в C++. Тя предотвратява грешки от типа "добавих милисекунди към секунди", като прави такива операции невъзможни за компилация без изрично преобразуване.

В стария C++ (и C) времето беше просто `long` (timestamp). В `std::chrono` времето е **обект**.

### 1.1. Трите стълба на Chrono

1.  **Durations (Продължителност):** Представлява интервал от време (напр. "5 минути").
    *   `std::chrono::seconds`, `std::chrono::milliseconds`.
    *   Можете да събирате различни типове: `auto total = 1min + 5s;` (автоматично става 65s).
    *   Съхранява се като `count` (число) и `ratio` (дробова част, напр. 1/1000 за ms).

2.  **Clocks (Часовници):** Източници на време.
    *   **`system_clock`:** "Стенен часовник" (Wall Clock). Показва реалното астрономическо време. Може да бъде променян от потребителя или NTP сървър (т.е. може да се върне назад!). Не е подходящ за измерване на интервали.
    *   **`steady_clock`:** Монотонен часовник. Никога не се връща назад. Гарантирано "тиктака" с постоянна скорост (напр. време от рестартиране на PC). Това е **единственият правилен избор** за `Stopwatch` (хронометър).
    *   **`high_resolution_clock`:** Часовник с най-малкия възможен тик (често е `steady_clock` под капака).

3.  **Time Points (Времеви точки):** Конкретен момент от време спрямо епохата.
    *   `time_point = clock::now();`
    *   `duration = end - start;`

### 1.2. Преобразуване (Duration Cast)
Когато искате да превърнете секунди в милисекунди, става автоматично (няма загуба на данни).
Когато искате обратното (ms -> sec), трябва да сте експлицитни, защото има загуба (закръгляне).

```cpp
auto ms = 1500ms;
// auto s = ms; // ГРЕШКА!
auto s = std::chrono::duration_cast<std::chrono::seconds>(ms); // 1s
```

## 2. std::filesystem: Крос-платформена навигация

Въведена в C++17, библиотеката "<filesystem>" слага край на мъките с `MAX_PATH`, `opendir` и разликата между `/` и `\`. Тя осигурява обектно-ориентиран интерфейс към файловата система.

### 2.1. Обектът `std::filesystem::path`
Това е сърцето на библиотеката. Той не е просто низ.
*   **Парсване:** Разбира `C:\Windows\System32` и `/usr/bin` еднакво.
*   **Конкатенация:** Използва оператор `/`.
    ```cpp
    path p = "folder";
    p /= "subfolder"; // Добавя правилния разделител автоматично
    p /= "file.txt";
    ```
*   **Методи:** `stem()` (име без разширение), `extension()`, `parent_path()`.

### 2.2. Манипулация и Запитвания
*   `exists(p)`: Проверка дали файлът съществува.
*   `is_directory(p)` / `is_regular_file(p)`.
*   `create_directory(p)`: Създава папка (връща false, ако вече съществува).
*   `copy(src, dest, options)`: Мощно копиране (рекурсивно, overwrite).
*   `remove(p)` / `remove_all(p)`: Триене (all е еквивалент на `rm -rf`).

### 2.3. Рекурсивно обхождане (Directory Iterator)
Преди C++17, рекурсивното обхождане изискваше 50 реда код. Сега:

```cpp
namespace fs = std::filesystem;
for (auto const& entry : fs::recursive_directory_iterator(".")) {
    if (entry.is_regular_file() && entry.path().extension() == ".cpp") {
        std::cout << entry.file_size() << " bytes\n";
    }
}
```

## 3. Професионално обобщение

1.  **Chrono:** Използвайте `steady_clock` за performance тестове. Използвайте `system_clock` само ако трябва да покажете дата на потребителя.
2.  **Filesystem:** Никога не манипулирайте пътища като `std::string` (търсене на запетаи и т.н.). Винаги ползвайте `std::filesystem::path`.
3.  **Ексешъни:** Функциите във filesystem хвърлят изключения при грешка (напр. Access Denied). Имат и `nothrow` версии, които приемат `std::error_code&` като параметър.
