# Функции (Functions) в C++

## 1. Въведение

Функциите са градивните блокове на всяка C++ програма. Те представляват именувани блокове от код, които изпълняват специфична задача. Използването на функции позволява:
*   **Модулност:** Разделяне на сложни проблеми на по-малки, управляеми части.
*   **Повторна употреба:** Един път написан код може да се вика многократно от различни места.
*   **Абстракция:** Скриване на детайлите на имплементацията (знаем *какво* прави функцията, без да е нужно да знаем *как* го прави).

---

## 2. Структура на Функция

Една функция в C++ се състои от заглавна част (signature/prototype) и тяло (body).

```cpp
//   Връщан тип   Име      Параметри
//      |          |           |
//      v          v           v
       int        sum(int a, int b) {
           // Тяло на функцията
           int result = a + b;
           return result; // Връщане на стойност
       }
```

### 2.1. Декларация vs Дефиниция
*   **Декларация (Прототип):** Съобщава на компилатора за съществуването на функцията, нейното име, параметри и връщан тип. Обикновено се слага в заглавни файлове (`.h`).
    ```cpp
    int sum(int a, int b); // Точка и запетая накрая
    ```
*   **Дефиниция:** Съдържа реалния код (имплементацията).
    ```cpp
    int sum(int a, int b) { return a + b; }
    ```

## 3. Видове Параметри

### 3.1. Предаване по Стойност (Pass by Value)
Това е стандартният начин. Създава се **копие** на аргумента. Промените във функцията **не се отразяват** на оригиналната променлива.

```cpp
void modify(int x) {
    x = 10; // Променя само локалното копие
}
```

### 3.2. Предаване по Референция (Pass by Reference)
Използва се амперсанд `&`. Функцията работи директно с оригиналната променлива. Използва се за модификация или за избягване на копиране на тежки обекти.

```cpp
void modify(int& x) {
    x = 10; // Променя оригинала
}
```

### 3.3. Предаване по Константна Референция (Pass by const Reference)
Най-добрият начин за предаване на големи обекти (като `std::string`, `std::vector`), които не трябва да бъдат променяни. Пести памет (няма копиране) и е безопасно (read-only).

```cpp
void printMessage(const std::string& msg) {
    std::cout << msg << std::endl;
}
```

### 3.4. Default Arguments (Параметри по подразбиране)
Можем да зададем стойности по подразбиране, които се използват, ако извикващият пропусне аргумента. Те трябва да са винаги последни в списъка.

```cpp
void greet(std::string name, std::string title = "Mr./Ms.") {
    std::cout << "Hello, " << title << " " << name << std::endl;
}

// greet("John"); -> Hello, Mr./Ms. John
// greet("Jane", "Dr."); -> Hello, Dr. Jane
```

## 4. Връщане на Стойности

### 4.1. Връщане по стойност
Стандартният начин. Връща копие на резултата.

### 4.2. Void функции
Функции, които не връщат нищо (`void`). Използват се за извършване на действие (печатане, запис във файл). Може да се използва `return;` за ранен изход.

### 4.3. Връщане на множество стойности
В C++ функциите могат да връщат само едно нещо. За да върнем повече, можем да използваме:
*   Референции като изходни параметри.
*   `std::pair` или `std::tuple`.
*   Структура (`struct`).

```cpp
#include <tuple>
std::tuple<int, int> getCoordinates() {
    return {10, 20};
}
// Извикване (C++17 structured binding):
// auto [x, y] = getCoordinates();
```

## 5. Function Overloading (Претоварване на функции)

C++ позволява да имаме няколко функции с **едно и също име**, стига списъкът им с параметри (брой или тип) да е различен. Типът на връщаната стойност не участва в разграничаването.

```cpp
int area(int side) { return side * side; } // Квадрат
int area(int w, int h) { return w * h; }   // Правоъгълник
double area(double r) { return 3.14 * r * r; } // Кръг
```

Компилаторът решава коя функция да извика на базата на подадените аргументи.

## 6. Inline Функции

Ключовата дума `inline` подсказва на компилатора да замести извикването на функцията с тялото ѝ директно в кода. Това елиминира overhead-а (забавянето) от извикването на функция, но увеличава размера на изпълнимия файл. Подходящо за много кратки функции (getters/setters).

```cpp
inline int max(int a, int b) {
    return (a > b) ? a : b;
}
```

---

## 7. Function Templates (Шаблони на функции)

Ако искаме една функция да работи с различни типове данни, използваме шаблони (Generic programming).

```cpp
template <typename T>
T add(T a, T b) {
    return a + b;
}

// Работи за int, double, float и т.н.
// add<int>(5, 10);
// add<double>(5.5, 2.3);
```

---

## 8. Lambda Функции (Анонимни функции) - C++11

Ламбда изразите позволяват дефиниране на функции директно на мястото, където се използват (inline), често като аргументи на други функции (напр. при сортиране).

Синтаксис: `[capture](parameters) -> return_type { body }`

```cpp
#include <vector>
#include <algorithm>
#include <iostream>

int main() {
    std::vector<int> nums = {4, 1, 3, 5, 2};
    
    // Сортиране в низходящ ред с ламбда
    std::sort(nums.begin(), nums.end(), [](int a, int b) {
        return a > b; 
    });

    // Capture example
    int multiplier = 10;
    auto times = [multiplier](int a) { return a * multiplier; };
    std::cout << times(5); // 50
}
```

*   `[]`: Нищо не се прихваща от външния обхват.
*   `[=]`: Всички външни променливи се прихващат по стойност (копие).
*   `[&]`: Всички външни променливи се прихващат по референция.
*   `[x, &y]`: `x` по стойност, `y` по референция.

## 9. Рекурсивни Функции

Функция, която извиква сама себе си. Задължително трябва да има **базов случай** (base case), който да прекрати рекурсията, иначе ще настъпи препълване на стека (Stack Overflow).

(Подробно е разгледано в тема 17: Рекурсия).

## 10. Статични променливи във функции

Променлива, декларирана като `static` вътре във функция, се инициализира само веднъж и запазва стойността си между отделните извиквания на функцията.

```cpp
void counter() {
    static int count = 0;
    count++;
    std::cout << count << " ";
}

// counter(); -> 1
// counter(); -> 2
// counter(); -> 3
```

## 11. Обобщение

*   Функциите са от съществено значение за чист и поддържан код.
*   Разбирането на механизмите за предаване на параметри (Value vs Reference) е критично за производителността.
*   Модерният C++ разчита силно на Templates и Lambda функции за гъвкавост.
*   Винаги разделяйте декларацията от дефиницията при големи проекти.
