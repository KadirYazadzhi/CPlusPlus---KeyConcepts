# Функции (Functions) в C++ - Пълно ръководство

## 1. Архитектура на функциите
Функцията е самостоятелен блок от код, който изпълнява специфична логическа задача. В C++ функциите са основният инструмент за постигане на модулност и преизползваемост на кода.

### 1.1. Декларация vs Дефиниция
*   **Декларация (Прототип):** Съобщава на компилатора името, типа на връщания резултат и параметрите. Обикновено се намира в хедър файловете (.h).
*   **Дефиниция:** Съдържа реалната имплементация на кода.

---

## 2. Механизми за предаване на параметри

Това е една от най-критичните части за производителността в C++.

### 2.1. Предаване по стойност (Pass by Value)
Създава се локално копие на обекта. Подходящо само за малки типове (int, double, char).
```cpp
void swap(int a, int b); // Копията се разменят, оригиналите остават същите
```

### 2.2. Предаване по референция (Pass by Reference)
Използва се `&`. Функцията работи директно с оригинала.
```cpp
void increment(int& val) { val++; }
```

### 2.3. Предаване по константна референция (Pass by Const Reference)
**Златното правило на C++:** Предавайте големи обекти (string, vector, класове) чрез `const T&`. Избягва копирането и гарантира безопасност.
```cpp
void printData(const std::vector<int>& data); 
```

### 2.4. Предаване чрез указател (Pass by Pointer)
Използва се, когато аргументът е опционален (може да бъде `nullptr`).

## 3. Разширени концепции

### 3.1. Функционално претоварване (Function Overloading)
Можете да имате функции с едно и също име, но различни параметри. Компилаторът ги различава чрез процес, наречен **Name Mangling**.

### 3.2. Параметри по подразбиране (Default Arguments)
```cpp
void log(string msg, int level = 1); 
// Може да се вика като log("Hi") или log("Hi", 2)
```

### 3.3. Inline функции
Ключовата дума `inline` е молба към компилатора да замести извикването на функцията с нейния код, за да се спести overhead от стека.

---

## 4. Ламбда изрази (Lambda Expressions) - C++11/14/17/20

Ламбдите са анонимни обекти-функции. Те промениха начина, по който пишем модерен C++.

### 4.1. Синтаксис на Capture Clause
*   `[]` - нищо не се прихваща.
*   `[=]` - прихващане на всички локални променливи по стойност.
*   `[&]` - прихващане по референция.
*   `[x, &y]` - x по стойност, y по референция.

```cpp
auto multiplier = [factor = 10](int val) { return val * factor; };
```

## 5. Функционални обекти и std::function

Библиотеката `<functional>` ни позволява да третираме функциите като обекти.

```cpp
#include <functional>
std::function<int(int, int)> op;
op = [](int a, int b) { return a + b; };
```

---

## 6. Рекурсия и Call Stack

Всяко извикване на функция създава **Stack Frame** в паметта, който съдържа:
1.  Локални променливи.
2.  Параметри.
3.  Адрес за връщане.

⚠️ **Tail Call Optimization (TCO):** Някои компилатори могат да оптимизират рекурсията до цикъл, ако рекурсивното извикване е последното нещо във функцията.

---

## 7. Най-добри практики

1.  **Принцип на единствената отговорност:** Една функция трябва да прави само едно нещо.
2.  **Дължина:** Ако функцията е над 50-100 реда, вероятно трябва да се раздели.
3.  **Const Correctness:** Маркирайте методи, които не променят обекта, като `const`.
4.  **Noexcept:** Използвайте `noexcept` за функции, които гарантирано не хвърлят грешки (подобрява скоростта).
