# Многонишково Програмиране (Multithreading) в C++ - Пълно ръководство

## 1. Въведение: Конкурентност и Паралелизъм
В модерните компютърни системи процесорите имат множество ядра. Многонишковото програмиране позволява на една програма да изпълнява няколко задачи едновременно, като по този начин използва пълния капацитет на хардуера. От C++11 насам, езикът има стандартна библиотека за работа с нишки (`<thread>`).

---

## 2. Създаване на нишки (std::thread)
Нишката се стартира веднага щом създадем обект от тип `std::thread` и му подадем функция или ламбда израз.

```cpp
#include <thread>

void task() { /* работа */ }

int main() {
    std::thread t1(task);
    t1.join(); // Изчакваме нишката да приключи
}
```

### 2.1. Join и Detach
*   **join():** Блокира изпълнението на главната нишка, докато дъщерната не приключи.
*   **detach():** Позволява на нишката да работи самостоятелно във фонов режим.

---

## 3. Проблеми при споделени данни (Race Conditions)
Когато две или повече нишки се опитват да променят една и съща променлива едновременно, се получава **Data Race** – състояние, при което крайният резултат зависи от случайността.

### 3.1. Синхронизация с std::mutex
Мутексът (Mutual Exclusion) е механизъм, който позволява само на една нишка да достъпва даден блок код в даден момент.

```cpp
#include <mutex>
std::mutex mtx;
int counter = 0;

void safe_increment() {
    std::lock_guard<std::mutex> lock(mtx); // Автоматично заключва и отключва (RAII)
    counter++;
}
```

---

## 4. Асинхронни задачи (std::async и futures)
Ако искаме да получим резултат от нишка по-късно, използваме `std::async`. Той връща `std::future`, който ще съдържа стойността, когато тя е готова.

```cpp
#include <future>
std::future<int> result = std::async(std::launch::async, []() { return 42; });
int val = result.get(); // Блокира, докато резултатът не е готов
```

---

## 5. Атомарни операции (std::atomic)
За прости типове като `int` или `bool`, мутексите могат да бъдат твърде бавни. `std::atomic` предоставя ниско ниво синхронизация, която се изпълнява директно от процесора без заключване.

---

## 6. Deadlocks (Мъртва хватка)
Това се случва, когато нишка А чака ресурс, държан от нишка Б, а нишка Б чака ресурс, държан от нишка А. Програмата замръзва завинаги. Винаги използвайте `std::scoped_lock` (C++17) за заключване на множество мутекси едновременно.
