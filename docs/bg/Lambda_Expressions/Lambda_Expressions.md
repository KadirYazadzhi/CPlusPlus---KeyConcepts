# Ламбда Изрази (Lambda Expressions) в C++ - Пълно ръководство

## 1. Въведение: Анонимните функции
Ламбда изразите (въведени в C++11) са един от най-мощните инструменти на модерния C++. Те позволяват дефиниране на анонимни функции (функции без име) директно на мястото, където се използват. Това прави кода по-компактен и лесен за четене, особено при работа с алгоритми.

---

## 2. Синтаксис на Ламбда израза

`[ capture ] ( params ) -> return_type { body }`

1.  **Capture Clause `[]`:** Дефинира кои променливи от външния обхват ще бъдат достъпни вътре в ламбдата.
2.  **Parameter List `()`:** Аргументите на функцията.
3.  **Return Type `->`:** (Опционално) Тип на връщания резултат. Обикновено компилаторът го отгатва сам.
4.  **Body `{}`:** Кодът на функцията.

---

## 3. Прихващане на променливи (Capture)

Това е най-уникалната част на ламбдите.
*   `[]` - нищо не се прихваща.
*   `[=]` - прихващане на всички локални променливи **по стойност** (copy).
*   `[&]` - прихващане на всички локални променливи **по референция**.
*   `[x, &y]` - `x` по стойност, `y` по референция.

---

## 4. Mutable Lambdas
По подразбиране, променливите прихванати по стойност са константни вътре в ламбдата. Ако искате да ги променяте (локалните им копия), трябва да добавите ключовата дума `mutable`.

```cpp
int x = 10;
auto f = [x]() mutable { x++; return x; };
```

---

## 5. Употреба със STL Алгоритми
Ламбдите са перфектни за предикати в алгоритми като `std::sort`, `std::find_if`, `std::for_each`.

```cpp
std::vector<int> v = {1, 5, 2, 4, 3};
std::sort(v.begin(), v.end(), [](int a, int b) {
    return a > b; // Сортиране в низходящ ред
});
```

---

## 6. Generics (C++14)
От C++14 можете да използвате `auto` за параметрите на ламбдата, превръщайки я в "шаблонна" ламбда.

```cpp
auto generic_add = [](auto a, auto b) { return a + b; };
```
