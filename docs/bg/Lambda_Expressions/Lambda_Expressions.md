# Ламбда Изрази (Lambda Expressions) - Пълно техническо ръководство

## 1. Въведение: Функции без имена

Ламбда изразите (въведени в C++11) са един от най-въздействащите инструменти на модерния C++. Те позволяват дефиниране на анонимни обекти-функции (**Closure**) директно на мястото, където се използват. Това промени парадигмата на езика към по-функционално програмиране, позволявайки по-чист и експресивен код при работа с алгоритми и асинхронни задачи.

---

## 2. Анатомия на Ламбда израза

Синтаксисът се състои от четири основни части:
`[ capture ] ( params ) mutable exception -> return_type { body }`

### 2.1. Capture Clause `[]` (Механизъм за прихващане)
Това е най-уникалната част на ламбдите в C++. Тя позволява на функцията да "вижда" и използва променливи от външния обхват (Scope).

*   `[]`: **Stateless Lambda**. Не вижда нищо отвън. Може да се конвертира до обикновен `function pointer`.
*   `[=]`: **Copy Capture**. Всички използвани локални променливи се копират вътре в ламбдата. Безопасно, но може да е скъпо за големи обекти.
*   `[&]`: **Reference Capture**. Всички променливи се достъпват по референция. Бързо, но опасно (виж "Dangling References").
*   `[x, &y]`: Смесено прихващане. `x` по стойност, `y` по референция.
*   `[this]`: Позволява достъп до членовете на класа. В C++20 е препоръчително да ползвате `[*this]`, ако искате да копирате целия обект.

### 2.2. Mutable Lambdas
По подразбиране, операторът `()` на ламбдата е `const`. Това означава, че не можете да променяте променливи, прихванати по стойност.
```cpp
int counter = 0;
auto f = [counter]() mutable { 
    counter++; // Възможно само заради mutable. Променя се вътрешното копие.
    return counter; 
};
```

## 3. Как работи? (Compiler Implementation)

Когато напишете ламбда, компилаторът тайно генерира уникален, неименуван клас (**Closure Type**).

**Вашият код:**
```cpp
int factor = 10;
auto lambda = [factor](int n) { return n * factor; };
```

**Какво вижда компилаторът:**
```cpp
class __Lambda_Unique_Name {
    int _factor; // Копие на прихванатата променлива
public:
    __Lambda_Unique_Name(int f) : _factor(f) {}
    
    int operator()(int n) const {
        return n * _factor;
    }
};
```
Това обяснява защо ламбдите са толкова бързи – те са инлайнати обекти, а не указатели към функции.

## 4. Генерични Ламбди (C++14) и constexpr (C++17)

### 4.1. `auto` параметри
От C++14 ламбдите станаха шаблони.
```cpp
auto sum = [](auto a, auto b) { return a + b; };
```
Това генерира клас с темплейтен `operator()`. Можете да извикате `sum(1, 2)` и `sum(std::string("a"), "b")` с една и съща ламбда.

### 4.2. IIFE (Immediately Invoked Function Expression)
Техника, заимствана от JavaScript, за инициализация на константи със сложна логика.
```cpp
const int result = [&](){
    int val = calculate();
    if (val < 0) return 0;
    return val * 2;
}(); // Извиква се веднага!
```

## 5. Ламбди срещу `std::function`

Това е важна оптимизация.
*   **`auto f = [](){};`**: Нулев overhead. Компилаторът знае точния тип.
*   **`std::function<void()> f = [](){};`**: Има overhead. Използва Type Erasure, виртуални извиквания и често заделя памет в Heap-а.
**Съвет:** Използвайте `std::function` само ако трябва да съхраните ламбдата в контейнер (напр. `vector<function>`). Иначе ползвайте `template` или `auto`.

---

## 6. Професионални опасности: Dangling References

Най-честият бъг при асинхронен код:
```cpp
std::function<void()> getPrinter() {
    std::string text = "Hello";
    // ГРЕШКА! 'text' умира в края на функцията.
    // Ламбдата държи референция към мъртва памет.
    return [&text](){ std::cout << text; }; 
}
```
**Златно правило:** Ако ламбдата ще надживее обхвата, в който е създадена (напр. предава се на Thread или Task Queue), **ВИНАГИ** прихващайте по стойност `[=]` или използвайте smart pointers.

---

## 7. Професионално обобщение

1.  **Алгоритми:** Ламбдите са естественият партньор на STL алгоритмите (`sort`, `find_if`).
2.  **Move Capture (C++14):** Можете да местите обекти в ламбдата: `[ptr = std::move(unique_ptr)](){...}`.
3.  **Размер:** Ламбда без captures заема 1 байт (празен клас). Ламбда с captures заема размера на прихванатите данни.
4.  **Readability:** Ползвайте ги за кратки парчета код. Ако ламбдата стане над 5 реда, по-добре напишете нормален метод или функтор.
