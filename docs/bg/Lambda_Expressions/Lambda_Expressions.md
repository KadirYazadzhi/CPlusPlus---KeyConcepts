# Ламбда Изрази (Lambda Expressions) - Пълно техническо ръководство

## 1. Въведение: Функционалната революция в C++

Въвеждането на ламбда изрази в C++11 беше повратен момент. То трансформира езика от стриктно обектно-ориентиран и императивен към език, който поддържа мощни функционални парадигми.
Ламбдата е **анонимна функция**, която може да бъде дефинирана "на място" (inline), точно там, където е нужна. Тя може да "прихваща" (capture) променливи от околния контекст, превръщайки се в **Closure** (Затворена функция).

Преди ламбдите, за да сортираме вектор по специфичен начин, трябваше да пишем отделен функтор (клас с `operator()`) някъде далеч в кода. Сега го правим на един ред.

## 2. Анатомия на Ламбдата

Синтаксисът изглежда плашещ в началото, но е много логичен:
`[capture](params) specifiers -> return_type { body }`

### 2.1. Capture Clause (`[]`)
Това е "магията". Тук описваме кои променливи от външния свят са достъпни вътре.
*   `[]`: Нищо. (Чиста функция).
*   `[x, y]`: Прихваща `x` и `y` по стойност (копира ги).
*   `[&x]`: Прихваща `x` по референция (може да го променя).
*   `[=]`: Прихваща всичко използвано по стойност.
*   `[&]`: Прихваща всичко използвано по референция.
*   `[this]`: Прихваща текущия обект (за достъп до методи).

⚠️ **Опасност:** Прихващането по референция `[&]` е опасно, ако ламбдата надживее обхвата на променливите (Dangling Reference). Например, ако върнете такава ламбда от функция, тя ще сочи към унищожения стек.

### 2.2. Mutable
По подразбиране, прихванатите по стойност променливи са `const`. Ламбдата не може да ги променя.
Ключовата дума `mutable` премахва това ограничение.
```cpp
int counter = 0;
auto f = [counter]() mutable { return ++counter; };
// counter във f е копие. Външният counter си остава 0.
```

## 3. Generic Lambdas (C++14) и `auto`

В C++14 ламбдите станаха още по-мощни. Параметрите могат да бъдат `auto`.
Това на практика превръща ламбдата в шаблон (Template) на функция.

```cpp
auto print = [](auto x) {
    std::cout << x << "\n";
};

print(5);           // Компилира се версия за int
print("Hello");     // Компилира се версия за const char*
print(std::vector{1}); // Компилира се версия за vector
```
Това е основата на модерните generic алгоритми.

## 4. Функционални патерни: Map, Filter, Reduce

Ламбдите правят работата с колекции декларативна.

### Map (Transform)
```cpp
std::vector<int> nums = {1, 2, 3};
std::transform(nums.begin(), nums.end(), nums.begin(), 
               [](int n) { return n * n; }); // Повдигане на квадрат
```

### Filter (Copy If)
```cpp
std::vector<int> evens;
std::copy_if(nums.begin(), nums.end(), std::back_inserter(evens),
             [](int n) { return n % 2 == 0; }); // Само четните
```

### Reduce (Accumulate)
```cpp
int sum = std::accumulate(nums.begin(), nums.end(), 0, 
                          [](int acc, int n) { return acc + n; });
```

## 5. IIFE (Immediately Invoked Function Expression)

Това е идиом, зает от JavaScript. Дефинирате ламбда и я извиквате веднага.
Полезно е за инициализация на `const` променливи със сложна логика.

```cpp
// Искаме статусът да е константа, но логиката изисква if-else
const std::string status = [&]() {
    if (!isConnected) return "Disconnected";
    if (hasError) return "Error";
    return "Ready";
}(); // () накрая извиква ламбдата
```
Без IIFE, `status` не би могъл да е `const` или трябваше да пишем отделна функция.

## 6. Какво е ламбдата "под капака"?

Компилаторът превръща всеки ламбда израз в уникален, безименен клас (Closure Type).
*   Capture променливите стават член-данни на класа (полета).
*   Тялото на ламбдата става `operator()` (метод).
*   Ако няма capture (`[]`), класът може да се конвертира до обикновен C-style function pointer.

Затова типа на ламбдата не е известен. Трябва да ползваме `auto` или `std::function` (ако искаме да я съхраним).

## 7. Професионално обобщение

1.  **Краткост:** Използвайте ламбди за кратка логика (1-3 реда), която е специфична за дадено място. Ако логиката е сложна, направете истинска функция или named object.
2.  **std::bind:** Забравете за `std::bind`. Ламбдите го заместват напълно – те са по-четими, по-гъвкави и по-бързи (компилаторът ги инлайнва по-добре).
3.  **Move Capture:** C++14 позволява `[p = std::move(ptr)]`. Това е единственият начин да вкарате `unique_ptr` в ламбда (защото той не може да се копира).
