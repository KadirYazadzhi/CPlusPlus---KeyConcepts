# Шаблони (Templates) в C++ - Пълно ръководство

## 1. Концепция: Обобщено програмиране
Шаблоните са основата на **Generic Programming** в C++. Те ни позволяват да пишем код веднъж и той да работи с всякакви типове данни (int, double, стрингове или потребителски класове).

---

## 2. Шаблони на функции (Function Templates)
Вместо да пишем отделни функции `add(int, int)` и `add(double, double)`, пишем един шаблон.

```cpp
template <typename T>
T add(T a, T b) {
    return a + b;
}
```

---

## 3. Шаблони на класове (Class Templates)
STL контейнерите като `std::vector<T>` са най-добрият пример за шаблонни класове.

---

## 4. Как работи? (Instantiating)
Шаблоните не се компилират веднага. Компилаторът генерира специфичен код за всеки тип, с който извикате шаблона. Този процес се нарича **Instantiating**.

⚠️ **ВНИМАНИЕ:** Тъй като компилаторът трябва да вижда цялата дефиниция на шаблона, за да генерира код, обикновено шаблоните се пишат изцяло в **хедър файловете (.h)**.

---

## 5. Шаблонна Специализация (Specialization)
Понякога искате даден тип да се държи по-различно. Можете да напишете специфична версия на шаблона за конкретен тип.

```cpp
template <>
class Box<bool> {
    // Оптимизирана версия за булеви стойности
};
```

---

## 6. Вариадични Шаблони (Variadic Templates)
Въведени в C++11, те позволяват на шаблоните да приемат неограничен брой аргументи (напр. `printf` стил функции).
