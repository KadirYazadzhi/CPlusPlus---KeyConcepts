# Шаблони (Templates) в C++ - Пълно техническо ръководство

## 1. Въведение: Генеричното Програмиране

C++ е уникален с това, че поддържа **Generic Programming** на изключително високо ниво. Шаблоните (Templates) позволяват да напишете код веднъж и той да работи с всякакъв тип данни, стига те да поддържат нужните операции.
Това не е просто "замяна на текст" (като макросите). Това е пълна, Тюринг-пълна система за метапрограмиране, която се изпълнява по време на компилация.

---

## 2. Основни Шаблони

### 2.1. Шаблони на Функции
```cpp
template <typename T>
T max(T a, T b) {
    return (a > b) ? a : b;
}
// Компилаторът генерира отделни функции за int, float, UserClass...
```

### 2.2. Шаблони на Класове
Всички STL контейнери (`vector`, `map`) са шаблонни класове.
```cpp
template <typename T, size_t Size>
class Array {
    T data[Size]; // Размерът е известен по време на компилация!
public:
    T& operator[](size_t i) { return data[i]; }
};

Array<int, 5> myArr; // Всичко е на стека, супер бързо.
```

## 3. Специализация (Specialization)

Понякога искаме общият алгоритъм да работи по различен начин за конкретен тип (напр. `bool` или `char*`).

### 3.1. Пълна Специализация
```cpp
template <> 
const char* max<const char*>(const char* a, const char* b) {
    return (strcmp(a, b) > 0) ? a : b;
}
```

### 3.2. Частична Специализация (Само за класове)
Можем да специализираме само част от параметрите. `std::vector<bool>` е известен пример за частична специализация, която пакетира булевите стойности като битове (1 бит вместо 1 байт).

## 4. Variadic Templates (C++11)

Шаблони, които приемат променлив брой аргументи. Това е основата на `std::tuple`, `std::print` и `std::variant`.

```cpp
// 1. Базов случай (дъно на рекурсията)
void print() { std::cout << "\n"; }

// 2. Рекурсивен случай
template <typename T, typename... Args>
void print(T first, Args... args) {
    std::cout << first << " ";
    print(args...); // Разпакетиране на пакета
}
```

### Fold Expressions (C++17)
Сложи край на сложната рекурсия по-горе.
```cpp
template <typename... Args>
void print(Args... args) {
    (std::cout << ... << args) << "\n"; // Магия!
}
```

## 5. SFINAE и Concepts

Как да ограничим шаблона да работи само за определени типове?

### 5.1. SFINAE (Substitution Failure Is Not An Error) - Старият начин
Механизъм, при който ако даден тип не става за шаблона, компилаторът просто игнорира този шаблон (вместо да даде грешка) и търси друг. Използва се с `std::enable_if`.
```cpp
template <typename T>
typename std::enable_if<std::is_integral<T>::value, T>::type
add(T a, T b) { return a + b; }
```
Изключително грозен и труден за четене синтаксис.

### 5.2. Concepts (C++20) - Новият начин
```cpp
template <std::integral T>
T add(T a, T b) { return a + b; }
```
Това прави същото, но е четимо и дава ясни съобщения за грешки.

## 6. Template Metaprogramming (TMP)

Тъй като шаблоните се разгръщат по време на компилация, можем да ги ползваме за изчисления **преди програмата да стартира**.

```cpp
template <int N>
struct Factorial {
    static const int value = N * Factorial<N - 1>::value;
};

template <>
struct Factorial<0> {
    static const int value = 1;
};

// int x = Factorial<5>::value; // Компилира се директно като "int x = 120;"
```
В модерния C++ това се прави по-лесно с `constexpr` функции, но TMP все още се ползва за манипулация на типове (Type Traits).

---

## 7. Професионални капани

1.  **Code Bloat:** Всяка инстанция на шаблон (`vector<int>`, `vector<float>`, `vector<User>`) генерира **нов машинен код**. Прекаленото използване може драстично да увеличи размера на изпълнимия файл.
2.  **Бавна компилация:** Парсването на сложни шаблони е тежко за компилатора.
3.  **Дебъгване:** Грешките при шаблони преди C++20 (Concepts) могат да бъдат километрични и неразбираеми ("Template Error Hell").

---

## 8. Обобщение

Шаблоните са най-мощното оръжие на C++. Те позволяват създаването на библиотеки като STL, които са едновременно **абсолютно генерични** и **максимално ефективни** (без runtime overhead като виртуални функции или boxing). Овладяването им е задължително за Senior ниво.
