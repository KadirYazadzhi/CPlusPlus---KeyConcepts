# Шаблони (Templates) в C++ - Пълно техническо ръководство

## 1. Въведение: Парадигмата на Генеричното Програмиране
Шаблоните са най-мощният инструмент в арсенала на C++ разработчика. Те позволяват писането на код, който е независим от типа данни (**Generic Programming**). Шаблоните не са код сами по себе си, а са чертежи, по които компилаторът генерира реален код по време на компилация.

---

## 2. Шаблони на Функции (Function Templates)

Вместо да претоварваме една функция десетки пъти за различни типове, дефинираме шаблон:

```cpp
template <typename T>
T maximum(T a, T b) {
    return (a > b) ? a : b;
}
```

### 2.1. Инстанциране (Instantiation)
Когато извикате `maximum(5, 10)`, компилаторът генерира версия за `int`. Ако извикате `maximum(3.14, 2.71)`, генерира версия за `double`. Това се случва в момента на компилация (**Compile-time**), което означава нулев спад в производителността.

---

## 3. Шаблони на Класове (Class Templates)

Позволяват създаването на гъвкави структури от данни. Целият STL (`vector`, `map`, `list`) е изграден върху шаблонни класове.

```cpp
template <typename T>
class Box {
    T data;
public:
    void set(T val) { data = val; }
    T get() { return data; }
};
```

---

## 4. Шаблонна Специализация (Template Specialization)

Понякога даден тип изисква специална логика. Например, сравняването на `bool` или на C-style низове (`char*`).

```cpp
// Пълна специализация за тип bool
template <>
class Box<bool> {
    unsigned char data; // Оптимизация на паметта
};
```

---

## 5. Вариадични Шаблони (Variadic Templates) - C++11

Позволяват на шаблона да приема произволен брой аргументи. Това е основата на функции като `std::make_unique` и кортежите `std::tuple`.

```cpp
template<typename... Args>
void printAll(Args... args) {
    (std::cout << ... << args) << std::endl; // Fold expression (C++17)
}
```

---

## 6. Метапрограмиране и SFINAE

Шаблоните са Тюринг-пълни, което означава, че по време на компилация можете да изпълнявате сложни алгоритми.
*   **Type Traits:** Задаване на въпроси към типа (напр. "Това число ли е?").
*   **SFINAE:** Техника за скриване на функции от компилатора, ако типовете не пасват.

---

## 7. Модерен C++: Концепти (Concepts) - C++20

Концептите решиха най-големия проблем на шаблоните – неразбираемите грешки. Сега можем изрично да кажем: "Този шаблон приема само типове, които са сравними".

```cpp
template <std::integral T>
void onlyInts(T val) { /* ... */ }
```

---

## 8. Професионално обобщение
*   Шаблоните осигуряват **максимална скорост** (защото всичко е пресметнато предварително).
*   Винаги пишете шаблоните в **хедър файлове**.
*   Внимавайте за **Code Bloat** (прекомерно увеличаване на размера на изпълнимия файл при много инстанцирания).
