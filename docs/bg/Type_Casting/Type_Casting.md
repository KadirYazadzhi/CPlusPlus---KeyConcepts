# Преобразуване на Типове (Type Casting) в C++ - Пълно ръководство

## 1. Въведение: Защо C-style кастването е опасно?
В езика C преобразуването на типове става чрез синтаксиса `(type)value`. В C++ това все още работи, но се счита за **лоша практика**. C-style кастването е твърде мощно и неясно – то може да се държи като `static_cast`, `const_cast` или `reinterpret_cast` едновременно, което крие риск от грешки, трудни за откриване.

C++ въвежда четири специфични оператора за кастване, които са по-сигурни и по-лесни за търсене в сорс кода.

---

## 2. static_cast
Това е най-често използваното кастване. Извършва се по време на компилация.

### 2.1. Употреба
*   Преобразуване между базови типове (напр. `float` към `int`).
*   Преобразуване на указатели в йерархия от класове (от наследник към родител – "Upcasting").
*   Извикване на експлицитни конструктори или оператори за преобразуване.

```cpp
double d = 3.14;
int i = static_cast<int>(d); // Безопасно премахване на дробната част
```

---

## 3. dynamic_cast
Използва се изключително за работа с **полиморфни класове** (такива, които имат поне една виртуална функция). Извършва проверка по време на изпълнение (**Runtime**).

### 3.1. Downcasting
Ако имате указател към базов клас и искате да го превърнете в указател към наследник:
*   Ако преобразуването е възможно, връща валиден указател.
*   Ако не е възможно, връща `nullptr`.

```cpp
Base* b = new Derived();
Derived* d = dynamic_cast<Derived*>(b);
if (d) { /* Успех */ }
```

---

## 4. const_cast
Единственият оператор, който може да премахва или добавя `const` квалификатора.

⚠️ **ВНИМАНИЕ:** Промяната на променлива, която е дефинирана оригинално като `const`, чрез `const_cast` води до **Undefined Behavior**. Използвайте го само при интеграция със стари библиотеки, които не поддържат `const` параметри, но гарантирано не променят данните.

---

## 5. reinterpret_cast
Най-опасният оператор. Той казва на компилатора: "Третирай тези битове памет като съвсем друг тип". Не извършва никакви проверки и не променя данните, само тяхната интерпретация.

Използва се в ниско ниво програмирането (напр. превръщане на указател в целочислен адрес).

---

## 6. Обобщение
*   Използвайте **static_cast** за нормални преобразувания.
*   Използвайте **dynamic_cast** за безопасна навигация в класови йерархии.
*   Избягвайте **reinterpret_cast**, освен ако не пишете драйвер или софтуер за работа с хардуер.
