# C++ и Python Interop (pybind11) - Пълно техническо ръководство

## 1. Въведение: Защо да комбинираме двата езика?
Python е кралят на продуктивността и изкуствения интелект (AI), но е бавен. C++ е кралят на производителността, но е труден за бързо прототипиране. Професионалният софтуер често използва **хибриден модел**: Python за логиката от високо ниво и C++ за изчисленията.

Библиотеката **pybind11** е модерният стандарт за създаване на Python модули на C++.

---

## 2. Как работи pybind11?

pybind11 е "header-only" библиотека, която използва шаблонна магия, за да превърне C++ типовете в Python обекти автоматично.

### 2.1. Базов пример
```cpp
#include <pybind11/pybind11.h>

int add(int i, int j) { return i + j; }

// Дефиниране на модула
PYBIND11_MODULE(example, m) {
    m.doc() = "pybind11 example plugin";
    m.def("add", &add, "A function which adds two numbers");
}
```

---

## 3. Предаване на данни: STL и Numpy

### 3.1. Автоматична конверсия на STL
pybind11 автоматично превръща `std::vector` в Python `list`, `std::map` в `dict` и `std::string` в `str`. Това обаче изисква копиране на данните.

### 3.2. Нулев overhead с Numpy
Ако работите с AI (TensorFlow, PyTorch), ще използвате **Numpy**. pybind11 позволява на C++ да достъпва Numpy масиви директно в паметта без копиране (**zero-copy**).

---

## 4. Капсулиране на класове (Binding Classes)

Можете да превърнете цял C++ клас в Python клас:
```cpp
py::class_<Pet>(m, "Pet")
    .def(py::init<const std::string &>())
    .def("setName", &Pet::setName)
    .def_property("name", &Pet::getName, &Pet::setName);
```

---

## 5. GIL (Global Interpreter Lock)

⚠️ **КРИТИЧНО ЗА ПРОФЕСИОНАЛИСТИ:** Python има GIL, който позволява само една нишка да изпълнява Python код едновременно. Когато C++ кодът ви извършва тежки изчисления, вие трябва да **освободите GIL**, за да позволите на Python да работи паралелно.

```cpp
py::gil_scoped_release release; // Python може да работи в други нишки сега
// Тежки C++ изчисления тук
py::gil_scoped_acquire acquire; // Връщаме контрола
```

## 6. Професионално обобщение
*   Използвайте **pybind11**, вместо стария Python C API.
*   Винаги освобождавайте GIL при тежки задачи.
*   Използвайте **Numpy интеграцията** за висока производителност при работа с вектори и матрици.
*   Хибридният модел (C++ Core + Python API) е тайната на успеха на библиотеки като **NumPy, Scipy и TensorFlow**.
