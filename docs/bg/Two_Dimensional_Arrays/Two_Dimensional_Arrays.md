# Двумерни Масиви (2D Arrays) в C++ - Пълно техническо ръководство

## 1. Въведение: Представяне на матрици
Двумерният масив (матрица) е инструментът, с който описваме структури от тип редове и колони. В C++ разбирането на това как тези данни се съхраняват във физическата памет е разликата между работещия софтуер и **високопроизводителния** софтуер.

---

## 2. Моделът "Row-Major Order" (Ред след ред)

⚠️ **КЛЮЧОВА КОНЦЕПЦИЯ:** Паметта на компютъра е линейна (едноизмерна). Двумерният масив не е физическа таблица в RAM паметта. C++ подрежда елементите един след друг, ред по ред.

Ако имаме `int a[2][3]`, в паметта те изглеждат така:
`[ред0,кол0], [ред0,кол1], [ред0,кол2], [ред1,кол0], [ред1,кол1], [ред1,кол2]`

### 2.1. Математическата формула за достъп
За да намери елемента `a[i][j]`, компилаторът не търси в таблица. Той изпълнява една аритметична операция:
`Адрес = Начало + (i * Брой_Колони + j) * sizeof(Тип)`

Това обяснява защо при подаване на масив на функция, **задължително** трябва да посочите броя на колоните. Без това число, компилаторът не знае колко голям е един "ред" и не може да "прескочи" до следващия.

---

## 3. Декларация и Инициализация (Всички варианти)

### 3.1. Статична (Stack)
```cpp
int matrix[3][3] = {
    {1, 2, 3}, // Ред 0
    {4, 5, 6}, // Ред 1
    {7, 8, 9}  // Ред 2
};
```

### 3.2. Динамична (Heap) - Сложен вариант
За истински динамична матрица използваме указател към масив от указатели:
```cpp
int** matrix = new int*[rows]; // Масив от указатели към редове
for(int i = 0; i < rows; ++i) {
    matrix[i] = new int[cols]; // Заделяне на всеки ред
}

// Освобождаване (В обратен ред!)
for(int i = 0; i < rows; ++i) delete[] matrix[i];
delete[] matrix;
```
⚠️ **Проблем:** Този метод е **бавен**, защото редовете са пръснати в паметта и убиват кеша на процесора.

---

## 4. Оптимизация: Traversal и Cache Locality

Начинът, по който обхождате матрицата, може да промени скоростта на кода ви **стотици пъти**.

### 4.1. Cache-friendly (Бързо)
Винаги обхождайте първо редовете, после колоните:
```cpp
for(int i = 0; i < rows; ++i)
    for(int j = 0; j < cols; ++j)
        sum += matrix[i][j]; // Четем паметта последователно.
```

### 4.2. Cache-hostile (Бавно)
Обхождането по колони (външен цикъл колони) е пагубно за скоростта:
```cpp
for(int j = 0; j < cols; ++j)
    for(int i = 0; i < rows; ++i)
        sum += matrix[i][j]; // Прескачаме паметта. CPU чака RAM паметта.
```

---

## 5. Професионално решение: Flattening (Плоска матрица)
В високопроизводителните системи (игри, AI) рядко се ползва `int**`. Вместо това се ползва един 1D масив, който се третира като 2D:
```cpp
std::vector<int> flat_matrix(rows * cols);
// Достъп до (ред i, колона j):
int value = flat_matrix[i * cols + j];
```
**Защо?** Само една алокация, непрекъсната памет, максимална скорост.

---

## 6. Двумерни масиви и Функции
При подаване на 2D масив на функция, трябва да укажете размера на второто измерение (колоните).
```cpp
void print(int arr[][3], int rows); // OK
// void print(int arr[][], int rows); // ГРЕШКА!
```

---

## 7. Обобщение
*   Матриците в C++ са **линейни** под капака.
*   **Редът на обхождане** е критичен за скоростта.
*   Използвайте **Flattening** за професионални приложения.
*   Винаги предпочитайте `std::vector<std::vector<T>>` пред сурови указатели, ако не е критично за скоростта.
