# Двумерни Масиви (2D Arrays) в C++

## 1. Въведение

Двумерният масив (2D array) в C++ е най-простата форма на многомерен масив. Най-лесно може да се визуализира като **таблица** или **матрица**, която има редове и колони.

Технически, в C++ двумерният масив е "масив от масиви". Това означава, че всеки елемент на основния масив е сам по себе си друг масив.

---

## 2. Декларация и Инициализация

### 2.1. Декларация
Синтаксисът е: `тип име[брой_редове][брой_колони];`

```cpp
int matrix[3][4]; 
// Декларира матрица с 3 реда и 4 колони.
// Общо 3 * 4 = 12 елемента от тип int.
```

### 2.2. Инициализация
Можем да инициализираме масива по време на декларацията по няколко начина.

**Вариант 1: Вложени скоби (Препоръчително)**
Това е най-четимият начин, който визуално разделя редовете.

```cpp
int matrix[3][3] = {
    {1, 2, 3},  // Ред 0
    {4, 5, 6},  // Ред 1
    {7, 8, 9}   // Ред 2
};
```

**Вариант 2: Линеен списък**
Тъй като паметта е последователна, можем да изброим всички елементи в един списък. Компилаторът ще ги попълни ред по ред.

```cpp
int matrix[2][3] = {1, 2, 3, 4, 5, 6};
// Резултат:
// 1 2 3
// 4 5 6
```

**Вариант 3: Частична инициализация**

```cpp
int matrix[2][2] = {{1}, {2, 3}};
// Резултат:
// 1 0 (неинициализираните стават 0)
// 2 3
```

## 3. Достъп до Елементи

Достъпът се осъществява чрез два индекса: `array[ред][колона]`.

```cpp
int grid[3][3] = {
    {10, 20, 30},
    {40, 50, 60},
    {70, 80, 90}
};

int val = grid[1][2]; // Ред 1, Колона 2 -> Стойност 60
grid[0][0] = 999;     // Променя първия елемент (горе ляво)
```

⚠️ **Важно:** Индексите винаги започват от 0.
*   Редовете са от `0` до `брой_редове - 1`.
*   Колоните са от `0` до `брой_колони - 1`.

---

## 4. Памет и Подредба (Memory Layout)

В C++ двумерните масиви се съхраняват в паметта **Row-Major Order** (по редове). Това означава, че елементите от първия ред са разположени последователно, следвани веднага от елементите на втория ред и т.н.

За масив `mat[2][3]`:
`{ (0,0), (0,1), (0,2), (1,0), (1,1), (1,2) }`

Това е важно за производителността (CPU Cache Locality). При обхождане е по-бързо да се итерира първо по редове (вътрешният цикъл да е по колони).

---

## 5. Обхождане на Двумерен Масив

Стандартният начин за обхождане е чрез **вложени for цикли**.

```cpp
#include <iostream>

int main() {
    int mat[3][2] = {
        {1, 2},
        {3, 4},
        {5, 6}
    };

    // Външен цикъл: Редове
    for (int i = 0; i < 3; i++) {
        // Вътрешен цикъл: Колони
        for (int j = 0; j < 2; j++) {
            std::cout << mat[i][j] << " ";
        }
        std::cout << std::endl; // Нов ред след всеки ред на матрицата
    }

    return 0;
}
```

## 6. Двумерни масиви и Функции

Предаването на двумерен масив на функция има една особеност: **трябва задължително да посочите броя на колоните**. Броят на редовете може да бъде пропуснат (както при едномерните масиви), но броят на колоните е нужен на компилатора, за да изчисли адресите (адресна аритметика).

```cpp
const int COLS = 3;

// Правилно: Колоните са указани
void printMatrix(int matrix[][COLS], int rows) {
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < COLS; j++) {
            std::cout << matrix[i][j] << " ";
        }
        std::cout << std::endl;
    }
}

// Грешно: void func(int matrix[][]) - Компилаторът не знае ширината на реда
```

## 7. Динамични Двумерни Масиви

Ако размерите на матрицата не са известни по време на компилация, трябва да използваме динамична памет. Това е по-сложно и изисква указатели към указатели.

### 7.1. Създаване
```cpp
int rows, cols;
std::cin >> rows >> cols;

// 1. Заделяме масив от указатели (всеки ще сочи към ред)
int** matrix = new int*[rows];

// 2. Заделяме памет за всеки ред
for (int i = 0; i < rows; i++) {
    matrix[i] = new int[cols];
}

// Сега можем да ползваме matrix[i][j] нормално
matrix[0][0] = 5;
```

### 7.2. Освобождаване (Delete)
Трябва да освободим паметта в обратен ред.

```cpp
// 1. Освобождаваме всеки ред
for (int i = 0; i < rows; i++) {
    delete[] matrix[i];
}

// 2. Освобождаваме масива от указатели
delete[] matrix;
```

### 7.3. Модерна алтернатива (std::vector)
Горният код е податлив на грешки (memory leaks). В съвременния C++ е много по-добре да се използва `std::vector` от вектори.

```cpp
#include <vector>

int rows = 5, cols = 5;
// Създава 5x5 матрица, инициализирана с 0
std::vector<std::vector<int>> matrix(rows, std::vector<int>(cols, 0));

matrix[2][3] = 10; // Работи точно като масив, но се грижи за паметта автоматично
```

## 8. Приложение: Умножение на матрици

Класически пример за използване на двумерни масиви.

```cpp
void multiply(int A[2][2], int B[2][2], int C[2][2]) {
    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 2; j++) {
            C[i][j] = 0;
            for (int k = 0; k < 2; k++) {
                C[i][j] += A[i][k] * B[k][j];
            }
        }
    }
}
```

---

## 9. Обобщение

*   Двумерните масиви се използват за таблични данни.
*   Паметта е подредена последователно (ред след ред).
*   При предаване във функция, броят на колоните е задължителен.
*   За динамични матрици, предпочитайте `std::vector<std::vector<T>>` пред `T**`, за да избегнете проблеми с управлението на паметта.
