# Двумерни Масиви (2D Arrays) в C++ - Пълно техническо ръководство

## 1. Въведение: Представяне на многомерни данни
Двумерният масив (матрица) е инструментът, с който описваме структури от тип редове и колони. Въпреки че го визуализираме като таблица, в RAM паметта той е **линеен**. Разбирането на това как C++ "картира" 2D координатите в 1D адреси е разликата между начинаещия и професионалния инженер.

---

## 2. Моделът "Row-Major Order"
C++ използва стандарта **Row-Major Order**. Това означава, че матрицата се съхранява ред след ред.

**Пример:** `int a[2][3]`
В паметта: `[0,0], [0,1], [0,2]` следвани веднага от `[1,0], [1,1], [1,2]`.

### 2.1. Математическата формула за достъп
За да намери елемента `a[i][j]`, компилаторът изпълнява следната логика:
`Адрес = Начало + (i * Брой_Колони + j) * sizeof(Тип)`

⚠️ **ВАЖНО:** Тъй като числото `Брой_Колони` е част от формулата, то **трябва** да бъде известно по време на компилация (или подадено изрично при функциите).

---

## 3. Декларация и Инициализация (Всички варианти)

### 3.1. Статична (Stack)
```cpp
int board[3][3] = {
    {1, 2, 3}, // Ред 0
    {4, 5, 6}, // Ред 1
    {7, 8, 9}  // Ред 2
};
```

### 3.2. Динамична (Heap) - Трудният начин
За истински динамична матрица използваме указател към масив от указатели:
```cpp
int** matrix = new int*[rows]; // Масив от 1D масиви
for(int i = 0; i < rows; ++i) matrix[i] = new int[cols];

// Изтриване (в обратен ред!)
for(int i = 0; i < rows; ++i) delete[] matrix[i];
delete[] matrix;
```
⚠️ **Проблем:** Този метод е **бавен**, защото редовете са пръснати в паметта и убиват кеша на процесора.

---

## 4. Оптимизация: Traversal и Cache Locality
Това е най-важният урок при работа с матрици.

### 4.1. Cache-friendly (Бързо)
Винаги обхождайте вътрешния цикъл по колоните:
```cpp
for(int i = 0; i < rows; ++i)
    for(int j = 0; j < cols; ++j)
        sum += matrix[i][j]; // Четем паметта последователно (1, 2, 3, 4...)
```

### 4.2. Cache-hostile (Бавно)
Обхождането по колони (външен цикъл колони) е пагубно за скоростта:
```cpp
for(int j = 0; j < cols; ++j)
    for(int i = 0; i < rows; ++i)
        sum += matrix[i][j]; // Скачаме през големи блокове памет. Процесорът чака RAM-а.
```

---

## 5. Професионално решение: Flattening (Плоска матрица)
В гейм индустрията и научните изчисления рядко се ползва `int**`. Вместо това се ползва един 1D масив, който се третира като 2D:
```cpp
std::vector<int> matrix(rows * cols);
// Достъп до (ред i, колона j):
int value = matrix[i * cols + j];
```
**Защо?** Само една алокация, непрекъсната памет, максимална скорост.

---

## 6. Двумерни масиви и Функции
При подаване на 2D масив на функция, трябва да укажете всички размери освен първия:
```cpp
void process(int arr[][10], int rows); // OK
// void process(int arr[][], int rows); // ГРЕШКА!
```

---

## 7. Обобщение
*   Матриците в C++ са **линейни** под капака.
*   **Редът на обхождане** е критичен за скоростта.
*   Използвайте **Flattening** (1D vector) за професионални приложения.
*   Винаги предпочитайте `std::vector<std::vector<T>>` пред сурови указатели, ако скоростта не е краен приоритет.
