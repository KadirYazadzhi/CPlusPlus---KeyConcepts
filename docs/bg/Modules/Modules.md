# Модули (Modules) в C++20 - Пълно техническо ръководство

## 1. Въведение: Краят на 40-годишното наследство
От създаването си, C++ разчита на `#include` – механизъм за чисто текстово копиране на хедър файлове. Това води до огромни времена за компилация (защото един файл се прекомпилира милиони пъти) и до проблеми с макросите. **Модулите** са най-голямата промяна във физическата структура на C++, която заменя текстовото вмъкване с логическо зареждане на бинарни интерфейси.

---

## 2. Анатомия на Модула

### 2.1. Интерфейсна единица (.cppm / .ixx)
Тук дефинирате какво ще виждат потребителите. Използва се ключовата дума `export`.
```cpp
export module math; // Декларация на модул

export int add(int a, int b) {
    return a + b; // Тази функция е видима отвън
}

int secret_helper() { return 42; } // Скрита функция
```

### 2.2. Използване (main.cpp)
```cpp
import math; // Вместо #include "math.h"
import <iostream>; // Дори стандартната библиотека е модул от C++23
```

## 3. Предимства за големи системи

### 3.1. Драстично по-бърза компилация
Когато модулът се компилира, той се записва в **BMI (Binary Module Interface)**. Всеки `import` зарежда този бинарен файл почти мигновено. В големи проекти времето за билд може да спадне с до **80%**.

### 3.2. Изолация на макросите
Макросите дефинирани вътре в модул не "изтичат" навън. Край на случаите, в които `#define ERROR` в една библиотека счупва друга.

### 3.3. Липса на Header Guards
Понеже не е текстово копиране, няма нужда от `#ifndef HEADER_H` или `#pragma once`.

---

## 4. Глобален и Частен фрагмент на модула
Модулите позволяват да разделите интерфейса от имплементацията по много по-организиран начин от старите хедъри.
*   **Module Interface:** Описва функциите.
*   **Module Implementation:** Съдържа реалния код (не се експортира).

---

## 5. Професионално обобщение
*   Модулите са **бъдещето** на C++.
*   Започнете да ги използвате в нови проекти, за да избегнете "Header Hell".
*   Помнете, че `import std;` в C++23 ще замени включването на всички стандартни хедъри накуп.
