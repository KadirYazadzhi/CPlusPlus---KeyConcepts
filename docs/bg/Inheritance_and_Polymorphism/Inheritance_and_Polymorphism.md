# Наследяване и Полиморфизъм в C++ - Пълно ръководство

## 1. Наследяване (Inheritance): Връзката "Is-A"
Наследяването позволява създаването на нов клас (наследник) на базата на вече съществуващ (родител). Наследникът автоматично получава всички свойства и методи на родителя, като може да добавя нови или да пренаписва съществуващите.

### 1.1. Видове наследяване
*   **Public (най-често):** Public членовете на родителя остават public в наследника.
*   **Protected:** Членовете стават protected.
*   **Private:** Всичко става private.

---

## 2. Полиморфизъм (Polymorphism): Много форми
Полиморфизмът позволява на обекти от различни класове да бъдат третирани като обекти от общ базов тип. Това се постига чрез **виртуални функции**.

### 2.1. Виртуални функции (Virtual Functions)
Ключовата дума `virtual` казва на компилатора: "Изчакай до изпълнението (Runtime), за да решиш коя точно функция да извикаш".

```cpp
class Base {
public:
    virtual void show() { cout << "Base"; }
};

class Derived : public Base {
public:
    void show() override { cout << "Derived"; }
};
```

---

## 3. Абстрактни класове и интерфейси
Ако една виртуална функция е дефинирана като "чиста" (`virtual void func() = 0;`), класът става **абстрактен**. Не можете да създавате обекти от него. Той служи само за основа на други класове.

---

## 4. Виртуален деструктор: Златно правило
⚠️ **ВАЖНО:** Ако един клас има поне една виртуална функция, неговият деструктор **задължително** трябва да бъде виртуален. В противен случай, при изтриване на обект наследник през указател към родител, ще имате теч на памет.

---

## 5. Override и Final (C++11)
*   **override:** Гарантира, че наистина пренаписвате функция от родителя (предпазва от правописни грешки).
*   **final:** Забранява по-нататъшното наследяване на класа или метода.
