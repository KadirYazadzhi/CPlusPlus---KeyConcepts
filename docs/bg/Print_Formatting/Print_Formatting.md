# std::print и Форматиране в C++ - Пълно техническо ръководство

## 1. Въведение: Еволюцията на изхода в C++

В продължение на 40 години C++ програмистите бяха раздвоени между два свята:
1.  **C-style `printf`:** Бърз и с компактен синтаксис, но напълно **небезопасен** (Type Unsafe). Ако сбъркате `%d` с `%s`, програмата крашва.
2.  **C++ `iostream` (`std::cout`):** Типобезопасен и разширяем, но изключително **тромав**, бавен и труден за форматиране. Налага се използването на манипулатори като `std::setprecision`, `std::fixed`, което прави кода нечетим.

C++20 (с `<format>`) и C++23 (с `<print>`) въведоха революция, която съчетава скоростта на `printf` с безопасността на `iostream` и удобството на Python f-strings.

## 2. `std::format` (C++20): Модерният низ

`std::format` не печата нищо. Той връща `std::string` с форматираното съдържание. Това го прави идеален за генериране на логове, съобщения за грешки или UI текст.

### 2.1. Базов синтаксис
Използват се фигурни скоби `{}` като заместители (placeholders).
```cpp
#include <format>
std::string msg = std::format("Hello, {}! You have {} messages.", "Ivan", 5);
```

### 2.2. Спецификатори на формата
Синтаксисът е: `{ [index] : [fill] [align] [width] [.precision] [type] }`

*   **Индекси:** `"{1} преди {0}"` -> разменя аргументите.
*   **Подравняване:**
    *   `{:>10}`: Подравняване вдясно (ширина 10).
    *   `{:<10}`: Подравняване вляво.
    *   `{:^10}`: Центриране.
*   **Запълване:** `{:*^10}` -> Центриране със звездички (`**text***`).
*   **Числа:**
    *   `{:.2f}`: Две цифри след запетаята (Fixed point).
    *   `{:04x}`: Hex с водещи нули (напр. `00af`).
    *   `{:b}`: Двоичен формат (Binary).

## 3. `std::print` и `std::println` (C++23)

Докато `std::format` заделя памет за `string`, `std::print` пише директно в изходния буфер (или файл).

### 3.1. Защо е по-добър от `std::cout`?
1.  **По-малко код:** Няма `<<` оператори.
2.  **Без състояние:** `std::cout` пази състояние (stateful). Ако смените прецизността на `cout`, тя остава променена завинаги, което може да счупи друга част от програмата. `std::print` е без състояние (stateless).
3.  **Скорост:** Директни системни повиквания (`write`), избягвайки виртуалните функции на `ostream`.

### 3.2. Уникод (UTF-8) в Windows
Това е "Killer Feature".
`std::print` гарантира, че UTF-8 низ ще се изпише правилно на конзолата, дори под Windows (където `cout` често вади "маймуница" заради Codepages).

```cpp
#include <print>
int main() {
    // Работи перфектно навсякъде!
    std::println("Здравей, свят! Температурата е {:.1f}°C", 23.5);
}
```

## 4. Разширяване на библиотеката (Custom Formatters)

За да направите вашия клас съвместим с `std::format`, трябва да специализирате структурата `std::formatter`.

```cpp
struct Point { int x, y; };

template <>
struct std::formatter<Point> {
    // 1. Parse: Чете формата (напр. "{:p}" или "{:j}")
    constexpr auto parse(std::format_parse_context& ctx) {
        return ctx.begin(); // Засега игнорираме спецификаторите
    }

    // 2. Format: Извършва писането
    auto format(const Point& p, std::format_context& ctx) const {
        return std::format_to(ctx.out(), "({}, {})", p.x, p.y);
    }
};

// Употреба:
std::print("Hero location: {}", Point{10, 20});
```

## 5. Производителност: Бенчмарк анализ

*   **Binary Size:** Използването на `iostream` добавя стотици килобайти към изпълнимия файл заради тежките темплейти. `<print>` е много по-лек.
*   **Compile Time:** `<format>` се компилира значително по-бързо от `<iostream>`.
*   **Runtime:** В много тестове `std::print` е по-бърз дори от `printf`, защото парсването на формата става по време на компилация (за низови литерали), докато `printf` го прави по време на изпълнение.

---

## 6. Професионално обобщение

1.  **Мигрирайте:** Започнете да заменяте `cout` и `printf` с `std::print` (ако ползвате C++23) или `fmt::print` (библиотеката `{fmt}`, която е основата на стандарта).
2.  **Безопасност:** Ако напишете `std::print("{:d}", "string")`, кодът **няма да се компилира**. Това е огромно предимство пред `printf`, който би гръмнал по време на работа (Runtime Crash).
3.  **Логване:** `std::format` е идеалният инструмент за създаване на структурирани логове.
