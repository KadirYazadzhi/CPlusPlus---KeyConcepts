# Концепти (Concepts) в C++20 - Пълно техническо ръководство

## 1. Въведение: Проблемът на "Слепите" шаблони
Преди C++20 шаблоните бяха изключително мощни, но напълно лишени от семантична проверка. Ако подадете грешен тип на шаблон, грешката се появява дълбоко в неговата имплементация, което води до стотици редове неразбираем текст ("Template Error Hell"). **Концептите** са механизъм за налагане на ограничения върху шаблоните параметри още в тяхната декларация.

---

## 2. Философия: Duck Typing на ниво компилация
Концептите позволяват да кажете: "Не ме интересува какъв точно е типа `T`, стига той да може да се събира и да има метод `print()`".

---

## 3. Синтаксис и Клаузата `requires`

### 3.1. Кратък синтаксис
```cpp
template <std::integral T>
T add(T a, T b) { return a + b; }
```
Тук `std::integral` е стандартен концепт, който ограничава `T` само до целочислени типове.

### 3.2. Клаузата `requires` (Ad-hoc ограничения)
Можете да дефинирате изисквания директно:
```cpp
template <typename T>
requires requires(T a, T b) { a + b; }
T sum(T a, T b) { return a + b; }
```

---

## 4. Дефиниране на собствени Концепти (Expert Level)

Можете да комбинирате логически условия и проверки на интерфейси.
```cpp
template <typename T>
concept Drawable = requires(T v) {
    { v.draw() } -> std::same_as<void>; // Трябва да има метод draw() връщащ void
    v.x; // Трябва да има член-променлива x
};
```

---

## 5. Предимства за професионалния инженер
1.  **Ясни грешки:** Компилаторът казва веднага: "Типът `X` не удовлетворява концепта `Printable`".
2.  **По-бърза компилация:** Компилаторът не се опитва да инстанцира шаблона, ако условията не са изпълнени.
3.  **По-добро претоварване (Overloading):** Можете да имате две версии на функция – една за числа и една за низове, базирано на концепти.

---

## 6. Стандартни концепти в `<concepts>`
*   `std::same_as<T, U>`: Проверява дали два типа са идентични.
*   `std::derived_from<T, B>`: Проверява за наследяване.
*   `std::convertible_to<T, U>`: Проверява дали `T` може да стане `U`.
*   `std::equality_comparable`: Проверява дали работи `==`.

---

## 7. Професионално обобщение
Концептите са най-голямата промяна в C++ шаблоните от тяхното създаване. Те превръщат метапрограмирането от "черна магия" в добре документиран и лесен за поддръжка инженерен процес. Винаги използвайте концепти в новите си C++20 проекти.
