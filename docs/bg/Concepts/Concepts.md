# Концепти (Concepts) в C++20 - Пълно ръководство

## 1. Въведение: Краят на неясните грешки
Преди C++20 шаблоните бяха "слепи" – те приемаха всякакъв тип данни и гърмяха с 500 реда неразбираеми грешки, ако типът не поддържа нужните операции. **Концептите** позволяват да наложим формални изисквания към шаблоните параметри.

---

## 2. Синтаксис и Клаузата `requires`
Можем изрично да кажем, че функцията `add` работи само за числа:

```cpp
#include <concepts>

template <typename T>
requires std::integral<T>
T add(T a, T b) {
    return a + b;
}
```

Ако се опитате да подадете `std::string`, компилаторът ще спре веднага и ще каже: "Типът string не удовлетворява концепта integral".

---

## 3. Дефиниране на собствени концепти
Можете да дефинирате свои изисквания чрез ключовата дума `concept`.

```cpp
template <typename T>
concept Printable = requires(T v) {
    std::cout << v; // Проверява дали типът поддържа оператор <<
};

void log(Printable auto value) {
    std::cout << value << std::endl;
}
```

---

## 4. Предимства на Концептите
1.  **По-бърза компилация:** Компилаторът не се опитва да разгръща сложни шаблони, ако типът е грешен.
2.  **Документация на кода:** Веднага се вижда какво се очаква от потребителя на вашия шаблон.
3.  **Претоварване (Overloading):** Можете да имате различни версии на функция за различни концепти.

---

## 5. Стандартни концепти в <concepts>
*   `std::integral`, `std::floating_point`
*   `std::movable`, `std::copyable`
*   `std::derived_from<Derived, Base>`
*   `std::same_as<T, U>`
