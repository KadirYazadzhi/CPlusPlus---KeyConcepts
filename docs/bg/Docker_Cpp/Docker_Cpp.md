# Docker и Контейнеризация за C++ - Пълно техническо ръководство

## 1. Въведение: "Но на моята машина работи!"
В света на C++, една програма зависи от десетки неща: версия на компилатора, версия на стандартната библиотека (glibc), инсталирани системни пакети и променливи на средата. Docker решава този проблем, като опакова приложението и цялата му среда в един изолиран **контейнер**.

---

## 2. Docker за C++: Специфични предизвикателства

За разлика от езици с виртуални машини (Java), C++ се компилира до нативен код.
*   **Архитектура:** Контейнер, билдван на x86 (Intel), няма да тръгне на ARM (Apple M1/M2) без специални настройки.
*   **Размер на имиджа:** Сорс кодът и инструментите за билд са тежки. Професионалистите използват **Multi-stage builds**.

---

## 3. Multi-stage Build: Професионалният подход

Никога не включвайте компилатора и сорс кода в крайния имидж, който пращате на клиента.

**Dockerfile пример:**
```dockerfile
# Етап 1: Билд (Build stage)
FROM gcc:latest AS builder
WORKDIR /app
COPY . .
RUN g++ -O3 main.cpp -o my_app

# Етап 2: Изпълнение (Run stage)
FROM debian:stable-slim
WORKDIR /root/
COPY --from=builder /app/my_app .
CMD ["./my_app"]
```
*Резултат:* Имиджът намалява от 1GB (с компилатор) до 50MB (само бинарния файл).

---

## 4. Разработка вътре в контейнер (Dev Containers)

Вместо да инсталирате CMake, Conan и компилатори на вашия Windows/macOS, можете да ги инсталирате в Docker контейнер.
*   **VS Code Dev Containers:** Позволява ви да отворите папка в Docker и да пишете код там. Всички колеги в екипа ви ще имат **абсолютно една и съща** среда за разработка.

---

## 5. CI/CD и Docker
Docker е гръбнакът на съвременната автоматизация.
1. Програмистът прави `git push`.
2. GitHub Actions стартира Docker контейнер с всички зависимости.
3. Кодът се компилира и се тества вътре.
4. Ако всичко е наред, се създава "Production" имидж.

---

## 6. Професионално обобщение
*   Използвайте **Docker**, за да гарантирате, че сървърът ви има същата конфигурация като вашата машина.
*   Винаги използвайте **Multi-stage builds** за малки и сигурни имиджи.
*   Docker е най-добрият начин за тестване на C++ код под различни Linux дистрибуции (Ubuntu, Alpine, CentOS) едновременно.
