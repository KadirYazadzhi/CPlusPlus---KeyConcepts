# Обхвати (Ranges) в C++20 - Пълно ръководство

## 1. Въведение: Функционалното програмиране идва в C++
Библиотеката **Ranges** (`<ranges>`) е най-голямата промяна в STL от 20 години насам. Тя позволява да работим с колекции по декларативен начин, използвайки "тръбопроводи" (pipelines), подобно на езици като Python, Rust или C#.

---

## 2. Views (Изгледи): Мързеливо изчисляване
Най-мощната концепция в Ranges са **Views**. Те не копират данните, а създават лека обвивка над тях, която трансформира данните само когато са нужни (**Lazy Evaluation**).

```cpp
#include <ranges>
#include <vector>

std::vector<int> nums = {1, 2, 3, 4, 5, 6};

// Вземи четните числа, удвои ги и пропусни първото
auto result = nums 
            | std::views::filter([](int n) { return n % 2 == 0; })
            | std::views::transform([](int n) { return n * 2; })
            | std::views::drop(1);
```

---

## 3. Алгоритми с Ranges
Вече не е нужно да подавате `begin()` и `end()`. Можете да подадете целия контейнер директно.

```cpp
#include <algorithm>
std::ranges::sort(nums); // Вместо std::sort(nums.begin(), nums.end())
```

---

## 4. Проекции (Projections)
Алгоритмите в Ranges позволяват да трансформирате данните "в движение" преди сравнение.

```cpp
struct User { int id; string name; };
std::vector<User> users = {{2, "B"}, {1, "A"}};

// Сортирай по ID, без да пишеш сложна ламбда
std::ranges::sort(users, {}, &User::id);
```

---

## 5. Предимства
1.  **Чист код:** Намалява нуждата от сложни и вложени `for` цикли.
2.  **Производителност:** Избягва междинни копия на данни при филтриране и трансформиране.
3.  **Безопасност:** Тръбопроводите са по-малко податливи на грешки с итератори.
