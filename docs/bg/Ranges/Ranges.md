# Обхвати (Ranges) в C++20

## 1. Въведение

Библиотеката **Ranges** (`<ranges>`) е модерна надстройка над STL алгоритмите. Тя позволява да работим с колекции по **функционален**, декларативен начин, подобно на LINQ в C# или Streams в Java.

Вместо да подаваме `begin()` и `end()` на всеки алгоритъм, подаваме целия контейнер (Range).

---

## 2. Views (Изгледи) и Pipelines (Тръбопроводи)

Най-мощната характеристика е операторът `|` (pipe). Той позволява да веригаме операции, които се изпълняват **мързеливо** (lazy evaluation).

```cpp
#include <iostream>
#include <vector>
#include <ranges>

int main() {
    std::vector<int> numbers = {1, 2, 3, 4, 5, 6};

    // Задача: Вземи четните числа, удвои ги и пропусни първото
    auto result = numbers 
                | std::views::filter([](int n){ return n % 2 == 0; }) // {2, 4, 6}
                | std::views::transform([](int n){ return n * 2; })   // {4, 8, 12}
                | std::views::drop(1);                                // {8, 12}

    for (int n : result) {
        std::cout << n << " ";
    }
}
```

### Какво означава "Мързеливо"?
В горния пример **не се създават междинни вектори**. Няма памет, заделена за `{2, 4, 6}`. Изчисленията се случват точно когато итерираме в `for` цикъла. Това е изключително ефективно.

---

## 3. Алгоритми с Ranges

Стандартните алгоритми вече имат версии, които приемат range.

```cpp
#include <algorithm>

std::vector<int> v = {5, 1, 4, 2, 3};

// Преди C++20:
std::sort(v.begin(), v.end());

// С C++20:
std::ranges::sort(v);
```

---

## 4. Projections (Проекции)

Алгоритмите в Ranges поддържат "проекции" - начин да трансформираме данните, преди да ги сравним, без да пишем сложни ламбди.

```cpp
struct Person {
    int id;
    std::string name;
};

std::vector<Person> people = {{2, "Bob"}, {1, "Alice"}};

// Сортиране по ID (без Ranges)
std::sort(people.begin(), people.end(), [](const auto& a, const auto& b){
    return a.id < b.id;
});

// Сортиране по ID (с Ranges)
// Третият аргумент е проекцията (член-променлива)
std::ranges::sort(people, {}, &Person::id);
```

---

## 5. Видове Views

Някои полезни views от `<ranges>`:

*   `views::filter`: Филтрира по предикат.
*   `views::transform`: Променя стойността.
*   `views::take(n)`: Взима първите N елемента.
*   `views::drop(n)`: Пропуска първите N елемента.
*   `views::reverse`: Обръща реда.
*   `views::keys` / `views::values`: За работа с `map`.
*   `views::iota(1, 10)`: Генерира поредица 1..9.

---

## 6. Обобщение

*   Ranges правят кода по-кратък, по-четим и често по-бърз (заради липсата на междинни алокации).
*   Използвайте `|` за да композирате сложни заявки за данни.
*   Предпочитайте `std::ranges::sort(v)` пред стария синтаксис.
