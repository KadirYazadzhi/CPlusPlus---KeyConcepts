# Стекове (Stacks) в C++ - Пълно ръководство

## 1. Концепция: LIFO структура
Стекът е абстрактна структура от данни, която работи на принципа **Last-In, First-Out (LIFO)**. Това означава, че последният добавен елемент е първият, който бива изваден. Представете си купчина чинии или тесте карти – можете да добавяте само отгоре и да взимате само най-горния елемент.

---

## 2. Операции и сложност

Всички основни операции при стека са изключително бързи (**O(1)**):

1.  **push:** Добавя елемент на върха.
2.  **pop:** Премахва най-горния елемент.
3.  **top:** Връща стойността на върха, без да го трие.
4.  **empty:** Проверява дали е празен.
5.  **size:** Връща броя елементи.

⚠️ **Внимание:** В C++ `pop()` не връща стойност (типът му е `void`). Трябва първо да извикате `top()`, ако искате да видите стойността, преди да я премахнете.

---

## 3. Използване на std::stack (STL)

В STL `std::stack` не е контейнер сам по себе си, а **контейнерен адаптер**. Това означава, че той обвива друг контейнер (по подразбиране `std::deque`) и ограничава неговия интерфейс.

```cpp
#include <stack>
#include <vector>

// Можем да сменим базовия контейнер на вектор:
std::stack<int, std::vector<int>> s;
```

## 4. Ръчна имплементация (Deep Dive)

За да разберем как работи стекът, е полезно да видим как се имплементира с масив.

```cpp
template <typename T>
class MyStack {
    T* data;
    int top_index;
    int capacity;

public:
    MyStack(int size) : capacity(size), top_index(-1) {
        data = new T[capacity];
    }
    ~MyStack() { delete[] data; }

    void push(T val) {
        if (top_index >= capacity - 1) throw std::overflow_error("Stack Overflow");
        data[++top_index] = val;
    }

    void pop() {
        if (top_index < 0) return;
        top_index--;
    }

    T top() { return data[top_index]; }
};
```

## 5. Приложения в реалния свят

1.  **Call Stack:** Управление на извикванията на функции в процесора.
2.  **Обратен полски запис (Reverse Polish Notation):** Изчисляване на математически изрази.
3.  **Undo/Redo:** В текстови редактори като VS Code или Word.
4.  **DFS (Depth First Search):** Търсене в дълбочина в графи.
5.  **Balance Checking:** Проверка дали скобите в кода са правилно затворени.

---

## 6. Често срещани проблеми

*   **Stack Overflow:** Когато добавяте твърде много елементи в стек с фиксиран размер (често при безкрайна рекурсия).
*   **Empty Access:** Опит за `top()` или `pop()` върху празен стек води до срив. Винаги проверявайте `!s.empty()`.
