# Стекове (Stacks) в C++ - Пълно техническо ръководство

## 1. Въведение: Принципът на вертикалните данни
Стекът е линейна структура от данни, която следва строгата дисциплина **Last-In, First-Out (LIFO)**. В света на софтуерното инженерство стекът не е просто колекция от елементи, а механизъм за управление на състоянието и историята на изпълнение. Всяко действие, което може да бъде отменено (Undo), всяка функция, която може да се върне при родителя си, разчита на концепцията за стека.

---

## 2. Анатомия на STL Адаптера: std::stack

В Standard Template Library (STL), `std::stack` е дефиниран като **Контейнерен Адаптер**.

### 2.1. Защо Адаптер?
Той не е самостоятелен контейнер. Той е "обвивка" (wrapper) над друг контейнер (по подразбиране `std::deque`). Това позволява на програмиращия да смени вътрешната имплементация, без да променя логиката на стека.

```cpp
#include <stack>
#include <vector>

// Стек, базиран на вектор (непрекъсната памет, по-бърз кеш)
std::stack<int, std::vector<int>> fast_stack;
```

---

## 3. Основни Операции и Техническа Сложност

Всички операции са с времева сложност **O(1)**:

1.  **push(val):** Поставя елемент най-отгоре. Ако капацитетът е изчерпан (при `vector`), може да доведе до реалокация.
2.  **pop():** Премахва най-горния елемент. **Внимание:** Не връща стойност!
3.  **top():** Връща референция към най-горния елемент.
4.  **empty():** Проверява дали има данни.
5.  **size():** Връща текущия брой елементи.

---

## 4. Системно значение (The Hardware Stack)

### 4.1. Call Stack (Процесорен стек)
Когато програмата работи, тя използва физически стек в RAM паметта, управляван от регистрите `RSP` (Stack Pointer) и `RBP` (Base Pointer). Този стек пази адресите за връщане и локалните променливи. Ако рекурсията е безкрайна, този стек се препълва (**Stack Overflow**).

### 4.2. Алгоритмично значение
Стекът е двигателят на алгоритъма **DFS (Depth First Search)** и на всяка машина за състояния (State Machine).

---

## 5. Професионални капани

### 5.1. Достъп до празен стек
STL е проектиран за максимална скорост. Извикването на `top()` или `pop()` върху празен стек не хвърля изключение по подразбиране – то води до **Undefined Behavior** (обикновено Segfault). Винаги проверявайте `!s.empty()`.

### 5.2. Копиране на големи обекти
Когато извиквате `s.top()`, вие получавате референция. Ако я присвоите на обикновена променлива, ще направите излишно копие. Винаги използвайте `const auto&` за четене.

## 6. Ръчна имплементация (Deep Dive)
Разбирането на стека изисква да знаете как той работи на ниско ниво. Ето една "Safe" имплементация с динамичен масив:

```cpp
template <typename T>
class SafeStack {
    std::vector<T> data;
public:
    void push(const T& val) { data.push_back(val); }
    void pop() {
        if (data.empty()) throw std::underflow_error("Stack is empty");
        data.pop_back();
    }
    const T& top() const {
        if (data.empty()) throw std::underflow_error("Stack is empty");
        return data.back();
    }
};
```

## 7. Обобщение
*   Стекът е за **краткосрочна памет** и управление на потока.
*   Използвайте го за **Undo**, **RPN калкулатори** и **DFS**.
*   Предпочитайте `std::vector` като базов контейнер, ако ви трябва максимална скорост.
