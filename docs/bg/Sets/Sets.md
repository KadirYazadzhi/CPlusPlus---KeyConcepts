# Множества (Sets) в C++ - Пълно техническо ръководство

## 1. Концепция: Уникалност и Ред (Red-Black Tree)
В C++, `std::set` не е просто списък с уникални елементи. Той е **Асоциативен Контейнер**, който гарантира, че данните са винаги сортирани. За постигането на тази цел, STL използва **Червено-черно дърво (Red-Black Tree)** – вид самобалансиращо се двоично дърво за търсене.

---

## 2. Анатомия на Червено-черното дърво

### 2.1. Баланс и Сложност
За разлика от обикновените дървета, които могат да се "изродят" в списък (O(N)), червено-черното дърво гарантира, че височината му е винаги логаритмична.
*   **Търсене:** O(log N)
*   **Вмъкване:** O(log N)
*   **Изтриване:** O(log N)

### 2.2. Защо елементите са `const`?
Елементите в `std::set` са неизменяеми. Ако промените стойността на елемент, вие ще нарушите реда в дървото. Затова итераторите на сета са винаги `const_iterator`.

---

## 3. Сравнение на различните "Множества"

| Тип | Базова структура | Ред | Скорост |
| :--- | :--- | :--- | :--- |
| **std::set** | Red-Black Tree | Сортиран | O(log N) |
| **std::unordered_set** | Hash Table | Няма ред | O(1) средно |
| **std::multiset** | Red-Black Tree | Сортиран | O(log N) (дубликати) |

---

## 4. Професионални трикове (Advanced Usage)

### 4.1. Lower Bound и Upper Bound
Тези методи са изключително мощни. Те ви позволяват да намерите целия интервал от стойности между X и Y в логаритмично време.

### 4.2. Персонализирани Компартори
Можете да дефинирате собствен ред за сортиране чрез функционален обект:
```cpp
struct CustomOrder {
    bool operator()(const string& a, const string& b) const {
        return a.length() < b.length(); // Сортиране по дължина на низа
    }
};
std::set<string, CustomOrder> s;
```

---

## 5. Професионално обобщение
*   Използвайте `std::set`, когато ви трябва **сортиран** списък с уникални ключове.
*   Използвайте `std::unordered_set` за максимална скорост, ако редът не е важен.
*   Избягвайте големи обекти в `std::set`, защото всяко вмъкване води до алокация на нов възел (node overhead).
