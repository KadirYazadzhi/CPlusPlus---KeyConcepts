# Опашки с Приоритет в C++ - Пълно техническо ръководство

## 1. Концепция: Когато редът не зависи от времето

В стандартната опашка (`std::queue`), първият влязъл е първи излязъл (FIFO). В `std::priority_queue` обаче, първият излязъл е този с **най-висок приоритет**, независимо кога е бил добавен.

Това е перфектната абстракция за системи, където "спешността" е водещ фактор:
*   **Спешно отделение:** Пациент с инфаркт (дошъл преди 5 мин) влиза преди пациент с хрема (дошъл преди 1 час).
*   **ОС Шедулър:** Системен процес (kernel task) прережда потребителски процес (browser).

## 2. Вътрешна структура: Binary Heap (Двоична пирамида)

⚠️ **ИНЖЕНЕРЕН ПОГЛЕД:** `std::priority_queue` не е магия. Тя е просто `std::vector` + алгоритми за подредба на пирамида (Heap Algorithms).

### 2.1. Какво е Heap?
Това е двоично дърво, което спазва едно просто правило (**Heap Property**):
*   **Max-Heap:** Родителят винаги е по-голям или равен на децата си. Коренът е най-големият елемент.
*   **Min-Heap:** Родителят е по-малък. Коренът е най-малкият.

`std::priority_queue` **НЕ** поддържа целия масив сортиран. Това би било твърде бавно (O(N) при вмъкване). Тя поддържа само пирамидалната структура, което е достатъчно, за да знаем кой е "най-важният".

### 2.2. Математика на индексите (Implicit Data Structure)
Вместо да ползваме скъпи указатели (`Node* left, right`), ние пазим дървото в плосък масив:
За възел на индекс `i`:
*   **Ляво дете:** `2 * i + 1`
*   **Дясно дете:** `2 * i + 2`
*   **Родител:** `(i - 1) / 2`

Това прави структурата изключително компактна и Cache-Friendly.

## 3. Операции и Сложност

| Операция | Сложност | Описание |
| :--- | :--- | :--- |
| **push()** | **O(log N)** | Добавя в края и "изплува" нагоре (Sift Up / Swim). |
| **pop()** | **O(log N)** | Маха корена, слага последния на негово място и го "потапя" надолу (Sift Down / Sink). |
| **top()** | **O(1)** | Връща `vector[0]`. |

## 4. Min-Heap и Custom Comparators

По подразбиране C++ създава **Max-Heap** (най-голямото число е отгоре).

### 4.1. Създаване на Min-Heap
За да обърнете реда (напр. за Dijkstra алгоритъм), трябва да смените компаратора:
```cpp
// Тип, Контейнер, Компаратор
std::priority_queue<int, std::vector<int>, std::greater<int>> min_pq;
```

### 4.2. Собствени структури
Ако пазите сложни обекти (напр. `Task`), трябва да дефинирате как се сравняват.
```cpp
struct Task {
    int priority;
    string name;
    
    // Предефиниране на operator<
    bool operator<(const Task& other) const {
        // Внимание: priority_queue вади НАЙ-ГОЛЕМИЯ.
        // Ако искаме task с по-малко число да излезе пръв (като priority 1),
        // трябва да обърнем логиката:
        return priority > other.priority; 
    }
};
```
Или с Functor:
```cpp
struct CompareTask {
    bool operator()(const Task& a, const Task& b) {
        return a.priority > b.priority;
    }
};
std::priority_queue<Task, std::vector<Task>, CompareTask> pq;
```

## 5. make_heap, push_heap, pop_heap

STL ви дава достъп до суровите алгоритми чрез заглавния файл `<algorithm>`. Можете да превърнете *всеки* вектор в пирамида и обратно.

```cpp
std::vector<int> v = {10, 20, 5, 30};

std::make_heap(v.begin(), v.end()); // Пренарежда вектора в Heap (O(N))
// v.front() вече е 30

v.push_back(40);
std::push_heap(v.begin(), v.end()); // Оправя пирамидата след добавяне (O(log N))
// v.front() е 40

std::pop_heap(v.begin(), v.end()); // Мести най-големия (40) най-отзад
v.pop_back(); // Реално го маха от вектора
```
Това е полезно, ако искате да имате достъп до целия масив, а не само до върха.

## 6. Приложения в реалния свят

1.  **Алгоритъм на Дейкстра (Dijkstra) и A*:** Търсене на най-кратък път. Опашката пази непосетените възли, сортирани по текущо разстояние.
2.  **Хъфман кодиране (Huffman Coding):** Компресия на данни. Използва Min-Heap, за да комбинира най-рядко срещаните символи.
3.  **K-те най-големи елемента:** Ако ви трябват топ 10 резултата от 1 милион, поддържайте Min-Heap с размер 10. Ако новият елемент е по-голям от върха, махнете върха и вкарайте новия.

## 7. Професионално обобщение

*   `std::priority_queue` е най-бързият начин да поддържате "текущия лидер" в поток от данни.
*   **Внимавайте с логиката на `<`**: При `priority_queue`, "по-малко" означава "по-ниско в пирамидата".
*   Няма итератори. Не можете да обходите опашката, без да я разрушите (освен ако не ползвате `make_heap` върху собствен вектор).
*   Запазете памет чрез `reserve()` на вътрешния контейнер.
