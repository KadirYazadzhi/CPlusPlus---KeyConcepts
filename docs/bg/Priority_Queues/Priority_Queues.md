# Опашки с Приоритет (Priority Queues) в C++ - Пълно ръководство

## 1. Концепция: Не е просто FIFO
За разлика от стандартната опашка, която следва принципа "първи влязъл, първи излязъл", `std::priority_queue` подрежда елементите според тяхната стойност. Елементът с най-висок приоритет (по подразбиране най-голямата стойност) винаги е на върха и излиза първи.

---

## 2. Вътрешна структура: Двоична пирамида (Heap)
Опашката с приоритет обикновено се имплементира като **Binary Heap** върху `std::vector`. Това позволява ефективно управление на приоритетите без пълно сортиране на целия контейнер.

### 2.1. Производителност (Complexity)
*   **Добавяне (push):** O(log N)
*   **Премахване на върха (pop):** O(log N)
*   **Преглед на върха (top):** O(1)

---

## 3. Min-Heap срещу Max-Heap

По подразбиране C++ създава **Max-Heap** (най-големият елемент е отгоре).

### 3.1. Как да направим Min-Heap (най-малкият отгоре)?
Трябва да променим шаблона на декларацията:
```cpp
#include <queue>
#include <vector>
#include <functional>

std::priority_queue<int, std::vector<int>, std::greater<int>> min_pq;
```

---

## 4. Работа с потребителски обекти

За да използвате `std::priority_queue` с ваши класове, трябва да дефинирате как се сравняват обектите.

### 4.1. Претоварване на operator<
```cpp
struct Task {
    int priority;
    string description;

    // Важно: priority_queue използва < за подредба.
    bool operator<(const Task& other) const {
        return priority < other.priority;
    }
};
```

---

## 5. Защо няма итератори?
`std::priority_queue` не поддържа итератори. Вие не можете да обхождате елементите или да променяте тези в средата. Това е така, защото всяка промяна би нарушила структурата на Heap-а. Единственият начин да видите всички елементи е да ги изваждате един по един с `pop()`.

## 6. Приложения
*   **Алгоритъм на Дейкстра:** За намиране на най-кратък път.

*   **Планиране на задачи (OS Scheduling):** Винаги изпълнявай задачата с най-висок приоритет първа.
