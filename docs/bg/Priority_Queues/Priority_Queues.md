# Опашки с Приоритет в C++ - Пълно техническо ръководство

## 1. Концепция: Абстракцията на "Важните данни"
`std::priority_queue` е адаптер, който предоставя достъп само до най-големия (или най-малкия) елемент. В професионалния софтуер това е структурата, която задвижва системните шедулъри (schedulers) и сложните изкуствени интелекти (напр. Pathfinding).

---

## 2. Анатомия на Двоичната Пирамида (Binary Heap)

Почти винаги `priority_queue` се имплементира като **Binary Heap** (Двоична пирамида) върху масив (`std::vector`).
*   **Предимство:** Изключително ефективно използване на паметта.
*   **Подредба:** Не е пълно сортиране! Поддържа се само свойството, че родителят е по-голям от децата си.

### 2.1. Сложност (Complexity)
*   `push()`: **O(log N)** - Поставя елемента в края и го "избутва" нагоре (Bubble-up).
*   `pop()`: **O(log N)** - Премахва върха и реорганизира пирамидата (Heapify).
*   `top()`: **O(1)** - Връща първия елемент на вектора.

---

## 3. Min-Heap срещу Max-Heap

По подразбиране C++ създава **Max-Heap**.
За да направите **Min-Heap** (най-малкото число отгоре), трябва да използвате следната декларация:
```cpp
std::priority_queue<int, std::vector<int>, std::greater<int>> pq;
```

---

## 4. Сложни обекти и Компартори
За професионални приложения често се налага приоритетът да е комплексен обект.
```cpp
struct Task {
    int priority;
    long timestamp;
    bool operator<(const Task& other) const {
        if (priority != other.priority) return priority < other.priority;
        return timestamp > other.timestamp; // По-старите задачи са с предимство
    }
};
```

---

## 5. Професионално обобщение
*   Използвайте `priority_queue` за алгоритми като **Dijkstra** или **A***.
*   Помнете, че нямате достъп до елементите в средата.
*   Ако ви трябва често променяне на приоритети, вероятно ви трябва друга структура (напр. ръчно управление на Heap).
