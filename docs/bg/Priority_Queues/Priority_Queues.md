# Опашки с Приоритет в C++ - Пълно техническо ръководство

## 1. Концепция: Стойност пред Ред
Стандартната опашка (FIFO) обслужва елементите в реда на тяхното пристигане. `std::priority_queue` обаче обслужва елементите според тяхната **важност**. Елементът с най-висок приоритет винаги е на върха, независимо кога е влязъл в структурата.

---

## 2. Анатомия на Binary Heap (Пирамида)

Почти винаги `priority_queue` се имплементира като **Binary Heap** (Двоична пирамида) върху динамичен масив (`std::vector`).

### 2.1. Предимства на Heap-а
*   **Space Efficient:** Не пази указатели. Връзките между родител и деца се изчисляват математически чрез индексите.
*   **Производителност:**
    *   `push()`: **O(log N)**
    *   `pop()`: **O(log N)**
    *   `top()`: **O(1)**

---

## 3. Min-Heap срещу Max-Heap

По подразбиране STL създава **Max-Heap** (най-големият елемент е с най-висок приоритет).

### 3.1. Деклариране на Min-Heap
За да получите най-малкия елемент на върха, синтаксисът е по-сложен:
```cpp
#include <queue>
#include <vector>
#include <functional>

std::priority_queue<int, std::vector<int>, std::greater<int>> min_pq;
```

## 4. Сложни обекти и Критерии за приоритет
За професионални приложения (напр. планиране на задачи в OS), приоритетът рядко е просто число.
```cpp
struct Task {
    int importance;
    long deadline;

    // Важно: priority_queue използва < за подредба.
    // За да работи правилно, дефинираме operator<
    bool operator<(const Task& other) const {
        if (importance != other.importance) 
            return importance < other.importance;
        return deadline > other.deadline; // По-ранният краен срок е с предимство
    }
};
```

---

## 5. Професионални капани
1.  **Липса на итератори:** Вие не можете да обхождате `priority_queue`. Единственият начин да видите данните е да ги изтривате (`pop()`).
2.  **Промяна на приоритет:** Ако промените обект, който вече е вътре в опашката, тя няма да се реорганизира автоматично. Това ще счупи структурата на данните. Трябва да извадите обекта и да го вкарате наново.
