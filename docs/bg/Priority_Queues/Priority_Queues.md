# Опашки с Приоритет в C++ - Пълно техническо ръководство

## 1. Концепция: Когато редът не зависи от времето
В стандартната опашка, първият влязъл е първи излязъл. В `std::priority_queue` обаче, първият излязъл е този с **най-висок приоритет**. Това е абстракция на реални системи като спешното отделение в болница или системния шедулър на Linux, където важните задачи пререждат останалите.

---

## 2. Вътрешна структура: Binary Heap (Двоична пирамида)

⚠️ **ИНЖЕНЕРЕН ПОГЛЕД:** `priority_queue` не поддържа данните си сортирани. Тя поддържа само **свойството на пирамидата**.

### 2.1. Икономия на памет
Пирамидата се съхранява в обикновен масив (`std::vector`). Връзките между родител и деца се изчисляват математически:
*   `родител(i) = (i - 1) / 2`
*   `ляво_дете(i) = 2*i + 1`
*   `дясно_дете(i) = 2*i + 2`
Това елиминира нуждата от съхранение на указатели и прави структурата изключително компактна.

---

## 3. Производителност и Математика

*   **push():** **O(log N)**. Елементът се добавя в края и се избутва нагоре (Up-Heapify).
*   **pop():** **O(log N)**. Коренът се премахва, на негово място идва последният елемент и се избутва надолу (Down-Heapify).
*   **top():** **O(1)**. Директен достъп до първия елемент на масива.

---

## 4. Min-Heap срещу Max-Heap

По подразбиране C++ създава **Max-Heap**. Ако искате най-малкият елемент да бъде отгоре (напр. за алгоритми за най-кратък път), декларацията е:
```cpp
std::priority_queue<int, std::vector<int>, std::greater<int>> min_pq;
```

---

## 5. Персонализирани обекти: Критерий за важност
В професионалния код приоритетът често е комплексен. За да работи опашката, трябва да дефинирате `operator<`:
```cpp
struct Job {
    int level;
    long deadline;
    bool operator<(const Job& other) const {
        return level < other.level; // По-голям левъл = по-висок приоритет
    }
};
```

---

## 6. Професионални капани
1.  **Промяна на приоритета:** Ако промените стойността на обект, който вече е в опашката, тя **няма да се реорганизира**. Това ще доведе до грешна подредба. Трябва да изтриете обекта и да го вкарате наново.
2.  **Липса на итератори:** Вие не можете да обхождате `priority_queue`. Трябва да я изпразвате елемент по елемент, за да видите съдържанието.

## 7. Професионално обобщение
*   Използвайте `priority_queue` за **Dijkstra**, **A*** и **Data Compression (Huffman)**.
*   Използвайте я винаги, когато имате динамичен поток от данни и ви трябва само най-важният елемент.
*   За критични по време системи, обмислете `reserve()` на базовия вектор.
