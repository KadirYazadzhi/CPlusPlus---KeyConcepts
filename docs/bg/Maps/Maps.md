# Карти (Maps) в C++ - Пълно ръководство

## 1. Въведение: Речникът на C++
`std::map` е асоциативен контейнер, който съхранява двойки **Ключ - Стойност**. Всеки ключ е уникален и е свързан с точно една стойност. Подобно на `std::set`, елементите в картата винаги са сортирани по своя ключ.

---

## 2. Вътрешна имплементация
Картите се имплементират като **самобалансиращи се двоични дървета** (обикновено Червено-черни дървета).

### 2.1. Производителност (Complexity)
*   **Търсене:** O(log N)
*   **Вмъкване:** O(log N)
*   **Изтриване:** O(log N)

---

## 3. Достъп и Модификация

### 3.1. Оператор []
Най-лесният начин за достъп. **Внимание:** Ако ключът не съществува, операторът `[]` автоматично ще го създаде със стойност по подразбиране (напр. 0 за int).

```cpp
std::map<string, int> ages;
ages["Ivan"] = 25; // Създава или обновява
```

### 3.2. Методът at()
По-безопасен от `[]`. Ако ключът липсва, хвърля изключение `std::out_of_range`.

---

## 4. Обхождане (Iteration)

При итериране получавате двойка от типа `std::pair<const Key, Value>`.

```cpp
for (const auto& [name, age] : ages) { // C++17 Structured Bindings
    std::cout << name << " е на " << age << " години\n";
}
```

---

## 5. Методи за търсене

1.  **find():** Връща итератор към двойката.
2.  **count():** Връща 1 или 0 (тъй като ключовете са уникални).
3.  **lower_bound() / upper_bound():** За намиране на диапазони от ключове.

---

## 6. Кога да използваме Map?
*   Когато имате нужда от асоциация (напр. ID -> Потребител).
*   Когато данните трябва да бъдат винаги сортирани.
*   Когато търсенето трябва да бъде предвидимо бързо (log N).
