# Optional, Variant и Any (C++17) - Пълно техническо ръководство

## 1. Въведение: Сбогом на void* и Null

До C++17 работата с "липсващи", "алтернативни" или "динамични" типове данни изискваше използването на опасни похвати като `nullptr`, `void*` или тромави `union` структури.
C++17 въведе три нови "vocabulary types" (контейнери за стойности), вдъхновени от функционалното програмиране (Haskell, Rust), които правят кода типобезопасен и експресивен.

---

## 2. `std::optional`: Стойности, които може да не съществуват

Най-често използваният от трите. Той решава класическия проблем: *"Какво да върне функция, ако не намери резултат?"*

### 2.1. Защо е по-добър от nullptr или -1?
*   **Семантика:** `std::optional<int>` казва: "Може да има int, а може и да няма". `int*` казва: "Това е адрес".
*   **Безопасност:** Няма нужда от динамична памет (`new int`). Стойността се съхранява вътре в обекта (на стека).

```cpp
std::optional<User> findUser(int id) {
    if (db.hasUser(id)) return db.getUser(id);
    return std::nullopt; // Еквивалент на "нищо"
}

auto user = findUser(10);
if (user) { // bool конверсия
    print(user->name); // operator->
} else {
    print("User not found");
}
```

### 2.2. Монадични операции (C++23)
В C++23 бяха добавени методи като `.and_then()` и `.transform()`, които позволяват верижно извикване без `if` проверки.

## 3. `std::variant`: Алгебрични типове данни (Sum Types)

`std::variant<A, B, C>` е модерната, типобезопасна версия на `union`. Той може да съдържа стойност от **точно един** тип от списъка във всеки момент.

### 3.1. Как работи?
Variant съхранява най-големия възможен обект (чрез `union` под капака) и един скрит индекс (`size_t`), който помни кой тип е активен в момента.

### 3.2. `std::visit`: Шаблонът Посетител (Visitor Pattern)
Това е професионалният начин за работа с `variant`. Той елиминира нуждата от `if (holds_alternative<int>)` проверки.

```cpp
using VarType = std::variant<int, float, std::string>;

struct Printer {
    void operator()(int i) { cout << "Int: " << i; }
    void operator()(float f) { cout << "Float: " << f; }
    void operator()(const string& s) { cout << "Str: " << s; }
};

VarType v = "Hello";
std::visit(Printer{}, v); // Извиква operator()(string)
```

**Overloaded Lambdas:** Често се ползва с помощна структура `overloaded` за дефиниране на ламбди на място.

## 4. `std::any`: Пълният динамизъм

`std::any` е контейнер, който може да съдържа **абсолютно всеки** тип (стига да е копируем).
Това е еквивалентът на `Object` в Java/C# или `void*` в C, но със запазена информация за типа (RTTI).

### 4.1. Използване и Cast
За да вземете стойността, трябва да знаете точния тип:
```cpp
std::any a = 10;
a = std::string("Test");

// Безопасно извличане
try {
    std::string s = std::any_cast<std::string>(a);
} catch (const std::bad_any_cast& e) {
    // Грешен тип!
}
```

⚠️ **ВНИМАНИЕ:** Тъй като `std::any` често използва динамична алокация (Heap) за големи обекти, той е много по-бавен от `variant` и трябва да се избягва, освен ако типовете наистина са неизвестни (напр. property system в Game Engine).

## 5. Сравнителен анализ (Memory & Performance)

| Тип | Предназначение | Памет | Бързина |
| :--- | :--- | :--- | :--- |
| **std::optional<T>** | 0 или 1 стойност | `sizeof(T)` + `bool` (alignment) | Отлична (Stack) |
| **std::variant<A, B>** | Една от N опции | `max(sizeof(A), sizeof(B))` + `idx` | Много добра (Stack) |
| **std::any** | Всеки възможен тип | Heap allocation (често) | Бавна (RTTI + Heap) |

## 6. Професионално обобщение

1.  **Optional:** Използвайте го за връщане на резултати, които може да липсват, и за "мързелива" инициализация на полета.
2.  **Variant:** Използвайте го за state machines, парсване на JSON/XML (стойност може да е число или стринг) и обработка на грешки (`variant<Result, Error>`).
3.  **Any:** Използвайте само в краен случай, когато се нуждаете от `void*` с проверка на типовете.
