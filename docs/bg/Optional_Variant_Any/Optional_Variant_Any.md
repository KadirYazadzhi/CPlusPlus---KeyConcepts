# Модерни Типове Данни (Optional, Variant, Any) - Пълно ръководство

## 1. std::optional: Стойности, които може да липсват
`std::optional` (C++17) решава проблема с функции, които невинаги връщат резултат. Вече не е нужно да ползвате `nullptr` или специални числа като `-1`.

```cpp
std::optional<int> findUser(int id) {
    if (id == 1) return 42;
    return std::nullopt; // Няма стойност
}
```

---

## 2. std::variant: Безопасен Union
`std::variant` е тип, който може да съхранява една стойност от предварително зададен списък с типове. Той е **type-safe** – винаги знае какво има вътре.

```cpp
std::variant<int, std::string> v = "Hello";
v = 10;
int x = std::get<int>(v);
```

### 2.1. std::visit
Най-мощният начин за работа с `variant` е чрез Visitor pattern (ламбда изрази за всеки възможен тип).

---

## 3. std::any: Пълна гъвкавост
`std::any` може да съхранява **абсолютно всеки** тип данни. За да вземете стойността, трябва изрично да я кастнете (`std::any_cast`).

---

## 4. Обобщение
*   **optional:** Използвайте за опционални резултати.
*   **variant:** Когато знаете възможните типове (напр. грешка ИЛИ успех).
*   **any:** Когато типовете са напълно неизвестни (рядко се препоръчва).
