# Списъци (Lists) в C++

## 1. Въведение

`std::list` е контейнер, който имплементира **двойно свързан списък** (Doubly Linked List). Дефиниран е в `<list>`.

За разлика от `std::vector`, елементите на списъка **не се съхраняват в последователна памет**. Всеки елемент (възел) съдържа стойността си и указатели към предишния и следващия елемент.

### Предимства:
*   **Вмъкване и триене:** O(1) (константно време) на произволна позиция, ако имаме итератор към нея. Не се изисква преместване на другите елементи.
*   **Няма реалокация:** Добавянето на елемент никога не води до копиране на целия контейнер (както при `vector`).

### Недостатъци:
*   **Бавен достъп:** Няма произволен достъп по индекс (`operator[]`). За да стигнем до 5-тия елемент, трябва да минем през първите 4. Търсенето е O(N).
*   **Памет:** Всеки елемент има overhead (два допълнителни указателя).
*   **Cache Misses:** Разпръснати са в паметта, което е лошо за процесорния кеш.

## 2. Основни Операции

```cpp
#include <iostream>
#include <list>
#include <algorithm>

int main() {
    std::list<int> myList = {10, 20, 30};

    // 1. Добавяне в двата края - O(1)
    myList.push_back(40);
    myList.push_front(0); 

    // Лист: 0 -> 10 -> 20 -> 30 -> 40

    // 2. Достъп до краищата
    std::cout << myList.front() << std::endl; // 0
    std::cout << myList.back() << std::endl;  // 40

    // 3. Вмъкване в средата
    // Трябва първо да намерим позицията с итератор
    auto it = myList.begin();
    std::advance(it, 2); // Премества итератора с 2 позиции напред (сочи към 20)

    myList.insert(it, 15); // Вмъква 15 ПРЕДИ 20
    // Лист: 0 -> 10 -> 15 -> 20 -> 30 -> 40

    // 4. Триене
    myList.pop_front(); // Маха 0
    myList.pop_back();  // Маха 40

    return 0;
}
```

## 3. Специфични операции за List

`std::list` има вградени методи за сортиране и манипулация, които са по-ефективни от генеричните алгоритми в `<algorithm>`, защото работят само чрез пренасочване на указатели, без копиране на данни.

### 3.1. `sort()`
Стандартният `std::sort` не работи със списъци (защото изисква Random Access Iterators). Затова списъкът си има собствен `sort`.

```cpp
myList.sort(); // Сортира възходящо O(N log N)
myList.sort(std::greater<int>()); // Сортира низходящо
```

### 3.2. `splice()` (Сливане/Преместване)
Уникална и мощна операция. Премества елементи от един списък в друг (или вътре в същия) за O(1) време, без никакво копиране.

```cpp
std::list<int> list1 = {1, 2, 3};
std::list<int> list2 = {10, 20, 30};

auto it = list1.begin();
it++; // Сочи към 2

// Премества ЦЕЛИЯ list2 вътре в list1 преди позиция 'it'
list1.splice(it, list2);

// list1: 1 -> 10 -> 20 -> 30 -> 2 -> 3
// list2: (празен)
```

### 3.3. `remove()` и `unique()`
*   `remove(val)`: Маха всички елементи със стойност `val`.
*   `remove_if(predicate)`: Маха по условие.
*   `unique()`: Маха последователни дубликати (изисква сортиран списък за пълен ефект).

## 4. `std::forward_list` (C++11)

Това е **едносвързан списък** (Singly Linked List). Дефиниран в `<forward_list>`.
Всеки елемент пази указател само към следващия.

*   **Предимство:** По-малко памет от `std::list`.
*   **Недостатък:** Може да се обхожда само напред. Няма `push_back` (защото е O(N)), само `push_front`.

```cpp
#include <forward_list>
std::forward_list<int> fl = {1, 2, 3};
fl.push_front(0); // Ефективно
// Няма .size()! (Заради O(N) сложност)
```

## 5. Обобщение

Използвайте `std::list` само когато:
1.  Трябва често да вмъквате/триете елементи **в средата** на контейнера.
2.  Не ви трябва достъп по индекс (`vec[5]`).
3.  Искате итераторите към елементите да останат валидни дори след вмъкване/триене на други места (Iterator Invalidation e много рядко при списъците).

В 90% от случаите `std::vector` е по-добрият избор заради кеш-ефективността и скоростта.
