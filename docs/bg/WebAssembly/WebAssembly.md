# WebAssembly (WASM) и C++ - Пълно техническо ръководство

## 1. Въведение: Браузърът като операционна система
Дълго време JavaScript беше единственият господар на браузъра. **WebAssembly (WASM)** промени това, като въведе бинарен формат, който позволява на езици като C++ да работят в браузъра с почти нативна скорост. Вече можете да пренесете Photoshop, 3D игри (Unreal Engine) или AI модели директно в уеб страницата.

---

## 2. Екосистемата Emscripten

`Emscripten` е основният инструмент (компилатор), който превръща C++ код в WASM. Той не само компилира кода, но и предоставя "обвивка", която симулира стандартни C библиотеки и POSIX файлова система в браузъра.

---

## 3. Компилационен процес

Когато компилирате за WASM:
1. **C++ Code** се превръща в **LLVM IR**.
2. Emscripten го превръща в **.wasm** (бинарен файл) и **.js** (лепило между JS и WASM).

**Примерна команда:**
```bash
emcc main.cpp -o index.html -s WASM=1
```

---

## 4. Паметта в WebAssembly

WASM използва **Linear Memory** – голям непрекъснат блок от памет (ArrayBuffer в JS).
*   C++ кодът вижда тази памет като нормална RAM.
*   **Предизвикателство:** Указателите в WASM са 32-битови (в момента), което ограничава паметта до 4GB.

---

## 5. Интеграция с JavaScript

Можете да викате C++ функции от JS и обратно.
```cpp
#include <emscripten/bind.h>

std::string say_hello() { return "Hello from C++!"; }

EMSCRIPTEN_BINDINGS(my_module) {
    emscripten::function("sayHello", &say_hello);
}
```
В браузъра:
```javascript
const msg = Module.sayHello();
console.log(msg);
```

---

## 6. Производителност и Ограничения

### 6.1. Предимства
*   **Скорост:** До 10-20 пъти по-бърз от JS за математически задачи.
*   **Преносимост:** Пишете веднъж, работи на всеки браузър и всяка ОС.

### 6.2. Ограничения
*   **Няма директен достъп до DOM:** WASM трябва да "говори" с JS, за да промени нещо на екрана.
*   **Няма многонишковост (традиционна):** Използват се Web Workers, което е по-сложно.

---

## 7. Професионално обобщение
*   Използвайте **WebAssembly** за тежки изчисления, обработка на звук/видео и криптография в уеб.
*   Използвайте **Emscripten** като ваша стандартна среда.
*   WASM не замества JavaScript – той го допълва там, където скоростта е критична.
