# STL Алгоритми (STL Algorithms) в C++ - Пълно техническо ръководство

## 1. Въведение: Сърцето на Standard Template Library

Един от основните принципи на C++ е: **"Не пиши ръчни цикли, ако има алгоритъм за това"**.
Библиотеката `<algorithm>` съдържа над 100 високо оптимизирани, генерични функции. Те отделят **логиката** (какво правим) от **структурата** (върху какво го правим).

Защо да ги ползваме?
1.  **Ефективност:** Писани са от експерти и често ползват SIMD инструкции.
2.  **Коректност:** Няма off-by-one грешки или невалидни итератори.
3.  **Четимост:** `std::sort` говори повече от 10 реда `for` цикли.

---

## 2. Философията на Итераторите

Алгоритмите в C++ не "знаят" нищо за контейнерите (`vector`, `list`). Те работят върху **диапазони (Ranges)**, дефинирани от два итератора: `[first, last)`.
*   `first`: Сочи към първия елемент.
*   `last`: Сочи **след** последния елемент (Past-the-end).

**Категории итератори:**
Алгоритмите изискват определено ниво на достъп:
*   **Input Iterator:** `std::find` (еднопосочно четене).
*   **Forward Iterator:** `std::replace` (еднопосочно писане).
*   **Bidirectional Iterator:** `std::reverse` (нужда от `--it`).
*   **Random Access Iterator:** `std::sort` (нужда от `it + 5`).

---

## 3. Категории Алгоритми (Deep Dive)

### 3.1. Немодифициращи (Read-Only)
Те само анализират данните.
*   **`std::all_of` / `any_of` / `none_of`**: Предикатна логика.
    ```cpp
    bool hasZero = std::any_of(v.begin(), v.end(), [](int i){ return i == 0; });
    ```
*   **`std::count` / `count_if`**: Броене.
*   **`std::find` / `find_if`**: Линейно търсене.

### 3.2. Модифициращи (Write/Reorder)
Променят съдържанието или реда.
*   **`std::copy` / `copy_if`**: Копиране.
*   **`std::transform`**: Map операция (прилага функция върху всеки елемент).
    ```cpp
    std::transform(v.begin(), v.end(), v.begin(), [](int x) { return x * x; });
    ```
*   **`std::remove_if`**: Премества "изтритите" елементи накрая (Erase-Remove Idiom).

### 3.3. Сортиране и Бинарно Търсене
Това е "тежката артилерия".
*   **`std::sort`**: O(N log N). Използва IntroSort (Mix от QuickSort, HeapSort и InsertionSort).
*   **`std::partial_sort`**: Сортира само първите K елемента (полезно за Top 10).
*   **`std::binary_search`**: Връща `true/false`.
*   **`std::lower_bound`**: Връща итератор към първия елемент `>= val`.

## 4. Паралелни Алгоритми (C++17)

С навлизането на многоядрените процесори, C++17 добави "Execution Policies" в `<execution>`.

```cpp
#include <execution>
#include <algorithm>

std::sort(std::execution::par, v.begin(), v.end()); // Паралелно сортиране!
```

**Политики:**
1.  **`seq`**: Последователно (стандартно).
2.  **`par`**: Паралелно (на нишки).
3.  **`par_unseq`**: Паралелно и векторизирано (SIMD). Изисква много чисти функции без странични ефекти.

## 5. C++20 Ranges: Бъдещето

В C++20 алгоритмите бяха преосмислени. Библиотеката `<ranges>` позволява композиция (Pipe syntax) и мързеливо изпълнение (Lazy Evaluation).

```cpp
// Старо:
std::sort(v.begin(), v.end());

// C++20:
std::ranges::sort(v);

// Композиция (Pipeline):
auto result = v | std::views::filter([](int i){ return i % 2 == 0; })
                | std::views::transform([](int i){ return i * i; });
```
Това прави кода декларативен и четим като SQL или LINQ.

## 6. Професионално обобщение

1.  **Познавайте библиотеката:** Прегледайте списъка с алгоритми поне веднъж (`cppreference.com`). Често има специализиран алгоритъм за вашата нужда (напр. `std::rotate`).
2.  **Ламбди:** Ползвайте ги активно за къстъм предикати.
3.  **Binary Search:** Ако данните са сортирани, винаги ползвайте `std::lower_bound` вместо `std::find`. Разликата е O(log N) срещу O(N).
4.  **Erase-Remove:** Не забравяйте да извикате `v.erase()` след `std::remove()`, иначе размерът на вектора няма да се промени.
