# STL Алгоритми (STL Algorithms) в C++

## 1. Въведение

Standard Template Library (STL) предоставя не само контейнери (като `vector`, `map`), но и мощен набор от **генерични алгоритми** за работа с тях. Те са дефинирани в заглавния файл `<algorithm>`.

Алгоритмите работят върху **диапазони** (ranges), дефинирани от итератори (напр. `begin()` и `end()`). Това ги прави независими от конкретния тип на контейнера.

---

## 2. Немодифициращи Алгоритми (Non-modifying)

Тези алгоритми само четат данните, без да ги променят.

### 2.1. `std::for_each`
Прилага функция върху всеки елемент.

```cpp
std::vector<int> v = {1, 2, 3};
std::for_each(v.begin(), v.end(), [](int n) {
    std::cout << n << " ";
});
```

### 2.2. `std::find` и `std::find_if`
Търсене на елемент.
*   `find`: Търси по стойност.
*   `find_if`: Търси по условие (предикат).

```cpp
auto it = std::find(v.begin(), v.end(), 2);
if (it != v.end()) std::cout << "Found 2";

auto it2 = std::find_if(v.begin(), v.end(), [](int n){ return n > 2; });
```

### 2.3. `std::count` и `std::count_if`
Брои срещанията.

```cpp
int evens = std::count_if(v.begin(), v.end(), [](int n){ return n % 2 == 0; });
```

---

## 3. Модифициращи Алгоритми (Modifying)

Променят съдържанието на контейнера.

### 3.1. `std::sort`
Най-използваният алгоритъм. Сортира елементите в O(N log N).

```cpp
std::vector<int> nums = {5, 1, 4, 2, 3};
std::sort(nums.begin(), nums.end()); // 1, 2, 3, 4, 5

// Сортиране с къстъм компаратор (низходящо)
std::sort(nums.begin(), nums.end(), std::greater<int>());
```

### 3.2. `std::transform`
Прилага операция върху всеки елемент и записва резултата (подобно на `map` във функционалните езици).

```cpp
std::vector<int> out;
out.resize(nums.size());

// Удвоява всеки елемент и записва в out
std::transform(nums.begin(), nums.end(), out.begin(), 
               [](int n) { return n * 2; });
```

### 3.3. `std::fill` и `std::generate`
*   `fill`: Запълва диапазона с еднаква стойност.
*   `generate`: Запълва диапазона с резултат от функция.

```cpp
std::fill(v.begin(), v.end(), 0); // Всичко става 0

int i = 0;
std::generate(v.begin(), v.end(), [&i](){ return ++i; }); // 1, 2, 3...
```

---

## 4. Други полезни алгоритми

*   `std::reverse`: Обръща реда на елементите.
*   `std::rotate`: Завърта елементите.
*   `std::unique`: Премахва **последователни** дубликати (често се ползва след `sort`).
*   `std::binary_search`: Бързо търсене в сортиран масив O(log N).
*   `std::min_element` / `std::max_element`: Намира най-малкия/големия елемент.

---

## 5. `<numeric>` алгоритми

В заглавния файл `<numeric>` има математически алгоритми.

*   `std::accumulate`: Сумира елементите (или друга редукция).
    ```cpp
    int sum = std::accumulate(v.begin(), v.end(), 0);
    ```
