# STL Алгоритми (STL Algorithms) в C++ - Пълно техническо ръководство

## 1. Въведение: Силата на Декларативното Програмиране

C++ Standard Template Library (STL) алгоритмите са може би най-подценяваната част от езика. Много програмисти все още пишат ръчни `for` цикли за търсене, броене или копиране на елементи.

Златното правило на C++ експерта (Шон Парент) е: **"No raw loops" (Никакви сурови цикли)**.

Ако пишете `for` цикъл, вие описвате *как* да се направи нещо. Ако използвате `std::algorithm`, вие казвате *какво* искате да постигнете. Това прави кода:
1.  **По-изразителен:** Името на алгоритъма документира намерението.
2.  **По-безопасен:** Елиминира грешките с индексите (off-by-one errors).
3.  **По-бърз:** STL имплементациите често са ръчно оптимизирани и могат да използват SIMD инструкции.

Всички алгоритми живеят в заглавния файл `<algorithm>` (и `<numeric>` за математическите).

---

## 2. Анатомия на Алгоритмите: Итератори и Диапазони

Почти всички STL алгоритми работят върху двойка итератори `[first, last)`.
*   `first`: Сочи към началото на обработвания диапазон.
*   `last`: Сочи към позицията **след** последния елемент ("past-the-end"). Този елемент никога не се обработва.

```cpp
std::vector<int> v = {1, 5, 3, 9, 2};
std::sort(v.begin(), v.end()); // Сортира целия вектор
```

## 3. Класификация и Примери от Реалния Свят

### 3.1. Алгоритми за Търсене (Search)
Вместо да въртите цикъл и да пишете `if (x == val) break;`:

*   **`std::find`**: Търси стойност. Връща итератор към първото срещане или `end()`, ако не е намерено.
*   **`std::find_if`**: Търси елемент, отговарящ на условие (предикат).
    ```cpp
    // Намери първото четно число
    auto it = std::find_if(v.begin(), v.end(), [](int n){ return n % 2 == 0; });
    ```
*   **`std::all_of` / `any_of` / `none_of`**: Проверяват дали условието важи за всички/някои/нито един елемент.
    ```cpp
    if (std::all_of(users.begin(), users.end(), [](auto& u){ return u.isActive(); })) {
        std::cout << "All users are active!";
    }
    ```

### 3.2. Алгоритми за Модификация (Modify)
*   **`std::fill`**: Запълва диапазон с една стойност.
*   **`std::iota`** (в `<numeric>`): Запълва с поредица (1, 2, 3...). Много полезно за тестови данни.
*   **`std::transform`**: Еквивалентът на `map` във функционалното програмиране. Прилага функция върху всеки елемент и записва резултата.
    ```cpp
    std::vector<int> squares;
    // v = {1, 2, 3} -> squares = {1, 4, 9}
    std::transform(v.begin(), v.end(), std::back_inserter(squares), 
                   [](int x) { return x * x; });
    ```
*   **`std::replace` / `replace_if`**: Заменя стойности.

### 3.3. Изтриване на елементи: Idioma Erase-Remove
Това е най-честото объркване в STL. Алгоритмите **не могат** да променят размера на контейнера. Те само местят елементи.
`std::remove` премества всички елементи, които *не* са за триене, в началото на вектора и връща итератор към новия логически край. "Изтритите" елементи остават в края със стари/невалидни стойности.

```cpp
// Грешно:
std::remove(v.begin(), v.end(), 99); // Размерът на v не се променя!

// Правилно (преди C++20):
v.erase(std::remove(v.begin(), v.end(), 99), v.end());

// Правилно (C++20):
std::erase(v, 99); // Удобна wrapper функция
```

### 3.4. Сортиране и Подредба
*   **`std::sort`**: Стандартно сортиране (O(N log N)). Не е стабилно (може да размени реда на равни елементи).
*   **`std::stable_sort`**: Запазва реда на равните елементи. По-бавно и изисква повече памет.
*   **`std::partial_sort`**: Сортира само първите K елемента (напр. "Топ 10 резултата"). Много по-бързо от пълно сортиране, ако ви трябва само част от резултата.
*   **`std::nth_element`**: Поставя N-тия елемент на правилното му място, така че всички преди него са по-малки, а всички след него – по-големи. Използва се за намиране на медиана.

### 3.5. Работа с множество (Set Operations)
Ако имате два **сортирани** диапазона, можете да правите бързи операции:
*   `std::set_intersection`: Сечение (общи елементи).
*   `std::set_union`: Обединение.
*   `std::set_difference`: Разлика.
*   `std::merge`: Слива два сортирани диапазона в един.

## 4. C++17 Parallel Algorithms

C++17 въведе революционна промяна: възможността алгоритмите да се изпълняват паралелно (multi-threaded) или векторизирано (SIMD) само чрез добавяне на един параметър – **Execution Policy**.

```cpp
#include <execution>
#include <algorithm>

std::vector<int> huge_data(1000000);
// ...

// Стандартно (една нишка)
std::sort(std::execution::seq, huge_data.begin(), huge_data.end());

// Паралелно (ползва всички ядра на CPU)
std::sort(std::execution::par, huge_data.begin(), huge_data.end());

// Паралелно + Векторизирано (Unsequenced)
std::sort(std::execution::par_unseq, huge_data.begin(), huge_data.end());
```
⚠️ **Внимание:** При `par` и `par_unseq` вие носите отговорност да нямате "Race Conditions" в ламбда функциите или операторите за сравнение. Те трябва да са Thread-safe.

## 5. C++20 Ranges: Новата ера

C++20 въведе библиотеката `<ranges>`, която решава проблема с "двойките итератори". Вече можем да подаваме целия контейнер.

```cpp
// Преди:
std::sort(v.begin(), v.end());

// C++20:
std::ranges::sort(v);
```

### Views и Pipes (Композиция)
Най-мощната част на Ranges са "изгледите" (Views). Те са мързеливи (lazy) операции, които не копират данни, а създават прозорец към тях. Могат да се навързват с оператора `|` (като в Linux shell).

```cpp
#include <ranges>

auto result = v 
    | std::views::filter([](int i){ return i % 2 == 0; }) // Вземи само четните
    | std::views::transform([](int i){ return i * i; })   // Повдигни на квадрат
    | std::views::take(5);                                // Вземи първите 5
    
// Нищо не се е сметнало дотук!
// Смятането започва чак когато итерираме:
for (int i : result) {
    std::cout << i << " ";
}
```
Това позволява писане на изключително експресивен и ефективен код без междинни алокации на памет.

## 6. Професионални съвети

1.  **Ламбда функции:** Научете се да пишете кратки и ясни ламбди. Те са основният начин за къстъмизиране на алгоритмите (custom comparators, predicates).
2.  **Binary Search:** Ако данните са сортирани, `std::find` (O(N)) е грешка. Използвайте `std::binary_search` (за проверка) или `std::lower_bound` (за намиране на позиция) – те са O(log N).
3.  **Не преоткривайте колелото:** Ако пишете цикъл, спрете и проверете `cppreference.com/w/cpp/algorithm`. Вероятно вече има функция за това, което правите (напр. `std::rotate`, `std::next_permutation`, `std::clamp`).
4.  **Четете документацията за сложност:** Знайте разликата между `std::sort` (N log N) и `std::list::sort` (оптимизиран за свързани списъци).
