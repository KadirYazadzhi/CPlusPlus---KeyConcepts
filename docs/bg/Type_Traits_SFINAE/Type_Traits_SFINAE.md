# Type Traits и SFINAE в C++ - Пълно техническо ръководство

## 1. Въведение: Програмиране на компилатора

Метапрограмирането в C++ ни позволява да пишем код, който се адаптира към типовете данни автоматично. Докато нормалните функции работят с обекти и стойности, шаблонното метапрограмиране работи с **типове** по време на компилация.

**Type Traits** (Свойства на типовете) и **SFINAE** (Substitution Failure Is Not An Error) са инструментите, които позволяват на библиотеките (като STL или Boost) да бъдат толкова гъвкави, безопасни и бързи. Те ни позволяват да питаме компилатора: *"Този тип число ли е?", "Има ли виртуален деструктор?", "Може ли да се копира?"*.

---

## 2. Type Traits: Задаване на въпроси

Библиотеката `<type_traits>` (въведена в C++11) предоставя стотици шаблонни структури, които ни казват свойствата на типа.

### 2.1. Основни проверки (Primary Type Categories)
*   `std::is_integral<T>`: Дали T е цяло число (int, char, long)?
*   `std::is_floating_point<T>`: Дали T е float/double?
*   `std::is_pointer<T>`: Дали T е указател?
*   `std::is_class<T>`: Дали T е потребителски тип?

### 2.2. Модификация на типове
Можем не само да питаме, но и да променяме типовете по време на компилация:
*   `std::remove_const<T>::type`: Премахва `const`.
*   `std::remove_reference<T>::type`: Премахва `&` или `&&`.
*   `std::decay<T>::type`: Премахва всичко (const, volatile, ref) и превръща масивите в указатели.

### 2.3. Практически пример: `if constexpr` (C++17)
Това е най-лесният начин да използваме Type Traits. Кодът, който не отговаря на условието, **буквално се изтрива** от компилатора и не се компилира.

```cpp
template <typename T>
void process(T val) {
    if constexpr (std::is_pointer_v<T>) {
        std::cout << "Обработвам указател: " << *val << "\n";
    } else {
        std::cout << "Обработвам стойност: " << val << "\n";
    }
}
```

## 3. SFINAE (Substitution Failure Is Not An Error)

⚠️ **КЛЮЧОВА КОНЦЕПЦИЯ:** Когато компилаторът се опитва да намери правилния шаблон за даден тип и се провали при заместването (Substitution), той **не дава грешка веднага**. Той просто "изтрива" този шаблон от списъка с кандидати и продължава да търси други.

Това поведение ни позволява да "включваме" и "изключваме" функции в зависимост от типа.

### 3.1. `std::enable_if`
Това е класическият инструмент (преди C++20) за SFINAE. Той разчита на факта, че ако условието е `false`, вътрешният тип `type` не съществува, което предизвиква грешка при заместване (SFINAE) и функцията се игнорира.

```cpp
// Тази функция съществува САМО ако T е число с плаваща запетая
template <typename T>
typename std::enable_if<std::is_floating_point<T>::value, T>::type
calculate(T x) { 
    return std::sqrt(x); 
}

// Тази функция съществува САМО ако T е цяло число
template <typename T>
typename std::enable_if<std::is_integral<T>::value, T>::type
calculate(T x) { 
    return x * x; 
}
```

## 4. Създаване на собствени Type Traits

Можете да напишете свой собствен Trait, за да проверите дали даден клас има специфичен метод (напр. `.serialize()`). Това използва тъмна магия с `decltype` и `void_t`.

```cpp
// Проверяваме дали T има метод .serialize()
template <typename T, typename = void>
struct has_serialize : std::false_type {};

template <typename T>
struct has_serialize<T, std::void_t<decltype(std::declval<T>().serialize())>> : std::true_type {};
```

## 5. Модерното бъдеще: Concepts (C++20)

В C++20, повечето нужди от SFINAE и грозния `enable_if` са заменени от **Concepts**. Те са по-бързи, по-четливи и дават човешки грешки.

```cpp
template <typename T>
concept Number = std::integral<T> || std::floating_point<T>;

void print(Number auto x) { // Приема само числа
    std::cout << x;
}
```
Ако подадете `std::string` на `print`, компилаторът ще каже: *"string does not satisfy concept Number"*.

---

## 6. Професионално обобщение

1.  **Оптимизация:** Type Traits позволяват на алгоритми като `std::copy` да използват `memcpy` за прости типове (POD) и цикъл за сложни обекти.
2.  **Интерфейси:** Използвайте ги, за да наложите ограничения върху шаблоните си.
3.  **Еволюция:** Започнете с `if constexpr`. Ако не стига, ползвайте Concepts (ако сте на C++20). Ползвайте `enable_if` само за поддръжка на стар код (C++11/14/17).
