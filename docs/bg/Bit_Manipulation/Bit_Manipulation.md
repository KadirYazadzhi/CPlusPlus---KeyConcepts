# Битови Манипулации (Bit Manipulation) - Пълно техническо ръководство

## 1. Въведение: Езикът на електроните
Битовите манипулации позволяват на C++ програмиста да работи директно с най-малката единица информация – бита (0 или 1). В свят, доминиран от абстракции от високо ниво, способността да манипулираш паметта на битово ниво остава критично умение за системното програмиране, криптографията, разработката на драйвери и игрови двигатели.

---

## 2. Фундаментални оператори (The Toolbox)

### 2.1. Логически операции
*   **AND (`&`):** Резултатът е 1 само ако и двата входни бита са 1. Използва се за **маскиране** (извличане на специфични битове).
*   **OR (`|`):** Резултатът е 1 ако поне един от битовете е 1. Използва се за **вдигане на флагове**.
*   **XOR (`^`):** Резултатът е 1 ако битовете са различни. Използва се за **обръщане (toggle)** на състояние и в прости криптиращи алгоритми.
*   **NOT (`~`):** Побитово отрицание. Обръща всички 0 в 1 и обратно.

### 2.2. Побитови измествания (Shifts)
*   **Left Shift (`<<`):** Мести битовете наляво, запълвайки с 0 отдясно. Всеки скок е умножение по 2.
*   **Right Shift (`>>`):** Мести битовете надясно. При `unsigned` запълва с 0, при `signed` поведението зависи от знака (аритметично изместване).

---

## 3. Битови "Хакове" (Expert Techniques)

### 3.1. Проверка на бит (Is bit N set?)
```cpp
bool is_set = (value & (1 << n)) != 0;
```

### 3.2. Вдигане на бит (Set bit N)
```cpp
value |= (1 << n);
```

### 3.3. Изчистване на бит (Clear bit N)
```cpp
value &= ~(1 << n);
```

### 3.4. Проверка за степен на двойката
Най-елегантният трик: `(n > 0) && ((n & (n - 1)) == 0)`.

---

## 4. Модерен C++: Библиотеката `<bit>` (C++20)
Преди C++20 програмистите използваха специфични за компилатора функции (напр. `__builtin_popcount`). Вече имаме стандартен път:
*   `std::popcount(n)`: Връща броя на битовете със стойност 1.
*   `std::countl_zero(n)`: Брои водещите нули (критично за алгоритми за компресия).
*   `std::bit_cast<T>(u)`: Най-бързият и безопасен начин за преобразуване на типове чрез преинтерпретация на битовете (напр. от `double` към `uint64_t`).

---

## 5. Системно приложение: Битови полета (Bit-fields)
C++ позволява дефинирането на структури, където променливите заемат точно определен брой битове:
```cpp
struct Header {
    unsigned int version : 4;
    unsigned int type    : 4;
    unsigned int length  : 24;
}; // Цялата структура заема точно 32 бита (4 байта).
```

---

## 6. Професионално обобщение
*   Битовите операции са **константни по време (O(1))** и се изпълняват директно от ALU на процесора за 1 такт.
*   Използвайте ги за **икономия на памет** (напр. съхраняване на 8 булеви стойности в 1 байт).
*   Винаги използвайте `unsigned` типове при работа с битове, за да избегнете неочаквано поведение със знаковия бит.
