# Битови Манипулации (Bit Manipulation) - Пълно техническо ръководство

## 1. Въведение: Езикът на електроните

Битовите манипулации позволяват на C++ програмиста да работи директно с най-малката единица информация – бита (0 или 1). В свят, доминиран от абстракции от високо ниво, способността да манипулираш паметта на битово ниво остава критично умение за системното програмиране, криптографията, разработката на драйвери, мрежовите протоколи и игрови двигатели (където всеки байт е от значение).

---

## 2. Фундаментални оператори (The Toolbox)

### 2.1. Логически операции
*   **AND (`&`):** Резултатът е 1 само ако и двата входни бита са 1.
    *   *Приложение:* **Маскиране** (извличане на специфични битове). `x & 0xFF` взима само последния байт.
*   **OR (`|`):** Резултатът е 1 ако поне един от битовете е 1.
    *   *Приложение:* **Вдигане на флагове**. `flags | READ_ONLY`.
*   **XOR (`^`):** Резултатът е 1 ако битовете са различни.
    *   *Приложение:* **Обръщане (toggle)** и криптиране. `x ^ x` винаги е 0.
*   **NOT (`~`):** Побитово отрицание. Обръща всички 0 в 1 и обратно.

### 2.2. Побитови измествания (Shifts)
*   **Left Shift (`<<`):** Мести битовете наляво, запълвайки с 0 отдясно.
    *   `x << N` е еквивалентно на `x * 2^N`.
*   **Right Shift (`>>`):** Мести битовете надясно.
    *   `x >> N` е еквивалентно на `x / 2^N`.
    *   ⚠️ **Внимание:** При `signed` типове (напр. `int`), поведението зависи от компилатора (Arithmetic Shift – запазва знака, или Logical Shift). Винаги ползвайте `unsigned` за битови операции!

## 3. Битови "Хакове" (Expert Techniques)

Това са класически алгоритми, които избягват бавни разклонения (`if/else`).

### 3.1. Основни манипулации на N-тия бит
```cpp
// Проверка дали бит N е 1
bool is_set = (value & (1 << n)) != 0;

// Вдигане на бит N (Set to 1)
value |= (1 << n);

// Изчистване на бит N (Set to 0)
value &= ~(1 << n);

// Обръщане на бит N (Toggle)
value ^= (1 << n);
```

### 3.2. Математически трикове
*   **Четно/Нечетно:** `(x & 1) == 0` (по-бързо от `x % 2`).
*   **Степен на двойката:** `(n > 0) && ((n & (n - 1)) == 0)`.
*   **Размяна без temp (XOR Swap):**
    ```cpp
    a ^= b; b ^= a; a ^= b;
    ```

## 4. Модерен C++: Библиотеката `<bit>` (C++20)

Преди C++20 програмистите използваха специфични за компилатора функции (напр. `__builtin_popcount` в GCC). Вече имаме преносим стандарт:

*   **`std::popcount(n)`:** Връща броя на битовете със стойност 1 (Population Count / Hamming Weight).
*   **`std::countl_zero(n)`:** Брои водещите нули (Count Leading Zeros). Важно за логаритмични алгоритми.
*   **`std::bit_width(n)`:** Минималният брой битове за представяне на числото.
*   **`std::bit_cast<T>(u)`:** Най-бързият и безопасен начин за преобразуване на типове чрез преинтерпретация на битовете (напр. от `float` към `uint32_t` за бърз инверсен корен).

## 5. Битови полета и std::bitset

### 5.1. C-Style Bit-fields
Позволява пакетиране на данни в структура:
```cpp
struct PacketHeader {
    uint32_t version : 4;  // 4 бита
    uint32_t type    : 4;  // 4 бита
    uint32_t id      : 24; // 24 бита
}; // Общо 32 бита (4 байта)
```

### 5.2. std::bitset
C++ клас за работа с масив от битове. По-удобен от `int`, защото поддържа `operator[]` и `to_string()`.
```cpp
std::bitset<8> b("10101010");
b.flip(0); // 10101011
```

## 6. Ендианност (Endianness)

Как се записва `0x12345678` в паметта?
*   **Big-Endian:** `12 34 56 78` (Най-старшият байт първи - Мрежови стандарт).
*   **Little-Endian:** `78 56 34 12` (Най-младшият първи - x86/ARM стандарт).

C++20 добавя `std::endian::native`, за да проверите системата си по време на компилация.

## 7. Професионално обобщение

1.  **Unsigned:** Винаги използвайте `uint32_t` / `uint64_t` за битови маски.
2.  **Performance:** Битовите операции са **константни по време (O(1))** и се изпълняват за 1 такт на процесора. Те са по-бързи от събирането и умножението.
3.  **Flags:** Използвайте `enum class` с битови оператори за типобезопасни флагове.
