# Битови Манипулации (Bit Manipulation) в C++ - Пълно ръководство

## 1. Въведение: Силата на битовете
Битовите манипулации позволяват работа с данните на най-ниско ниво – индивидуалните битове (0 и 1). Това е критично за системното програмиране, писането на драйвери, криптографията и оптимизацията на паметта, където всеки байт е от значение.

---

## 2. Битови Оператори

*   **AND (`&`):** Резултатът е 1 само ако и двата бита са 1. (За проверка на флагове).
*   **OR (`|`):** Резултатът е 1 ако поне един от битовете е 1. (За вдигане на флагове).
*   **XOR (`^`):** Резултатът е 1 ако битовете са различни. (За обръщане на състояние).
*   **NOT (`~`):** Инвертира всички битове.
*   **Shifts (`<<`, `>>`):** Местят битовете наляво или надясно. `x << 1` е еквивалентно на умножение по 2.

---

## 3. Чести техники (Bit Hacks)

### 3.1. Проверка дали число е четно
```cpp
bool is_even = (n & 1) == 0;
```

### 3.2. Проверка дали число е степен на двойката
```cpp
bool is_power_of_two = n && !(n & (n - 1));
```

### 3.3. Работа с маски (Flags)
```cpp
const unsigned int FLAG_A = 1 << 0;
const unsigned int FLAG_B = 1 << 1;

unsigned int my_flags = 0;
my_flags |= FLAG_A; // Включване
if (my_flags & FLAG_A) { /* Активирано */ }
```

---

## 4. C++20 Библиотека `<bit>`
Новият стандарт стандартизира много функции, които преди бяха специфични за компилатора:
*   `std::popcount`: Брои единиците в числото.
*   `std::countl_zero`: Брои водещите нули.
*   `std::bit_cast`: Безопасно преобразуване на битовете от един тип в друг (напр. `double` към `long`).

---

## 5. std::bitset
Ако ви трябва масив от битове с произволен размер, ползвайте `std::bitset<N>`. Той предоставя удобен интерфейс за работа с битове като масив.
