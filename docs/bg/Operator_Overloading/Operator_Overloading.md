# Предефиниране на Оператори (Operator Overloading) - Пълно техническо ръководство

## 1. Въведение: Синтактичната захар на C++

Предефинирането на оператори е мощна характеристика на C++, която позволява на вашите потребителски класове да се държат като примитивни типове. Вместо да пишете тромав код като `matrixA.add(matrixB).multiply(matrixC)`, можете да напишете елегантното `(matrixA + matrixB) * matrixC`.

Това не е само за естетика – това е критично за писането на математически библиотеки (Linear Algebra), физични енджини, Smart Pointers и итератори.

---

## 2. Златните правила на дизайна

Преди да напишете и един ред код, трябва да знаете ограниченията:
1.  **Не можете да създавате нови оператори:** Не можете да дефинирате `operator@`. Само съществуващите (`+`, `-`, `*`, `[]`, `->` и т.н.).
2.  **Не можете да променяте приоритета:** `*` винаги ще се изпълнява преди `+`, независимо какво правят вашите функции.
3.  **Не можете да променяте арността:** Унарният `!` винаги ще приема един аргумент.
4.  **Поне един операнд трябва да е потребителски тип:** Не можете да промените как `int + int` работи.

## 3. Член-функция срещу Глобална (Friend) функция

### 3.1. Член-функция (Member Function)
Дефинира се вътре в класа.
*   **Синтаксис:** `Complex operator+(const Complex& other) const;`
*   **Особеност:** Левият операнд (`*this`) **задължително** е обект от вашия клас.
*   **Кога:** За оператори, които променят състоянието на обекта (`+=`, `-=`, `=`, `[]`, `->`, `()`).

### 3.2. Глобална функция (Non-member / Friend)
Дефинира се извън класа (често маркирана като `friend` за достъп до `private` данни).
*   **Синтаксис:** `friend Complex operator+(const Complex& lhs, const Complex& rhs);`
*   **Предимство:** Позволява **Implicit Conversion** (имплицитно преобразуване) на левия операнд.
    *   Ако `operator+` е член, `c1 + 5` работи, но `5 + c1` **НЕ работи** (защото `5` няма метод `operator+`).
    *   Ако е глобална, и двете работят!

## 4. Специални оператори: Deep Dive

### 4.1. Вход/Изход (`<<` и `>>`)
Те винаги трябва да са глобални `friend` функции.
*   **Защо?** Левият операнд е `std::ostream` (`cout`), а вие не можете да добавите методи към класа `std::ostream`.
```cpp
friend std::ostream& operator<<(std::ostream& os, const MyClass& obj) {
    os << obj.data;
    return os; // Връщаме потока за chaining (cout << a << b)
}
```

### 4.2. Присвояване (`operator=`) и Rule of Five
Това е най-сложният оператор. Той трябва да се справи с:
1.  **Self-assignment check:** `a = a;` не трябва да прави нищо (или поне да не чупи обекта).
2.  **Resource Management:** Трябва да изтрие старата памет и да задели нова (или да открадне ресурса при `move assignment`).
3.  **Return `*this`:** За да позволи `a = b = c;`.

### 4.3. Индексиране (`operator[]`)
Обикновено трябва да дефинирате **две** версии:
1.  `T& operator[](size_t index);` - За писане (`vec[0] = 5`).
2.  `const T& operator[](size_t index) const;` - За четене от константни обекти.

### 4.4. Functor (`operator()`)
Прави обекта да изглежда като функция. Това е основата на ламбда изразите и много STL алгоритми.

## 5. Инкремент и Декремент (`++`, `--`)

Как компилаторът различава префикс (`++i`) от постфикс (`i++`)? Чрез фиктивен параметър `int`.

1.  **Prefix (`++i`):**
    *   Увеличава и връща референция към новото състояние.
    *   Бързо и ефективно.
    *   `Type& operator++();`

2.  **Postfix (`i++`):**
    *   Прави копие на старото състояние, увеличава обекта, връща копието.
    *   **Бавно!** Създава временен обект.
    *   `Type operator++(int);` // int е dummy

**Съвет:** Винаги предпочитайте префиксния оператор (`++it`) в цикли.

## 6. Професионално обобщение

1.  **Semantics:** Не предефинирайте `+` да прави изваждане. Следвайте интуицията на математиката.
2.  **Chaining:** Винаги връщайте `Type&` за оператори, които модифицират обекта (`+=`, `=`), за да позволите вериги.
3.  **Efficiency:** Операторите `+`, `-`, `*` връщат нов обект по стойност. Операторите `+=`, `-=` връщат референция. Често е по-ефективно да имплементирате `+=` и после да дефинирате `+` чрез него.
    ```cpp
    T operator+(T lhs, const T& rhs) { // lhs е копие
        lhs += rhs;
        return lhs;
    }
    ```
