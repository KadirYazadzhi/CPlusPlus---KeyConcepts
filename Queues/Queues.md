# Опашки (Queues) в C++

## 1. Въведение

Опашката е линейна структура от данни, която следва принципа **FIFO (First-In, First-Out)** – Първи влязъл, първи излязъл. Това е точно както опашката в магазина: човекът, който се нареди пръв, бива обслужен пръв.

### Основни приложения:
*   Управление на задачи в операционни системи (Task Scheduling).
*   Буфериране на данни (IO Buffers, стрийминг на видео).
*   Алгоритми за обхождане в ширина (BFS - Breadth First Search).
*   Принтерни опашки (заявките се печатат в реда на постъпване).

---

## 2. Основни операции

Опашката има два края: **Front** (начало) и **Back** (край). Добавянето става отзад, а премахването – отпред.

Времевата сложност за всички основни операции е **O(1)**.

1.  **push:** Добавя елемент в края на опашката (enqueue).
2.  **pop:** Премахва елемента от началото на опашката (dequeue).
3.  **front:** Връща стойността на първия елемент.
4.  **back:** Връща стойността на последния елемент.
5.  **empty:** Проверява дали опашката е празна.
6.  **size:** Връща броя на елементите.

---

## 3. Използване на `std::queue`

В C++ STL опашката е реализирана в заглавния файл `<queue>`.

```cpp
#include <iostream>
#include <queue>

int main() {
    std::queue<std::string> q;

    // 1. Добавяне (Push)
    q.push("Client 1");
    q.push("Client 2");
    q.push("Client 3");

    // Опашката сега е: [Front] "Client 1", "Client 2", "Client 3" [Back]

    // 2. Достъп до елементи
    std::cout << "Front: " << q.front() << std::endl; // Client 1
    std::cout << "Back:  " << q.back()  << std::endl; // Client 3

    // 3. Премахване (Pop)
    q.pop(); // Премахва "Client 1"
    
    std::cout << "New Front: " << q.front() << std::endl; // Client 2

    // 4. Обхождане
    std::cout << "Remaining queue: ";
    while (!q.empty()) {
        std::cout << q.front() << " ";
        q.pop();
    }
    // Резултат: Client 2 Client 3

    return 0;
}
```

## 4. Видове Опашки

Освен стандартната опашка, C++ предоставя и специализирани версии:

### 4.1. Двустранна опашка (Deque - Double Ended Queue)
Позволява добавяне и премахване и от двата края. Разгледана е в отделна тема (Deque).

### 4.2. Опашка с приоритет (Priority Queue)
Елементите не са подредени по ред на постъпване, а по "важност" (приоритет). Най-големият елемент винаги излиза пръв. Разгледана е в отделна тема.

## 5. Пример: BFS (Breadth-First Search)

Най-известният алгоритъм, използващ опашка, е търсенето в ширина в графи или дървета.

Представете си, че търсим най-краткия път в лабиринт или връзки в социална мрежа ("приятели на приятели").

```cpp
#include <iostream>
#include <vector>
#include <queue>

// Представяне на граф чрез списък на съседство
std::vector<std::vector<int>> adj = {
    {1, 2},    // Възел 0 е свързан с 1 и 2
    {0, 3, 4}, // Възел 1 е свързан с 0, 3, 4
    {0},       // Възел 2 е свързан с 0
    {1},       // Възел 3 е свързан с 1
    {1}        // Възел 4 е свързан с 1
};

void bfs(int startNode) {
    std::vector<bool> visited(5, false);
    std::queue<int> q;

    visited[startNode] = true;
    q.push(startNode);

    while (!q.empty()) {
        int currentNode = q.front();
        q.pop();
        
        std::cout << currentNode << " "; // Обработваме възела

        // Добавяме всички непосетени съседи
        for (int neighbor : adj[currentNode]) {
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                q.push(neighbor);
            }
        }
    }
}
// Резултат от bfs(0): 0 1 2 3 4
```

## 6. Циклична Опашка (Circular Queue)

Когато имплементираме опашка с масив с фиксиран размер, срещаме проблем: ако само местим индекса `front` напред при `pop`, освободеното място в началото на масива остава неизползваемо ("мъртва зона").

Решението е **Циклична опашка** (Ring Buffer). Когато стигнем края на масива, индексът "завърта" обратно към началото (ако там е свободно).

Индексът се изчислява чрез модулна аритметика:
`nextIndex = (currentIndex + 1) % capacity`

Това се използва често в embedded системи и драйвери за буфериране на данни.

---

## 7. Ръчна имплементация (Linked List базирана)

Динамична опашка може лесно да се реализира със свързан списък. Поддържаме два указателя: `head` (за front) и `tail` (за back).

*   `push(val)`: Добавя нов възел след `tail` и премества `tail`.
*   `pop()`: Мести `head` към следващия възел и трие стария.

---

## 8. Обобщение

*   Опашката е FIFO структура.
*   Използвайте `std::queue` за повечето задачи.
*   Ключови операции: `push` (отзад), `pop` (отпред), `front`.
*   Незаменима при асинхронна обработка на данни и BFS алгоритми.
