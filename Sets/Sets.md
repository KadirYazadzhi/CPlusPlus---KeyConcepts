# Множества (Sets) в C++

## 1. Въведение

В C++, `std::set` е асоциативен контейнер, който съдържа **сортирани** и **уникални** обекти. Дефиниран е в заглавния файл `<set>`.

### Ключови характеристики:
*   **Уникалност:** Не може да има два еднакви елемента. Опитът за вмъкване на дубликат се игнорира.
*   **Сортиране:** Елементите винаги се поддържат сортирани (по подразбиране във възходящ ред: `<`).
*   **Имплементация:** Обикновено се реализира чрез **Червено-черно дърво** (Red-Black Tree) - вид балансирано двоично дърво за търсене.
*   **Сложност:** Основните операции (търсене, вмъкване, триене) са логаритмични: **O(log N)**.

---

## 2. Основни Операции

### 2.1. Създаване и Вмъкване (Insert)

```cpp
#include <iostream>
#include <set>

int main() {
    // Създава сет от цели числа, сортирани възходящо
    std::set<int> s;

    s.insert(10);
    s.insert(5);
    s.insert(20);
    s.insert(5); // Дубликат - няма да бъде добавен!

    // Сетът автоматично се подрежда: {5, 10, 20}
    std::cout << "Size: " << s.size() << std::endl; // 3

    return 0;
}
```

### 2.2. Промяна на реда на сортиране
Можем да подадем компаратор (функтор), за да променим подредбата, например в низходящ ред.

```cpp
// std::greater<int> е вграден функтор за намаляващ ред
std::set<int, std::greater<int>> descSet;
descSet.insert(10);
descSet.insert(20);
// Резултат: {20, 10}
```

## 3. Търсене на Елементи

Тъй като сетът е дървовидна структура, търсенето е много бързо.

### 3.1. Методът `find()`
Връща итератор към намерения елемент или `end()`, ако не е намерен.

```cpp
auto it = s.find(10);
if (it != s.end()) {
    std::cout << "Found: " << *it << std::endl;
} else {
    std::cout << "Not found" << std::endl;
}
```

### 3.2. Методът `count()`
Тъй като елементите са уникални, `count()` връща `1`, ако елементът присъства, и `0`, ако го няма. Удобно за булеви проверки.

```cpp
if (s.count(20)) { /* Съществува */ }
```

---

## 4. Изтриване на Елементи

Можем да трием по стойност или чрез итератор.

```cpp
s.erase(10); // Изтрива елемента със стойност 10

auto it = s.find(20);
if (it != s.end()) {
    s.erase(it); // Изтрива елемента, към който сочи итератора
}

s.clear(); // Изтрива всичко
```

---

## 5. Обхождане на Сет

Елементите в `std::set` са `const` (не могат да се променят директно), защото промяната на стойност би нарушила сортирането на дървото. Ако искате да промените елемент, трябва да го изтриете и добавите новия.

```cpp
std::set<std::string> names = {"Alice", "Charlie", "Bob"};

// Обхождане с Range-based for (C++11)
// Редът е азбучен: Alice, Bob, Charlie
for (const auto& name : names) {
    std::cout << name << " ";
}
```

## 6. Операции с обхвати (Lower/Upper Bound)

Това са мощни функции за търсене в сортирани последователности.

*   `lower_bound(k)`: Връща итератор към първия елемент, който е **>=** k.
*   `upper_bound(k)`: Връща итератор към първия елемент, който е **>** k (строго по-голям).

```cpp
std::set<int> nums = {10, 20, 30, 40, 50};

auto itLow = nums.lower_bound(30); // Сочи към 30
auto itUp = nums.upper_bound(30);  // Сочи към 40

// Изтриване на диапазон [30, 50) -> трие 30 и 40
nums.erase(itLow, nums.end()); 
```

## 7. Сет от потребителски обекти

За да съхраняваме наши класове/структури в `std::set`, трябва да дефинираме как те се сравняват (оператор `<`).

```cpp
struct Point {
    int x, y;

    // Предефиниране на оператор < (задължително за set)
    bool operator<(const Point& other) const {
        if (x != other.x) return x < other.x;
        return y < other.y;
    }
};

std::set<Point> points;
points.insert({1, 2});
points.insert({1, 5}); // Валидно, различно y
points.insert({1, 2}); // Дубликат, игнорира се
```

---

## 8. Обобщение

*   Използвайте `std::set`, когато ви трябва **уникалност** и **автоматично сортиране**.
*   Времева сложност: **O(log N)**.
*   Елементите са immutable (непроменяеми) - промяна чрез `erase` + `insert`.
*   За по-бързо търсене (**O(1)**), но без сортиране, използвайте `std::unordered_set` (базиран на хеш таблица).
