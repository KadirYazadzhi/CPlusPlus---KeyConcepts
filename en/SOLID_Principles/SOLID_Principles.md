# SOLID Principles in C++

## 1. Introduction

Five design principles for clean, maintainable, and extensible code.

---

## 2. Principles

*   **S:** Single Responsibility.
*   **O:** Open/Closed (Open for extension, closed for modification).
*   **L:** Liskov Substitution.
*   **I:** Interface Segregation.
*   **D:** Dependency Inversion.

---

## 3. Summary

Following SOLID leads to code that is easier to test and change without breaking existing logic.
