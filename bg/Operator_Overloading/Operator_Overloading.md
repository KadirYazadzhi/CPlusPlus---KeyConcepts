# Предефиниране на Оператори (Operator Overloading) в C++

## 1. Въведение

C++ позволява на операторите (`+`, `-`, `*`, `==`, `<<` и др.) да работят с потребителски дефинирани типове (класове и структури). Това се нарича **Operator Overloading**.

Това прави кода по-интуитивен и четим. Вместо `c3 = c1.add(c2)`, можем да напишем `c3 = c1 + c2`.

---

## 2. Синтаксис

Предефинирането става чрез дефиниране на функция със специално име `operator@`, където `@` е символът на оператора.

Тази функция може да бъде:
1.  **Член-функция (Member function):** Левият операнд е `this`.
2.  **Глобална функция (Non-member function):** Често се използва `friend` за достъп до private данните.

### 2.1. Пример: Събиране на комплексни числа

```cpp
class Complex {
public:
    double real, imag;

    Complex(double r = 0, double i = 0) : real(r), imag(i) {}

    // Член-функция
    Complex operator+(const Complex& other) const {
        return Complex(real + other.real, imag + other.imag);
    }
};

int main() {
    Complex c1(1.0, 2.0);
    Complex c2(3.0, 4.0);
    
    Complex c3 = c1 + c2; // Извиква c1.operator+(c2)
}
```

## 3. Предефиниране на Вход/Изход (<< и >>)

Операторите за потоци (`std::cout << obj`) са едни от най-често предефинираните. Те **задължително** трябва да бъдат имплементирани като глобални (friend) функции, защото левият операнд е `std::ostream` (който не е наш клас), а не нашият обект.

```cpp
#include <iostream>

class Point {
    int x, y;
public:
    Point(int x, int y) : x(x), y(y) {}

    // Friend декларация за достъп до private x и y
    friend std::ostream& operator<<(std::ostream& os, const Point& p);
};

// Дефиниция извън класа
std::ostream& operator<<(std::ostream& os, const Point& p) {
    os << "(" << p.x << ", " << p.y << ")";
    return os; // Връщаме потока за верижно извикване (cout << p << endl)
}

int main() {
    Point p(5, 10);
    std::cout << "Point: " << p << std::endl;
}
```

## 4. Други важни оператори

### 4.1. Оператори за сравнение (==, !=, <)
Необходими са, ако искате да ползвате обектите си в контейнери като `std::map`, `std::set` или да ги сортирате (`std::sort`).

```cpp
bool operator==(const Point& other) const {
    return x == other.x && y == other.y;
}
```

### 4.2. Оператор за присвояване (=)
Компилаторът генерира такъв по подразбиране (плитко копиране). Ако класът ви управлява динамична памет, задължително трябва да напишете свой (Deep Copy), за да избегнете проблеми (Rule of Three).

### 4.3. Унарен минус (-) и Инкремент (++)

```cpp
// Префиксен (++i)
Point& operator++() {
    x++; y++;
    return *this;
}

// Постфиксен (i++) - изисква dummy int параметър
Point operator++(int) {
    Point old = *this;
    operator++();
    return old;
}
```

### 4.4. Оператор за извикване на функция () - Functors
Позволява обектът да се държи като функция. Използва се много в STL алгоритмите.

```cpp
struct Multiplier {
    int factor;
    int operator()(int val) { return val * factor; }
};
```

## 5. Какво НЕ може да се предефинира?

*   Оператор за достъп до член `.`
*   Оператор за указател към член `.*`
*   Scope resolution `::`
*   Ternary operator `?:`
*   `sizeof`, `typeid`

Също така, не можете да създавате нови оператори (напр. `operator**` за степенуване).

---

## 6. Обобщение

*   Използвайте предефиниране разумно. `a + b` трябва да означава нещо интуитивно (събиране), а не "запиши във файл".
*   Ако операторът променя обекта (`+=`, `++`), върнете `*this` по референция.
*   Ако операторът създава нов обект (`+`, `-`), върнете по стойност.
*   Операторите `<<` и `>>` винаги са външни функции (friends).
