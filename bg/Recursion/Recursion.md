# Рекурсия (Recursion) в C++

## 1. Въведение

Рекурсията е техника в програмирането, при която **една функция извиква сама себе си**, за да реши по-малка инстанция на същия проблем.

Всяка рекурсивна функция се състои от два задължителни компонента:
1.  **Базов случай (Base Case):** Условие, при което функцията спира да се вика сама и връща конкретен резултат. Без него ще се получи безкраен цикъл и препълване на стека (Stack Overflow).
2.  **Рекурсивна стъпка (Recursive Step):** Частта, където функцията извиква себе си с променени аргументи, доближавайки се към базовия случай.

---

## 2. Класически пример: Факториел

Факториел от N (`N!`) е произведението на всички числа от 1 до N.
Математическа дефиниция:
*   `0! = 1`
*   `N! = N * (N-1)!`

```cpp
#include <iostream>

unsigned long long factorial(int n) {
    // 1. Базов случай
    if (n <= 1) return 1;

    // 2. Рекурсивна стъпка
    return n * factorial(n - 1);
}

int main() {
    std::cout << factorial(5); // 120
    return 0;
}
```

### Как работи (Trace):
`factorial(5)` вика `5 * factorial(4)`
  `factorial(4)` вика `4 * factorial(3)`
    `factorial(3)` вика `3 * factorial(2)`
      `factorial(2)` вика `2 * factorial(1)`
        `factorial(1)` връща `1` (Базов случай!)
      Връща `2 * 1 = 2`
    Връща `3 * 2 = 6`
  Връща `4 * 6 = 24`
Връща `5 * 24 = 120`

## 3. Рекурсия vs Итерация

Всеки рекурсивен алгоритъм може да се напише и итеративно (с цикли).

| Характеристика | Рекурсия | Итерация (Цикли) |
| :--- | :--- | :--- |
| **Код** | По-кратък, по-чист за определени задачи (дървета, графи). | По-дълъг, изисква повече променливи за състояние. |
| **Памет** | Използва Call Stack (O(N) памет). Риск от Stack Overflow. | Използва Heap или само регистри (O(1) памет често). |
| **Скорост** | По-бавно заради overhead при извикване на функция. | По-бързо (няма function calls). |

## 4. Числа на Фибоначи (Опасността от лоша рекурсия)

Числата на Фибоначи са: 0, 1, 1, 2, 3, 5, 8... (`F(n) = F(n-1) + F(n-2)`).

```cpp
// Наивна рекурсия (Много неефективна!)
int fib(int n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n - 2);
}
```

Този код има експоненциална сложност **O(2^N)**. За `fib(50)` компютърът ще замръзне. Причината е, че едни и същи стойности се преизчисляват милиони пъти.

**Решение:** Използване на **Memoization** (съхраняване на резултатите) или итеративен подход.

## 5. Tail Recursion (Опашкова рекурсия)

Това е специален вид рекурсия, където рекурсивното извикване е **последното действие** във функцията. Модерните компилатори могат да оптимизират това (Tail Call Optimization), превръщайки го автоматично в цикъл, за да пестят памет.

```cpp
// Опашкова рекурсия (accumulator се предава надолу)
void printDown(int n) {
    if (n == 0) return;
    std::cout << n << " ";
    printDown(n - 1); // Последно действие
}
```

## 6. Приложения на рекурсията

Рекурсията е незаменима при:
1.  **Обхождане на Дървета и Графи (DFS):** Директории във файлова система, DOM дърво на HTML.
2.  **Divide and Conquer Алгоритми:** Merge Sort, Quick Sort, Binary Search.
3.  **Backtracking:** Генериране на пермутации, решаване на Судоку, Лабиринти.

### Пример: Обхождане на директория (Псевдокод)
```cpp
void listFiles(Directory dir) {
    for (File f : dir.files) {
        if (f.isDirectory()) {
            listFiles(f); // Рекурсия
        } else {
            print(f.name);
        }
    }
}
```

## 7. Обобщение

*   Рекурсията е елегантен начин за решаване на задачи, които могат да се разбият на подобни подзадачи.
*   Винаги дефинирайте **базов случай**.
*   Внимавайте за препълване на стека (Stack Overflow) при твърде голяма дълбочина.
*   За линейни задачи (като факториел), итерацията често е по-ефективна. За дървовидни задачи, рекурсията е крал.
