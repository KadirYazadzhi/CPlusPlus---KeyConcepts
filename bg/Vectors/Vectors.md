# Вектори (Vectors) в C++

## 1. Въведение

`std::vector` е най-използваният контейнер в C++ (STL). Той представлява **динамичен масив**, който може да променя размера си автоматично при добавяне или премахване на елементи.

За разлика от обикновените масиви (`int arr[10]`), векторът управлява паметта си сам, което го прави много по-безопасен и гъвкав. Намира се в заглавния файл `<vector>`.

### Ключови предимства:
*   **Динамичен размер:** Расте и се свива според нуждите.
*   **Бърз достъп:** Достъпът по индекс е O(1), точно както при масивите.
*   **Съвместимост:** Съхранява елементите в непрекъснат блок памет (contiguous memory), което го прави съвместим с C API-та, очакващи указатели.

---

## 2. Създаване и Инициализация

```cpp
#include <iostream>
#include <vector>

int main() {
    // 1. Празен вектор
    std::vector<int> v1;

    // 2. Вектор с начални стойности (Initializer list)
    std::vector<int> v2 = {1, 2, 3, 4, 5};

    // 3. Вектор с определен размер и стойност по подразбиране
    // Създава 10 елемента, всички със стойност 7
    std::vector<int> v3(10, 7); 

    // 4. Копиране на друг вектор
    std::vector<int> v4 = v2;
    
    return 0;
}
```

## 3. Основни Операции

### 3.1. Добавяне и Премахване
Оптималното място за добавяне е **в края** на вектора.

```cpp
std::vector<int> v;

// Добавяне в края (Push Back) - O(1) амортизирано
v.push_back(10);
v.push_back(20);

// Премахване от края (Pop Back) - O(1)
v.pop_back(); // Премахва 20

// Добавяне на произволна позиция (Insert) - O(N) - Бавно!
// Трябва да премести всички следващи елементи
v.insert(v.begin(), 5); // Добавя 5 в началото

// Изчистване на целия вектор
v.clear(); // Размерът става 0
```

### 3.2. Достъп до елементи

```cpp
std::vector<int> v = {10, 20, 30};

// Чрез оператор [] - Бързо, без проверка за грешки
std::cout << v[0]; // 10

// Чрез метод .at() - По-бавно, но безопасно (хвърля exception при грешка)
try {
    std::cout << v.at(100); 
} catch (const std::out_of_range& e) {
    std::cout << "Error: " << e.what();
}

// Първи и последен елемент
std::cout << v.front(); // 10
std::cout << v.back();  // 30
```

## 4. Капацитет и Размер (Size vs Capacity)

Това е една от най-важните концепции при векторите.

*   **Size (Размер):** Броят на елементите, които векторът реално съдържа в момента. (`v.size()`)
*   **Capacity (Капацитет):** Броят на елементите, за които векторът е заделил памет. (`v.capacity()`)

Когато `size` достигне `capacity` и добавим нов елемент (`push_back`), векторът трябва да се преоразмери (reallocation):
1.  Заделя нов, по-голям блок памет (обикновено 2 пъти по-голям).
2.  Копира (или премества) всички стари елементи в новата памет.
3.  Освобождава старата памет.

Тази операция е скъпа. Затова, ако знаем предварително колко елемента ще имаме, е добре да използваме `reserve()`.

```cpp
std::vector<int> v;
v.reserve(1000); // Заделя памет за 1000 елемента веднага

// Сега първите 1000 push_back операции няма да предизвикат реалокация
```

## 5. Обхождане (Итерация)

```cpp
std::vector<int> nums = {1, 2, 3, 4, 5};

// 1. С индекс (класически for)
for (size_t i = 0; i < nums.size(); ++i) {
    std::cout << nums[i] << " ";
}

// 2. С итератор
for (std::vector<int>::iterator it = nums.begin(); it != nums.end(); ++it) {
    std::cout << *it << " ";
}

// 3. Range-based for (C++11) - Препоръчително
for (int x : nums) {
    std::cout << x << " ";
}

// 4. За промяна на елементите
for (int& x : nums) {
    x *= 2; // Удвоява всеки елемент
}
```

## 6. Двумерни Вектори

Вместо масиви от масиви (`int**`), в C++ е стандарт да се използват вектори от вектори.

```cpp
// Създава матрица 3x4 (3 реда, 4 колони), пълна с нули
int rows = 3;
int cols = 4;
std::vector<std::vector<int>> matrix(rows, std::vector<int>(cols, 0));

matrix[0][1] = 5; // Достъпът е като при обикновените масиви

// Предимство: редовете могат да имат различна дължина (Jagged Array)
std::vector<std::vector<int>> jagged;
jagged.push_back({1, 2});
jagged.push_back({3, 4, 5, 6});
```

## 7. Emplace Back vs Push Back

В C++11 е въведен методът `emplace_back`. Той конструира обекта директно в паметта на вектора, избягвайки създаването на временен обект и копирането му.

```cpp
struct Person {
    std::string name;
    int age;
    Person(std::string n, int a) : name(n), age(a) {}
};

std::vector<Person> people;

// push_back: Създава временен Person, после го копира във вектора
people.push_back(Person("Alice", 30));

// emplace_back: Подава аргументите на конструктора директно
people.emplace_back("Bob", 25); // По-ефективно
```

## 8. Обобщение

*   `std::vector` е изборът по подразбиране за динамични масиви в C++.
*   Предлага бърз достъп (O(1)) и бързо добавяне в края.
*   Избягвайте добавяне/триене в началото (ползвайте `std::deque` или `std::list` за това).
*   Използвайте `reserve()`, за да избегнете излишни реалокации.
