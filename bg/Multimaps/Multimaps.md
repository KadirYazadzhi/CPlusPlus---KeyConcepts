# Мултикарти (Multimaps) в C++

## 1. Въведение

`std::multimap` е асоциативен контейнер, много подобен на `std::map`, но с една съществена разлика: **позволява дублиране на ключове**.

Това означава, че един ключ може да бъде свързан с множество стойности. Дефиниран е в `<map>`.

### Примери за употреба:
*   Речник (една дума може да има няколко значения).
*   Телефонен указател (един човек може да има няколко номера).
*   Индекс на библиотека (един автор има много книги).

---

## 2. Основни разлики от std::map

1.  **Няма оператор `[]`**: Тъй като един ключ може да сочи към много стойности, изразът `m[key] = val` е двусмислен (коя от всички стойности да промени?). Затова `[]` не се поддържа.
2.  **Вмъкване**: Винаги се използва `insert()`. То винаги успява и добавя нова двойка, дори ключът вече да съществува.

---

## 3. Работа с Multimap

```cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::multimap<std::string, std::string> library;

    // Вмъкване на книги
    library.insert({"Tolkien", "The Hobbit"});
    library.insert({"Tolkien", "Lord of the Rings"});
    library.insert({"Rowling", "Harry Potter"});
    library.insert({"Tolkien", "The Silmarillion"});

    std::cout << "Books by Tolkien: " << library.count("Tolkien") << std::endl; // 3

    return 0;
}
```

---

## 4. Търсене и Обхождане на стойности

Тъй като имаме много стойности за един ключ, `find()` връща итератор към **първия** намерен елемент с този ключ.

За да вземем **всички** стойности за даден ключ, използваме `equal_range()`. Тази функция връща двойка итератори (начало и край), които очертават диапазона на всички елементи с този ключ.

```cpp
// Търсим всички книги на Толкин
std::string author = "Tolkien";

auto range = library.equal_range(author);

std::cout << "Books by " << author << ":\n";
// range.first е началото, range.second е края (не включително)
for (auto it = range.first; it != range.second; ++it) {
    std::cout << " - " << it->second << std::endl;
}
```

Алтернативно, можем да използваме `lower_bound` и `upper_bound`, но `equal_range` е по-удобно.

---

## 5. Изтриване

*   `erase(key)`: Изтрива **всички** двойки с този ключ.
*   `erase(iterator)`: Изтрива само конкретната двойка, към която сочи итераторът.

```cpp
// Изтрива всички книги на Rowling
library.erase("Rowling");

// Изтрива само една конкретна книга на Tolkien
auto it = library.find("Tolkien"); // Намира първата (The Hobbit)
if (it != library.end()) {
    library.erase(it);
}
```

---

## 6. Unordered Multimap

Съществува и `std::unordered_multimap`. Аналогично на `unordered_map`, той е базиран на хеш таблица, позволява дубликати, но няма подредба на ключовете. Операциите са O(1).

---

## 7. Обобщение

*   Използвайте `multimap`, когато релацията Ключ-Стойност е **1:N** (едно към много).
*   Елементите са сортирани по ключ.
*   Използвайте `equal_range()` за итериране през всички стойности на даден ключ.
*   Няма оператор `[]`.
