# Указатели (Pointers) в C++

## 1. Въведение

Указателите са една от най-мощните, но и потенциално опасни характеристики на езика C++. В своята същност, **указателят е променлива, която съхранява адреса на друга променлива в паметта**, вместо да съхранява самата стойност.

Разбирането на указателите е ключово за:
*   Динамично заделяне на памет (Heap allocation).
*   Ефективна работа с масиви и структури от данни.
*   Полиморфизъм.
*   Взаимодействие с хардуера и операционната система.

---

## 2. Основи и Синтаксис

### 2.1. Декларация и Инициализация
Указател се декларира чрез символа звездичка `*`. За да вземем адреса на променлива, използваме оператора амперсанд `&` (address-of operator).

```cpp
int number = 42;
int* ptr = &number; // ptr съхранява адреса на number
```

В този пример:
*   `number` е променлива от тип `int` със стойност 42.
*   `&number` връща адреса на `number` в паметта (например `0x7ffebc`).
*   `ptr` е променлива от тип `int*` (указател към int), която съхранява този адрес.

### 2.2. Деференцииране (Dereferencing)
За да достъпим или променим стойността, която се намира на адреса, съхранен в указателя, използваме оператора `*` пред името на указателя. Това се нарича **деференцииране**.

```cpp
#include <iostream>

int main() {
    int val = 100;
    int* p = &val;

    std::cout << "Адрес: " << p << std::endl;       // Извежда адреса (напр. 0x...)
    std::cout << "Стойност: " << *p << std::endl;  // Извежда 100 (деференцииране)

    *p = 200; // Променяме стойността на val чрез указателя

    std::cout << "Нова стойност на val: " << val << std::endl; // 200
    return 0;
}
```

## 3. Null Pointers (Нулеви указатели)

Указател, който не сочи към нищо валидно, трябва да бъде маркиран като такъв.
В съвременния C++ (C++11 и нагоре) винаги използвайте ключовата дума `nullptr`.

```cpp
int* p1 = nullptr; // Препоръчително в C++11+
int* p2 = NULL;    // Старият C-style начин (все още работи, но не се препоръчва)
int* p3 = 0;       // Също валидно, но може да е двусмислено
```

**Защо `nullptr`?**
`NULL` обикновено е дефиниран просто като `0`. Това може да доведе до объркване при претоварване на функции (overloading) – дали подавате цяло число `0` или нулев указател. `nullptr` има собствен тип `std::nullptr_t` и елиминира тази двусмислица.

## 4. Аритметика с Указатели

Указателите поддържат аритметични операции, но те работят по специфичен начин, зависещ от типа данни, към който сочат.

Ако имате указател `int* p` и изпълните `p + 1`, адресът няма да се увеличи с 1 байт, а с **размера на типа** (в случая `sizeof(int)`, обикновено 4 байта).

```cpp
int arr[] = {10, 20, 30};
int* ptr = arr; // Сочи към arr[0] (10)

std::cout << *ptr << std::endl;       // 10

ptr++; // Премества се към следващия int (увеличава адреса с 4 байта)
std::cout << *ptr << std::endl;       // 20

ptr += 1; // Отива на arr[2]
std::cout << *ptr << std::endl;       // 30
```

Това е основата на итерирането през масиви в C стил.

---

## 5. Указатели и Масиви

В C++ името на масива често се държи като указател към първия му елемент ("decay to pointer").

```cpp
int arr[5] = {1, 2, 3, 4, 5};
int* p = arr; // Еквивалентно на int* p = &arr[0];

// Достъпът чрез индекс е всъщност аритметика с указатели:
// arr[i] е еквивалентно на *(arr + i)
```

**Разлики:**
*   `sizeof(arr)` връща пълния размер на масива в байтове.
*   `sizeof(p)` връща размера на самия указател (4 или 8 байта, зависи от OS).
*   Указателят може да бъде пренасочен (`p = otherArr`), докато името на масива `arr` е константен адрес и не може да се променя.

## 6. Void Pointers (void*)

`void*` е специален тип указател, който може да сочи към обект от **какъвто и да е тип**. Той представлява "суров" адрес в паметта без информация за типа данни.

**Ограничения:**
*   Не може да бъде деференцииран директно (компилаторът не знае колко байта да прочете).
*   Не поддържа аритметика.

За да го използвате, трябва изрично да го преобразувате (cast) към конкретен тип.

```cpp
int a = 10;
void* vPtr = &a;

// std::cout << *vPtr; // ГРЕШКА!
std::cout << *(static_cast<int*>(vPtr)); // OK: 10
```

## 7. Динамично заделяне на памет (Dynamic Memory)

Това е една от основните употреби на указателите. Променливите в стека (stack) се унищожават автоматично, когато излязат от обхват. Ако искаме данните да живеят по-дълго или размерът им да се определя по време на изпълнение, използваме Heap (динамична памет) чрез операторите `new` и `delete`.

```cpp
// Заделяне на единичен int
int* p = new int; 
*p = 50;

// Заделяне на масив
int size;
std::cin >> size;
int* arr = new int[size]; // Размерът се определя runtime

// ... ползване ...

// ОСВОБОЖДАВАНЕ НА ПАМЕТТА (Критично важно!)
delete p;       // За единичен обект
delete[] arr;   // За масив
```

**Memory Leaks (Теч на памет):**
Ако забравите да извикате `delete`, заделената памет остава заета до края на програмата. Това се нарича "memory leak" и е сериозен проблем при сървъри и дълго работещи приложения.

## 8. Указатели към Функции

C++ позволява да създавате указатели към функции. Това позволява подаването на логика (алгоритми) като параметри (callback функции).

```cpp
int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }

// Дефиниция на тип за по-лесно четене
using Operation = int(*)(int, int); 

void execute(int x, int y, Operation op) {
    std::cout << "Result: " << op(x, y) << std::endl;
}

int main() {
    execute(5, 3, add); // Result: 8
    execute(5, 3, sub); // Result: 2
}
```

## 9. Умни Указатели (Smart Pointers) - Модерен C++

В съвременния C++ (C++11/14/17/20), използването на "сурови" указатели (`new`/`delete`) за управление на собствеността на паметта се счита за **лоша практика**. Вместо тях се използват Smart Pointers от библиотеката `<memory>`. Те автоматично освобождават паметта, когато вече не е нужна (RAII идиома).

### 9.1. `std::unique_ptr`
Представлява **ексклузивна собственост**. Не може да бъде копиран, само местен (moved). Когато `unique_ptr` излезе от обхват, той автоматично извиква `delete` на обекта.

```cpp
#include <memory>

void example() {
    std::unique_ptr<int> uPtr = std::make_unique<int>(100);
    // std::unique_ptr<int> copy = uPtr; // ГРЕШКА! Не може да се копира.
    
    std::cout << *uPtr << std::endl;
} // uPtr се унищожава тук и паметта се освобождава автоматично.
```

### 9.2. `std::shared_ptr`
Представлява **споделена собственост**. Използва брояч на референциите (reference counting). Паметта се освобождава само когато последният `shared_ptr`, сочещ към нея, бъде унищожен.

```cpp
#include <memory>

void example() {
    std::shared_ptr<int> sPtr1 = std::make_shared<int>(200);
    std::shared_ptr<int> sPtr2 = sPtr1; // Валидно. Броячът става 2.
    
    // И двата указателя сочат към едно и също място.
} // Броячът става 0 и паметта се освобождава.
```

### 9.3. `std::weak_ptr`
Използва се заедно със `shared_ptr` за прекъсване на циклични зависимости (circular dependencies). Не притежава обекта и не влияе на брояча.

## 10. Често срещани грешки

1.  **Dangling Pointer (Висящ указател):** Указател, който сочи към памет, която вече е освободена.
    ```cpp
    int* p = new int(5);
    delete p;
    *p = 10; // ГРЕШКА! Undefined Behavior.
    ```
    *Решение:* Винаги задавайте `p = nullptr` след `delete`.

2.  **Memory Leak:** Забравяне на `delete`.
    *Решение:* Използвайте `std::unique_ptr` или `std::shared_ptr`.

3.  **Деференцииране на неинициализиран указател:**
    ```cpp
    int* p; // Стойността е случаен адрес (garbage).
    *p = 5; // ГРЕШКА! Може да срине програмата (Segfault).
    ```
    *Решение:* Винаги инициализирайте указателите (`nullptr` или валиден адрес).

## 11. Указател към Указател (Double Pointer)

Можем да имаме указател, който сочи към друг указател.

```cpp
int a = 10;
int* ptr = &a;
int** ptrToPtr = &ptr;

std::cout << a;          // 10
std::cout << *ptr;       // 10
std::cout << **ptrToPtr; // 10
```
Това често се използва при динамични двумерни масиви или при промяна на самия указател вътре във функция.

---

## 12. Const и Указатели

Има фина разлика къде се поставя ключовата дума `const`.

1.  **Указател към константа (`const int*`):** Не можем да променяме стойността, към която сочи, но можем да местим указателя.
    ```cpp
    const int* p = &a;
    // *p = 5; // ГРЕШКА
    p = &b;   // ОК
    ```

2.  **Константен указател (`int* const`):** Можем да променяме стойността, но не можем да местим указателя (адресът е фиксиран).
    ```cpp
    int* const p = &a;
    *p = 5;   // ОК
    // p = &b; // ГРЕШКА
    ```

3.  **Константен указател към константа (`const int* const`):** Нищо не може да се променя.

## Заключение

Указателите са инструментът, който дава на C++ програмиста директен контрол над машината. Въпреки че модерният C++ насърчава използването на референции и Smart Pointers за безопасност, дълбокото разбиране на "суровите" указатели е задължително за разбирането на това как работи компютърът и как се изграждат ефективни структури от данни.
