# Стекове (Stacks) в C++

## 1. Въведение

Стекът е фундаментална структура от данни от тип **LIFO (Last-In, First-Out)** – Последен влязъл, първи излязъл. Можем да си го представим като купчина чинии: можем да сложим нова чиния само най-отгоре и можем да вземем чиния само от най-отгоре.

### Основни приложения:
*   Управление на паметта (Call Stack) при извикване на функции.
*   Алгоритми за обхождане (DFS - Depth First Search).
*   Проверка за балансирани скоби в изрази.
*   Undo/Redo функционалност в редактори.
*   Пресмятане на математически изрази (обратен полски запис).

---

## 2. Основни операции

Стекът поддържа ограничен набор от операции, всички с времева сложност **O(1)** (константно време):

1.  **push:** Добавя елемент на върха на стека.
2.  **pop:** Премахва елемента от върха на стека.
3.  **top (или peek):** Връща стойността на елемента на върха, без да го премахва.
4.  **empty:** Проверява дали стекът е празен.
5.  **size:** Връща броя на елементите.

⚠️ **Внимание:** Опитът за `pop()` или `top()` върху празен стек води до недефинирано поведение (често срив на програмата). Винаги проверявайте с `empty()` преди тези операции!

## 3. Използване на `std::stack`

В C++ стандартната библиотека (STL) предоставя готовия контейнер адаптер `std::stack`, дефиниран в заглавния файл `<stack>`.

```cpp
#include <iostream>
#include <stack>

int main() {
    std::stack<int> s;

    // 1. Добавяне (Push)
    s.push(10); // Стек: [10]
    s.push(20); // Стек: [10, 20] (20 е върха)
    s.push(30); // Стек: [10, 20, 30]

    // 2. Размер
    std::cout << "Size: " << s.size() << std::endl; // 3

    // 3. Достъп до върха (Top)
    std::cout << "Top element: " << s.top() << std::endl; // 30

    // 4. Премахване (Pop)
    s.pop(); // Премахва 30. Стек: [10, 20]
    std::cout << "New Top: " << s.top() << std::endl; // 20

    // 5. Обхождане (изпразване на стека)
    std::cout << "Popping elements: ";
    while (!s.empty()) {
        std::cout << s.top() << " ";
        s.pop();
    }
    // Резултат: 20 10
    
    return 0;
}
```

## 4. Имплементация "под капака"

`std::stack` е **контейнер адаптер**. Това означава, че той не управлява паметта директно, а използва друг контейнер (по подразбиране `std::deque` - двустранна опашка) за съхранение на данните, като просто ограничава достъпа до тях, за да спази LIFO принципа.

Можем да сменим базовия контейнер:
```cpp
#include <vector>
std::stack<int, std::vector<int>> vectorStack; // Използва вектор отдолу
```

## 5. Пример: Проверка за балансирани скоби

Една от най-класическите задачи за стек. Дали изразът `{[()]}` е валиден?

**Алгоритъм:**
1.  Обхождаме низа символ по символ.
2.  Ако видим отваряща скоба `(`, `{`, `[`, я добавяме в стека.
3.  Ако видим затваряща скоба:
    *   Ако стекът е празен -> Грешка (няма съответстваща отваряща).
    *   Взимаме върха на стека. Ако той е съответната отваряща скоба, го махаме (`pop`).
    *   Ако не съвпада -> Грешка (грешно вложена скоба).
4.  Накрая, ако стекът е празен -> Валиден израз.

```cpp
#include <iostream>
#include <stack>
#include <string>

bool isValid(std::string expression) {
    std::stack<char> s;

    for (char c : expression) {
        if (c == '(' || c == '{' || c == '[') {
            s.push(c);
        } else {
            if (s.empty()) return false; // Затваряща без отваряща
            
            char top = s.top();
            if ((c == ')' && top == '(') ||
                (c == '}' && top == '{') ||
                (c == ']' && top == '[')) {
                s.pop();
            } else {
                return false; // Несъвпадащи скоби
            }
        }
    }
    return s.empty(); // Трябва да е празен накрая
}

int main() {
    std::string expr = "{[()]}";
    if (isValid(expr)) std::cout << "Valid\n";
    else std::cout << "Invalid\n";
}
```

## 6. Stack Overflow (Препълване на стека)

Терминът идва от ситуацията, при която системният стек (Call Stack), който се използва за рекурсия и локални променливи, се изчерпи. Този стек е с фиксиран размер (обикновено няколко MB).

`std::stack`, от друга страна, използва динамичната памет (Heap), така че неговият размер е ограничен само от наличната RAM памет на компютъра.

## 7. Ръчна имплементация (С масив)

За образователни цели е полезно да видим как се прави прост стек с масив.

```cpp
class MyStack {
    int arr[100];
    int topIndex;

public:
    MyStack() { topIndex = -1; }

    void push(int x) {
        if (topIndex >= 99) {
            std::cout << "Stack Overflow\n";
            return;
        }
        arr[++topIndex] = x;
    }

    void pop() {
        if (topIndex < 0) {
            std::cout << "Stack Underflow\n";
            return;
        }
        topIndex--;
    }

    int top() {
        if (topIndex < 0) return -1;
        return arr[topIndex];
    }

    bool empty() {
        return topIndex == -1;
    }
};
```
