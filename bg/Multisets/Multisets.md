# Мултимножества (Multisets) в C++

## 1. Въведение

`std::multiset` е асоциативен контейнер, подобен на `std::set`, който съхранява елементи в **сортиран ред**, но позволява **дублиране на стойности**.

Дефиниран е в `<set>`.

### Характеристики:
*   **Сортиране:** Елементите винаги са подредени (O(log N) за вмъкване).
*   **Дубликати:** Позволява добавянето на еднакви стойности. Всички дубликати се съхраняват съседни един до друг в дървото.

---

## 2. Работа с Multiset

```cpp
#include <iostream>
#include <set>

int main() {
    std::multiset<int> ms;

    ms.insert(10);
    ms.insert(20);
    ms.insert(10); // Успява!
    ms.insert(5);

    // Съдържание: 5, 10, 10, 20

    // Брой срещания
    std::cout << "Count of 10: " << ms.count(10) << std::endl; // 2

    return 0;
}
```

---

## 3. Търсене и Изтриване

### 3.1. Търсене
`find(val)` връща итератор към **първия** намерен екземпляр на `val`.

### 3.2. Изтриване
Внимавайте с метода `erase`.

```cpp
// Вариант 1: Изтриване по стойност
// Това ще изтрие ВСИЧКИ срещания на стойността 10!
ms.erase(10); 

// Вариант 2: Изтриване на един екземпляр
auto it = ms.find(20);
if (it != ms.end()) {
    ms.erase(it); // Изтрива само копието, към което сочи итератора
}
```

---

## 4. Обобщение

Използвайте `std::multiset`, когато ви трябва сортиран списък от елементи, където повторенията са валидни (например списък с оценки на студенти, цени на транзакции и др.).
