# Опашки с Приоритет (Priority Queues) в C++

## 1. Въведение

`std::priority_queue` е контейнер адаптер в C++, който предоставя функционалност за подреждане на елементите според тяхната важност (приоритет). Дефиниран е в `<queue>`.

За разлика от обикновената опашка (FIFO), където елементите излизат в реда на постъпване, в приоритетната опашка **елементът с "най-висок приоритет" винаги излиза пръв**, независимо кога е добавен.

### Характеристики:
*   По подразбиране, "най-висок приоритет" означава **най-голямата стойност** (Max Heap).
*   Времева сложност на добавяне (`push`) и премахване (`pop`): **O(log N)**.
*   Достъп до върха (`top`): **O(1)**.
*   Реализирана е върху структурата от данни **Binary Heap** (Двоична пирамида).

---

## 2. Основни Операции

Интерфейсът е почти идентичен с този на `std::stack`, а не на `std::queue` (имаме `top`, а не `front`).

```cpp
#include <iostream>
#include <queue>

int main() {
    std::priority_queue<int> pq;

    // Добавяне
    pq.push(10);
    pq.push(30);
    pq.push(20);
    pq.push(5);

    // Вътрешна структура (концептуално): [30, 20, 10, 5]
    // Най-големият елемент е винаги отгоре.

    std::cout << "Top element: " << pq.top() << std::endl; // 30

    // Премахване
    pq.pop(); // Маха 30. Следващият най-голям (20) идва отгоре.
    
    std::cout << "New Top: " << pq.top() << std::endl; // 20

    // Обхождане и изпразване
    while (!pq.empty()) {
        std::cout << pq.top() << " ";
        pq.pop();
    }
    // Резултат: 20 10 5 (сортирани низходящо)

    return 0;
}
```

## 3. Min-Heap (Минимален елемент пръв)

По подразбиране, `priority_queue` е Max-Heap. Ако искаме най-малкият елемент да излиза пръв (Min-Heap), трябва да променим компаратора.

Дефиницията на шаблона е:
`priority_queue<Type, Container, Comparator>`

```cpp
#include <iostream>
#include <queue>
#include <vector>

int main() {
    // std::greater<int> обръща логиката на сравнение
    std::priority_queue<int, std::vector<int>, std::greater<int>> minPQ;

    minPQ.push(10);
    minPQ.push(30);
    minPQ.push(5);

    std::cout << minPQ.top(); // 5 (най-малкият елемент)

    return 0;
}
```

## 4. Приоритетна опашка с потребителски обекти

За да използваме собствени класове, трябва или да претоварим оператора `<`, или да напишем собствен компаратор (структура с `operator()`).

### Вариант 1: Претоварване на operator<
```cpp
struct Student {
    std::string name;
    int grade;

    // Искаме студентите с по-висок успех да са с по-висок приоритет
    bool operator<(const Student& other) const {
        return grade < other.grade;
    }
};

std::priority_queue<Student> pq; // Ще ползва operator<
```

### Вариант 2: Външен компаратор (Functor)
Това е по-гъвкавият начин, защото не променя класа.

```cpp
struct Task {
    int id;
    int priority;
};

// Функтор за сравнение
struct CompareTask {
    bool operator()(const Task& t1, const Task& t2) {
        // По-малко число = по-малък приоритет (стандартно поведение)
        // Ако искаме по-малко число да е по-ВИСОК приоритет, обръщаме знака:
        return t1.priority > t2.priority; // Min-Heap поведение за priority полето
    }
};

int main() {
    std::priority_queue<Task, std::vector<Task>, CompareTask> taskQueue;
    taskQueue.push({1, 50});
    taskQueue.push({2, 10});

    // t2 (priority 10) ще излезе първо заради компаратора
}
```

## 5. Приложения

### 5.1. Алгоритъм на Дейкстра (Dijkstra)
Използва се за намиране на най-кратък път в граф. Опашката с приоритет (Min-Heap) се използва за винаги избиране на най-близкия непосетен възел.

### 5.2. Huffman Coding
Алгоритъм за компресия на данни, който строи дърво на базата на честотата на символите (най-честите символи са с най-висок приоритет).

### 5.3. Сливане на K сортирани масива
Ако имате К сортирани списъка и искате да ги обедините в един сортиран списък, Min-Heap с размер К е най-ефективното решение.

---

## 6. Обобщение

*   `std::priority_queue` не е FIFO, а подрежда по важност.
*   Базирана е на Heap структура (дърво в масив).
*   Много ефективна за намиране на мин/макс елемент в динамичен поток от данни.
*   Не поддържа итератори (не може да се обхожда без да се руши).
