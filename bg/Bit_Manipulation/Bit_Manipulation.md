# Битови Манипулации (Bit Manipulation) в C++

## 1. Въведение

В системното програмиране, драйверите и embedded системите често се налага да работим не с числа, а с отделни битове (флагове). C++ предоставя нискочестотни оператори за това.

---

## 2. Битови Оператори

Представете си `a = 5` (0101) и `b = 3` (0011).

*   `&` (AND): `a & b` -> 0001 (1)
*   `|` (OR):  `a | b` -> 0111 (7)
*   `^` (XOR): `a ^ b` -> 0110 (6)
*   `~` (NOT): `~a`    -> 1010 (обръща всички битове)
*   `<<` (Left Shift): `a << 1` -> 1010 (10) - Умножение по 2
*   `>>` (Right Shift): `a >> 1` -> 0010 (2) - Деление на 2

---

## 3. Чести операции (Идиоми)

```cpp
const int READ  = 1 << 0; // 0001 (1)
const int WRITE = 1 << 1; // 0010 (2)
const int EXEC  = 1 << 2; // 0100 (4)

int permissions = 0;

// 1. Вдигане на флаг (Set)
permissions |= READ; 

// 2. Проверка на флаг (Check)
if (permissions & READ) { /* ... */ }

// 3. Сваляне на флаг (Clear)
permissions &= ~READ;

// 4. Обръщане на флаг (Toggle)
permissions ^= WRITE;
```

## 4. C++20 Библиотека <bit>

C++20 добави заглавния файл `<bit>`, който стандартизира много полезни функции, които преди зависеха от компилатора (`__builtin_popcount` и т.н.).

*   `std::popcount(n)`: Брои единиците в числото.
*   `std::countl_zero(n)`: Брои водещите нули.
*   `std::bit_cast<T>(u)`: Най-безопасният начин да превърнем битовете на един тип в друг (напр. `float` към `int`), без да нарушаваме Aliasing правилата (както прави `reinterpret_cast` понякога).

```cpp
#include <bit>
#include <iostream>

int main() {
    unsigned int n = 0b10110; // 22
    std::cout << std::popcount(n) << "\n"; // 3 (три единици)
}
```

## 5. std::bitset

Ако ви трябват повече от 64 бита (колкото е `unsigned long long`), използвайте `std::bitset`.

```cpp
#include <bitset>
std::bitset<8> bits("10110010");
bits[0] = 0; // Промяна
std::cout << bits.to_ulong();
```
