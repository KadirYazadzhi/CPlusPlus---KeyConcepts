# Масиви (Arrays) в C++

## 1. Въведение

Масивът е една от най-фундаменталните структури от данни в програмирането. Той представлява **колекция от елементи от един и същи тип, разположени последователно в паметта**.

В C++ масивите са с **фиксиран размер**, което означава, че броят на елементите трябва да бъде известен по време на компилация (за статични масиви) и не може да се променя по време на изпълнение на програмата.

### Основни характеристики:
*   **Хомогенност:** Всички елементи са от един и същи тип (напр. само `int` или само `double`).
*   **Последователна памет:** Елементите се съхраняват един след друг, което гарантира изключително бърз достъп.
*   **Бърз достъп (Random Access):** Достъпът до всеки елемент става за константно време O(1) чрез неговия индекс.

---

## 2. Декларация и Инициализация

### 2.1. Декларация
Синтаксисът е `тип име[размер];`.

```cpp
int numbers[5]; // Декларира масив от 5 цели числа
// Стойностите в момента са неопределени (garbage values)!
```

### 2.2. Инициализация
Можем да зададем начални стойности при декларацията.

```cpp
// Пълна инициализация
int arr1[5] = {10, 20, 30, 40, 50};

// Частична инициализация (останалите стават 0)
int arr2[5] = {1, 2}; // {1, 2, 0, 0, 0}

// Автоматично определяне на размера
int arr3[] = {1, 2, 3}; // Размерът автоматично става 3

// Инициализиране с нули (C++11)
int arr4[5] = {}; // {0, 0, 0, 0, 0}
```

---

## 3. Достъп до елементи

Елементите се достъпват чрез **индекс**, поставен в квадратни скоби `[]`.
**Важно:** В C++ индексирането започва от **0**.

```cpp
int nums[3] = {100, 200, 300};

// Четене
std::cout << nums[0]; // 100 (първи елемент)
std::cout << nums[2]; // 300 (последен елемент)

// Писане
nums[1] = 500; // Променя втория елемент на 500
```

⚠️ **Внимание:** C++ **НЕ** прави проверка за излизане от границите на масива (Bounds Checking).
Ако се опитате да достъпите `nums[5]`, програмата ще прочете или запише в памет, която не притежава, което води до **Undefined Behavior** (недефинирано поведение) или срив (Segfault).

---

## 4. Масиви в паметта

Тъй като масивите са последователни, адресът на елемент `i` може да се изчисли лесно:
`Адрес[i] = Начален_Адрес + (i * Размер_на_Типа)`

Пример с `int arr[3]` (приемаме `sizeof(int) = 4` байта):
*   `arr[0]` е на адрес `0x1000`
*   `arr[1]` е на адрес `0x1004`
*   `arr[2]` е на адрес `0x1008`

Това обяснява защо достъпът е толкова бърз.

## 5. Обхождане на масив

Най-честият начин за работа с масиви е чрез цикли.

### 5.1. Класически `for` цикъл
Този метод ни дава достъп до индекса.

```cpp
int arr[5] = {10, 20, 30, 40, 50};

for (int i = 0; i < 5; i++) {
    std::cout << "Element at index " << i << ": " << arr[i] << std::endl;
}
```

### 5.2. Range-based `for` цикъл (C++11)
По-модерен и безопасен начин, ако не ни трябва индекса.

```cpp
for (int val : arr) {
    std::cout << val << " "; // Работи с копие на стойността
}

for (int& val : arr) {
    val *= 2; // Използваме референция, за да променяме елементите
}
```

## 6. Масиви и Функции

Когато подаваме масив на функция в C++, той **не се копира**. Вместо това, той "деградира" (decays) до **указател към първия си елемент**.

Това означава две неща:
1.  Функцията може да променя оригиналния масив.
2.  Функцията **губи информацията за размера** на масива. Трябва да подадем размера като отделен параметър.

```cpp
// Параметърът int arr[] е еквивалентен на int* arr
void printArray(int arr[], int size) {
    for (int i = 0; i < size; i++) {
        std::cout << arr[i] << " ";
    }
    std::cout << std::endl;
    
    // sizeof(arr) тук ще върне размера на указател (4 или 8), а не на масива!
}

int main() {
    int myArr[] = {1, 2, 3, 4, 5};
    // Изчисляване на размера: Общ размер / размер на един елемент
    int size = sizeof(myArr) / sizeof(myArr[0]);
    
    printArray(myArr, size);
}
```

## 7. Многомерни масиви (Multidimensional Arrays)

Масивите могат да имат повече от едно измерение. Най-често се използват двумерни масиви (матрици).

```cpp
// Матрица 3x3
int matrix[3][3] = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};

std::cout << matrix[1][1]; // Достъп до ред 1, колона 1 (стойност 5)
```

(Повече детайли са разгледани в темата "Двумерни Масиви").

## 8. Модерната алтернатива: `std::array`

В съвременния C++, използването на "C-style" масиви (`int arr[5]`) често се заменя с контейнера `std::array` (от заглавния файл `<array>`).

### Предимства на `std::array`:
*   Знае своя размер (`.size()`).
*   Не деградира до указател автоматично.
*   По-безопасен (има метод `.at()`, който прави проверка на границите).
*   Има същата производителност като C-style масив.

```cpp
#include <array>
#include <iostream>

int main() {
    std::array<int, 5> nums = {1, 2, 3, 4, 5};

    std::cout << "Size: " << nums.size() << std::endl;

    // Безопасен достъп (хвърля изключение при грешка)
    try {
        nums.at(10) = 5; 
    } catch (const std::out_of_range& e) {
        std::cerr << "Error: " << e.what() << std::endl;
    }

    return 0;
}
```

## 9. Често срещани проблеми

1.  **Buffer Overflow (Препълване на буфера):** Писане извън границите на масива. Това е най-честата причина за уязвимости в сигурността.
2.  **Забравен размер:** Тъй като функциите не знаят размера на C-масивите, лесно е да се итерира твърде дълго.
3.  **Връщане на локален масив:** Никога не връщайте C-масив от функция, освен ако не е динамично заделен или статичен.

```cpp
// ГРЕШКА!
int* createArray() {
    int arr[5] = {1, 2, 3, 4, 5};
    return arr; // Връща указател към унищожена стекова памет
}
```

---

## 10. Обобщение

Масивите са бързи и ефективни, но изискват внимателно управление на паметта и индексите. За модерен C++ код се препоръчва:
*   `std::array` за масиви с фиксиран размер.
*   `std::vector` за масиви с променлив (динамичен) размер.
*   C-style масиви се използват предимно за съвместимост със стари библиотеки или в embedded системи с ограничени ресурси.
