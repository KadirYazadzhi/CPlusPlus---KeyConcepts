# Двустранни Опашки (Deques) в C++

## 1. Въведение

`std::deque` (произнася се "дек", съкращение от **Double-Ended Queue**) е индексен контейнер, който позволява бързо вмъкване и премахване на елементи както от **началото**, така и от **края**.

Намира се в заглавния файл `<deque>`.

### Deque vs Vector
*   **Vector:** Бързо добавяне само в края (`push_back`). Добавянето отпред (`insert(begin)`) е много бавно O(N). Паметта е непрекъсната.
*   **Deque:** Бързо добавяне и в двата края O(1). Паметта **не е** непрекъсната (разпределена е на парчета/chunks).

---

## 2. Имплементация

`std::deque` обикновено се реализира като набор от масиви с фиксиран размер, управлявани от централен "масив от указатели" (map).
Когато добавяте елементи и текущият буфер се напълни, deque заделя нов буфер и го закача, вместо да копира всичко в нов, по-голям масив (както прави векторът).

Това означава:
*   Няма пълно копиране при разширяване.
*   Достъпът по индекс е малко по-бавен от вектора (две дереференции вместо една), но все пак е O(1).

---

## 3. Основни Операции

```cpp
#include <iostream>
#include <deque>

int main() {
    std::deque<int> d = {10, 20};

    // 1. Добавяне
    d.push_back(30);  // {10, 20, 30}
    d.push_front(5);  // {5, 10, 20, 30} - Уникално за deque/list

    // 2. Достъп по индекс (Random Access)
    std::cout << d[1]; // 10

    // 3. Премахване
    d.pop_front(); // Маха 5
    d.pop_back();  // Маха 30

    // 4. Размер
    std::cout << "Size: " << d.size();

    return 0;
}
```

---

## 4. Кога да използваме Deque?

`std::deque` е отличен избор, когато:
1.  Трябва да добавяте/махате елементи от **двата края** (напр. опашка от задачи, history buffer).
2.  Искате достъп по индекс (`operator[]`), но векторът е твърде скъп за преоразмеряване.
3.  Не ви трябва гарантирана непрекъсната памет (не работите с C функции като `memset` или `memcpy`).

Забележка: `std::stack` и `std::queue` по подразбиране използват `std::deque` като вътрешен контейнер.

---

## 5. Обобщение

*   `std::deque` е "Вектор с `push_front`".
*   Осигурява O(1) достъп по индекс.
*   По-сложна структура на паметта от вектор, но по-ефективна при разширяване от двата края.
