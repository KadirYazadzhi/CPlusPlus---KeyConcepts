# Карти (Maps) в C++

## 1. Въведение

`std::map` е асоциативен контейнер, който съхранява елементи във формата на **двойки ключ-стойност** (Key-Value pairs).

*   **Ключовете** са уникални и се използват за сортиране и търсене на елементите.
*   **Стойностите** са свързани с ключовете и могат да се повтарят.

Подобно на `std::set`, `std::map` обикновено се реализира чрез **балансирано двоично дърво** (Red-Black Tree).

### Характеристики:
*   **Подредба:** Елементите винаги са сортирани по ключ (възходящо по подразбиране).
*   **Сложност:** Търсене, вмъкване и триене отнемат **O(log N)** време.
*   **Уникалност:** Всеки ключ може да се среща само веднъж.

---

## 2. Създаване и Вмъкване

```cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    // Карта: Име (string) -> Години (int)
    std::map<std::string, int> ages;

    // 1. Вмъкване чрез оператор []
    // Ако ключът не съществува, се създава. Ако съществува, се презаписва.
    ages["Alice"] = 25;
    ages["Bob"] = 30;

    // 2. Вмъкване чрез insert() и std::pair
    ages.insert(std::pair<std::string, int>("Charlie", 20));
    
    // 3. Вмъкване чрез insert() и make_pair
    ages.insert(std::make_pair("David", 35));

    // 4. Вмъкване чрез инициализатор (C++11)
    ages.insert({"Eve", 28});

    std::cout << "Size: " << ages.size() << std::endl; // 5

    return 0;
}
```

---

## 3. Достъп до Елементи

### 3.1. Оператор `[]`
Най-удобният начин, но има страничен ефект: **Ако ключът не съществува, той се създава автоматично със стойност по подразбиране (0, празен низ и т.н.).**

```cpp
std::cout << ages["Alice"]; // 25
std::cout << ages["Zoro"];  // Връща 0 и добавя "Zoro" -> 0 в картата!
```

### 3.2. Методът `at()`
По-безопасен за четене. Хвърля `std::out_of_range` exception, ако ключът липсва.

```cpp
try {
    std::cout << ages.at("Nobody");
} catch (const std::exception& e) {
    std::cout << "Key not found\n";
}
```

---

## 4. Търсене и Проверка

### 4.1. Методът `find()`
Връща итератор към намерения елемент (двойка) или `end()`.

```cpp
auto it = ages.find("Bob");
if (it != ages.end()) {
    // it->first е ключът, it->second е стойността
    std::cout << "Found " << it->first << ": " << it->second << std::endl;
} else {
    std::cout << "Not found\n";
}
```

### 4.2. Методът `count()`
Връща 1 (има го) или 0 (няма го).

```cpp
if (ages.count("Alice")) { /* ... */ }
```

## 5. Обхождане на Map

При итериране през map, получаваме достъп до елементи от тип `std::pair<const Key, Value>`.

```cpp
std::map<std::string, int> ages = {{"Alice", 25}, {"Bob", 30}};

// Класически итератор
for (std::map<std::string, int>::iterator it = ages.begin(); it != ages.end(); ++it) {
    std::cout << it->first << " is " << it->second << " years old.\n";
}

// Range-based for (C++11)
for (const auto& pair : ages) {
    std::cout << pair.first << ": " << pair.second << "\n";
}

// Structured Binding (C++17) - Най-модерният и чист начин
for (const auto& [name, age] : ages) {
    std::cout << name << ": " << age << "\n";
}
```

Важно: Обхождането винаги е в **сортиран ред по ключ** (азбучен ред за стрингове).

---

## 6. Изтриване

```cpp
ages.erase("Alice"); // Трие по ключ

auto it = ages.find("Bob");
if (it != ages.end()) ages.erase(it); // Трие по итератор

ages.clear(); // Изтрива всичко
```

## 7. Map vs Unordered Map

| Характеристика | std::map | std::unordered_map |
| :--- | :--- | :--- |
| **Структура** | Балансирано дърво (Red-Black Tree) | Хеш таблица (Hash Table) |
| **Подредба** | Сортиран по ключ | Хаотичен (неопределен) ред |
| **Търсене/Вмъкване** | O(log N) | O(1) средно, O(N) най-лошо |
| **Консумация на памет** | По-ниска (обикновено) | По-висока (заради хеш таблицата) |
| **Изисквания към ключа** | Оператор `<` | Хеш функция и оператор `==` |

---

## 8. Обобщение

*   `std::map` е мощен инструмент за свързване на данни (речници, конфигурации).
*   Гарантира, че данните са сортирани.
*   Оператор `[]` е удобен, но внимавайте за нежелано вмъкване на елементи.
*   Използвайте `const auto& [key, val]` в C++17 за елегантно обхождане.
